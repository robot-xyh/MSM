# D7 比例导引与末端视觉 PNG 实现差距审计

**审计范围**：`subagent_reviews/D7_PROPORTIONAL_GUIDANCE_REVIEW_AND_PLAN.md`、`C_UAS_MAINSTREAM_SOLUTIONS_AND_DIFFICULTIES.md`、`research_modules/d7_proportional_guidance/`、`research_modules/d7_proportional_guidance/png_guidance_delivery/`、`research_modules/airsim_runtime/`、`research_modules/integrated_simulation/`、`research_modules/INTEGRATION_CONTRACT.md`。  
**边界**：本文只审计当前科研仿真、AirSim Blocks 闭环、离线记录和接口合同实现状态，不提出真实火控参数、毁伤模型、硬件部署或绕过人工授权的自动处置流程。

## 总体结论

D7 当前已经实现了可测试的离线二维经典 PN、合成视觉 LOS 末端模式、AirSim phase-1 dry-run 记录适配、SimpleFlight 受控 2v2 actor 拦截闭环，以及从 `png_guidance_delivery` 抽取的轻量视觉 PNG gate。`SimpleFlightPngGuidanceFilter` 已能根据 bbox 面积、检测置信度、LOS-rate 稳定性、视觉延迟、闭合速度和机动裕度决定是否允许进入视觉末端，并输出 SimpleFlight 速度命令。

主要差距集中在三处：

1. **主流程切换策略还没有完整消费 D5 `TerminalAssociation(locked)` 和 D3 plan/version 合同**。离线集成仿真按距离/时间直接切入 `vision_terminal`；AirSim 受控拦截使用 assigned object detection + PNG gate，但不是 D5 的 `locked/ambiguous/hold/reacquire` DTO。
2. **改进 PN、Pure Pursuit 对照、严格工程化视觉 PN 仍不完整**。经典 PN 已实现；Pure Pursuit 只有 AirSim terminal LOS heading 的行为片段，没有独立算法、配置、指标和对照实验；FRPN/augmented/biased/true PN 尚未实现。
3. **PX4/MAVLink/YOLO+ByteTrack/OpenCV/KCF 等能力存在于 delivery 包或文档中，但未进入 main D7 主线**。当前主线明确选择 SimpleFlight `moveByVelocityZAsync` 和 AirSim `simGetDetections`，未直接调用 PX4 Offboard、MAVLink body-rate、YOLO/TensorRT 或 OpenCV 标定链路。

D7 单元测试已通过：`python3 -m pytest research_modules/d7_proportional_guidance/tests`，结果为 `11 passed`。

## 关键缺失条件汇总

1. **D5 到 D7 的运行时门控合同**：D7 需要消费 `TerminalAssociation.assigned_global_track_id/local_track_id/decision_state/association_confidence/friend_conflict_state/assignment_version/plan_version`，并把 `locked` 作为唯一视觉末端入口。
2. **D3 到 D7 的版本化绑定 DTO**：需要 `resource_id`、`vehicle_name`、`assigned_global_track_id`、`plan_id`、`plan_version`、`track_version`、`authorization_state`、`assignment_validity_state`，并支持撤销和重分配。
3. **严格视觉 PN 所需观测条件**：稳定 camera intrinsics/extrinsics、bbox timestamp、local track 连续性、LOS-rate 滤波、距离/闭合速度估计来源、视觉延迟和丢检策略。
4. **外部视觉/飞控依赖条件**：YOLO/ByteTrack 需要图像帧、权重、class id、Ultralytics/lap/lapx、性能预算；OpenCV/KCF 需要 contrib build；PX4/MAVLink 需要 SITL、pymavlink、Offboard 状态机、推力/坐标标定和安全流程。
5. **D6 指标消费条件**：D7 需要稳定输出 guidance/intercept summary schema；D6 需要新增 adapter，把 min range、time to intercept、mode switch、collision object、abort reason 和 gate reject reason 归入 episode metrics。

## 建议执行顺序
