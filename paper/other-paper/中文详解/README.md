## 面向非专业读者的阅读方法

阅读单篇详解时，建议先回答四个问题：

1. **机器人实际要完成什么任务？** 先确认输入是什么、机器人要做什么动作、怎样才算成功。
2. **为什么这件事困难？** 分清困难来自感知、定位、规划、控制、机械结构，还是计算速度。
3. **工程上通常怎么做？** 先理解传统模块化方案和成熟默认做法，再看论文替换或增强了哪个环节。
4. **论文究竟验证到了哪一步？** 区分离线数据评测、仿真、硬件在环、实验室动捕真机和开放环境自主运行。

文中所说的“通用做法”主要依据论文的引言、相关工作和实验基线，表示常见工程路线，不代表唯一正确方案。刚入门时可先看每篇文档的“外行导读”“系统输入输出”和“实验结论”，再阅读公式和优化细节。

## 常见术语的白话解释

| 术语 | 白话解释 |
|---|---|
| 状态估计 | 根据相机、激光雷达、惯性测量等传感器，持续推算机器人当前的位置、姿态和速度 |
| 视觉惯性里程计 | 把相机与惯性测量结合起来估计运动；短时间很准，但长距离仍可能积累漂移 |
| 激光雷达惯性里程计 | 把激光点云与惯性测量结合起来定位和建图，常用于无卫星定位环境 |
| 同时定位与建图 | 机器人一边估计自己在哪里，一边建立环境地图，英文常缩写为 SLAM |
| 位姿图优化 | 把不同时刻的机器人位姿看成图节点，把里程计和回环看成边，整体调整轨迹以减少漂移 |
| 回环检测 | 识别机器人再次来到以前经过的位置，并用这次重逢纠正累计误差 |
| 轨迹优化 | 直接调整路径形状和时间分配，使运动同时满足避障、速度、加速度、推力等约束 |
| 模型预测控制 | 每隔很短时间预测未来运动并在线求解控制量，只执行第一步后再重新计算 |
| 运动捕捉 | 使用 NOKOV、Vicon、OptiTrack 等多相机系统在实验室内提供高精度位置和姿态 |
| 硬件在环 | 真实飞控或处理器接入模拟环境运行；比纯软件仿真更接近实机，但仍不等于真实飞行 |
| 基础模型/视频模型 | 在大规模数据上训练的通用神经网络，可用于三维理解、视频生成或语言条件导航 |
| 真值 | 用更高精度设备记录的参考答案；只用于算误差时，不代表算法运行依赖该设备 |

## 实物测试、运动捕捉与开放环境实验核对

为避免把“仿真效果好”“用真实数据评测”和“真实机器人闭环完成任务”混为一谈，下表逐篇核对原论文的实验形式。判定口径如下：

- **真机闭环**：算法在真实机器人上参与感知、规划或控制并实际执行任务；**实物采集/感知评测**表示用了真实传感器或真实平台数据，但没有完成机器人闭环任务。
- **运动捕捉或外部定位**：重点说明算法执行时是否依赖 NOKOV、Vicon、OptiTrack 等实验室运动捕捉设备；若设备只用于记录真值、画误差曲线而不向算法提供状态，会明确标成“仅作真值”。卫星定位和外部标记也单独注明。
- **开放环境实验**：指室外、森林、农田、道路、野外等不受实验室运动捕捉空间限制的真实环境。普通室内房间、飞行场馆、实验室搭建障碍场和地下停车库不计为开放环境。
- “未明确”表示原论文正文没有给出足够信息，不能据此推断使用或未使用某种设备。
