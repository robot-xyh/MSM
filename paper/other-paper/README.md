- 清单外机器人及自动化论文：35 篇。
- 与 `papers` 主清单重复、内容相同或版本不同的 PDF：10 份，位于 [`duplicates`](duplicates/)。
- 医学、材料和化学等非机器人论文：7 篇，原始文件位于 [`../others/unrelated`](../others/unrelated/)。
- 用户提供的原始压缩包：4 个，位于 [`archives`](archives/)。
- 所有 PDF 均已通过 `pdfinfo` 解析检查；这里只做本地文件分类，不代表已逐篇完成来源、版本和科研质量审计。
