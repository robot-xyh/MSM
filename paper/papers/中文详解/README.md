# 25 篇论文中文详细解读索引

> **本索引保留两种分类：第一至第四章先按任务和应用场景分类，第六章再按使用的算法与技术路线分类；第五章为建议阅读路线。**

本目录为浙江大学 Fast-Lab 等团队发表的 25 篇前沿机器人及智能无人系统论文的逐篇中文结构化详细解读。现已完整覆盖 `papers/` 目录下的全部 25 篇论文。每篇详解均链接原始 PDF，深入剖析研究背景、外行导读、当前研究现状与成熟度对比、核心术语白话解释、系统输入输出、算法与理论推导、网络架构/优化求解、实验设计、量化对比基准、创新点、局限与复现提示。

这些文档是面向技术理解和方案选型的**结构化中文详解**，不是逐句直译。量化结果均按论文正文记录。

## 面向非专业读者的阅读方法

每篇解读先回答四个最重要的问题：

1. **机器人实际要完成什么任务？** 先用日常场景说明输入、动作和成功标准。
2. **为什么这件事困难？** 区分感知、规划、控制、机械和计算速度上的困难。
3. **大家通常怎么做？** 说明截至这些论文发表前后（约 2023—2026 年）的通用工程流程、成熟默认方案和较新的研究路线。
4. **这篇论文改变了哪一步？** 避免把一个局部算法误解为已经解决整套自主系统。

文中对研究现状的表述主要依据各论文的引言、相关工作、实验基线和公开原文。这里的“通用做法”表示被大量机器人系统采用的典型路线，不代表所有团队或所有场景的唯一选择。

## 常见术语的白话解释

| 术语 | 白话解释 |
|---|---|
| 强化学习 | 让程序在模拟环境反复试错，通过成功奖励和失败惩罚学会控制策略 |
| 扩散模型 | 类似 AI 画图的去噪生成模型，通过学习概率分布生成平滑多样化的动作或点云 |
| 端到端 | 中间少做人工拆分，直接把相机/雷达/状态输入映射成动作或轨迹 |
| 仿真到现实 (Sim-to-Real) | 先在模拟器训练或测试，再把同一算法零样本/微调部署到真实机器人上 |
| 差分平坦性 | 用少量容易规划的平坦输出（如三维位置与偏航角）及其高阶导数，代数推回完整姿态和电机控制量 |
| 有符号距离场 (SDF/ESDF) | 地图中每个空间位置保存“离最近障碍表面还有多远”，障碍内部通常记为负值 |
| 凸安全走廊 (Flight Corridor) | 沿规划路径生成的无碰撞凸多面体连通区域，使复杂的避障约束转化为线性不等式 |
| 模型预测控制 (MPC/NMPC) | 每隔很短时间（如 10ms）预测未来一段运动，在线求解最优控制量，然后仅执行首步 |
| 增量非线性动态逆 (INDI) | 利用机载高频传感器测量的实际加速度与期望之差，直接反推并消除未建模扰动 |
| 视场 (FOV) | 相机或激光雷达在水平、垂直方向能观测到的有效角度范围 |
| 均方根误差 (RMSE) | 衡量整段轨迹或状态跟踪偏差的统计量，数值越小通常跟踪精度越高 |

## 实物测试、运动捕捉与开放环境实验核对

为避免把“仿真效果好”“用真实数据评测”和“真实机器人闭环完成任务”混为一谈，下表逐篇核对原论文的实验形式。判定口径如下：

- **真机闭环**：算法在真实机器人上参与感知、规划或控制并实际执行任务；**实物采集/感知评测**表示用了真实传感器或真实平台数据，但没有完成机器人闭环任务。
- **运动捕捉或外部定位**：重点说明算法执行时是否依赖 NOKOV、Vicon、OptiTrack 等实验室运动捕捉设备；若设备只用于记录真值、画误差曲线而不向算法提供状态，会明确标成“仅作真值”。卫星定位也单独注明。
- **开放环境实验**：指室外、森林、农田、道路、野外等不受实验室运动捕捉空间限制的真实环境。普通室内房间、飞行场馆、实验室搭建障碍场不计为开放环境。
- “未明确”表示原论文正文没有给出足够信息，不能据此推断使用或未使用某种设备。
