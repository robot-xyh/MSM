# 智能化火指控外场试验建议与方案

## 一、试验目的

外场试验围绕双光电侦察定位、区域协同搜索、目标任务分配、中心航迹与拦截无人机目标关联以及末段接近控制开展，重点检验各环节在真实飞行、真实通信和实际光照条件下能否连续工作。试验不以单次接近结果作为唯一依据，而是考察从目标发现、航迹形成、任务下达、机载搜索到人工接管脱离的全过程，形成可复核的飞行记录，为后续扩大目标数量和拦截无人机规模提供依据。

## 二、场地与设备配置

试验场地应具备明确的空域边界、起降区、目标活动区、拦截接近区和安全隔离区。目标航线与拦截航线分区规划，现场设置总指挥席、光电操作席、无人机操纵席和安全观察岗位。

首轮试验建议配置两套地面光电设备、2至6架拦截无人机和4至12架目标无人机。两套地面光电完成目标角航迹关联与交汇定位；拦截无人机依据中心下发的粗略位置和航迹进入指定视场区，通过机载光电搜索并建立本地目标航迹。规模验证可采用实飞平台与数字目标联合方式，将目标数量逐步扩展至20、60、100和200，重点检验任务分配、通信负载和计算能力，不以数字目标替代真实飞行验证。

近距试验应增设独立测距手段和接触检测装置。0.01米量级的距离判定不能仅依赖卫星定位，应采用近距测距设备、机体接触检测装置或两者组合确认。无人机可能接触的部位应设置轻质防护结构，并避开螺旋桨、动力系统、相机和飞控设备。

    D --> E[中心航迹与机载航迹关联]
    E --> F[目标任务分配]
    F --> G[末段接近]

    I --> J[人工立即脱离]

每个阶段通过后再进入下一阶段。设备参数、软件版本、地图、标定结果和安全边界在正式架次前冻结；现场如需修改，应形成新的试验版本并重新完成地面检查。

## 四、分阶段试验安排

### （一）设备标定与单机检查

完成双光电内外参数、设备位置、方位零位和时间同步标定，检查无人机定位、姿态、云台角度、图像时间戳和通信链路。通过静止目标和低速目标验证像素坐标、空间视线和目标方位计算是否一致。近距测距装置应在0.5米和0.01米附近分别进行多次静态标定，记录测量误差和触发稳定性。

### （二）双光电侦察定位

目标无人机按预定航线进入两套光电共同观测区域。两套光电分别形成单站角航迹，经时间对齐、候选筛选和一一关联后，利用两条空间视线进行交汇定位。试验由单目标开始，逐步增加至4、8和12个实飞目标，考察目标交叉、短时漏检和扫描重访条件下的航迹连续性。

本阶段记录单站航迹精度与覆盖度、双站目标关系精度与覆盖度、交汇定位误差、身份切换次数和处理周期。存在明显错误关联时，不向后续拦截环节下发该航迹。

### （三）区域协同搜索

中心根据目标位置、速度和预测误差范围生成搜索区域，并结合拦截无人机位置、剩余航程和相机视场完成区域分配。拦截无人机进入责任区域后，按确定的方位顺序进行云台扫描；发现目标后转入局部跟踪，未发现目标则依据最新预测滚动调整搜索区域。

试验分别设置目标预测准确、目标发生横向偏移和短时通信中断等情况，统计首次发现时间、规定时间内发现目标比例、重复搜索比例和未完成搜索的目标数量。首轮外场仍采用可解释的概率网格、扇区分配和滚动扫描方法，学习算法仅用于后续对照，不直接控制安全边界。

### （四）中心航迹与机载目标关联

中心将目标位置和预测轨迹转换到拦截无人机机体系、云台系和图像平面，给出预计出现位置和允许误差范围。机载相机在该范围内形成局部航迹，再根据观测时刻、像面位置、运动方向和多帧连续性完成一一关联。位置、姿态和云台角度必须采用图像曝光时刻的数据，不能使用消息到达时刻的数据。

试验按20个目标配30架拦截无人机、40个目标配50架拦截无人机的规模逐步扩展。实飞数量不足时，可将未实飞目标作为数字航迹接入任务分配和通信链路，但中心与机载图像关联的核心结果应以真实相机观测为准。

### （五）任务分配与末段接近

在目标和拦截无人机一一对应的前提下，以预计到达时间、剩余航程、视觉锁定质量和航迹冲突作为主要代价，采用匈牙利算法或最小费用流完成任务分配。任务下达后携带版本、生成时间和有效期，拦截无人机只执行当前有效计划。目标航迹更新、视觉丢失或飞行资源异常时，只调整受影响的任务关系。

末段接近采用现有比例导引或视觉导引方法，飞控保持姿态和速度基本稳定。试验重点验证目标持续位于相机视场内、接近方向可控、不同无人机航迹不发生危险交叉，以及人工能够在规定距离内顺利接管并脱离。

## 五、近距告警、人工接管与脱离

当相对距离缩小至0.5米时，系统发出声光告警，提示操纵员进入接管准备状态。自主程序继续维持原有控制，不增加新的近距机动动作。

当相对距离缩小至0.01米时，操纵员开始接管。程序停止继续逼近，仅完成控制权转交、状态监视和数据记录，随后由操纵员结合现场态势立即实施脱离。人工接管后，程序不再自动修正航迹，仅保留姿态失稳、动力异常或人工链路丢失情况下的飞控保护。

试验允许在防护部位发生受控轻接触。自主算法成绩统计至0.01米接管触发时刻；人工接管后的轻接触情况、操纵输入、脱离时间和最小间距单独记录，不与自主接近指标混合计算。任一测距来源失效、距离信息相互矛盾或人工链路不稳定时，不进入近距阶段。

## 六、试验场景与架次

| 类别 | 主要场景 | 建议安排 |
|---|---|---:|
| 设备联调 | 静态目标、低速单目标、时间同步与坐标检查 | 每项3至5次 |
| 双光电定位 | 单目标、多目标、交叉航迹、短时漏检 | 每类不少于10个有效架次 |
| 协同搜索 | 准确线索、偏移线索、局部漏搜、通信延迟 | 每类不少于10个有效架次 |
| 航迹交接 | 中心预测进入机载视场、多个相邻目标、局部航迹交叉 | 每类不少于10个有效架次 |
| 任务分配 | 目标数量变化、无人机退出、计划更新 | 每类不少于10个有效架次 |
| 末段接近 | 正常接近、目标机动、视觉短时丢失、人工接管脱离 | 每类不少于10个有效架次 |

每类基础场景先安排3至5个调试架次，确认设备与流程稳定后再计入正式结果。正式场景建议不少于30个有效架次；未满足预设进入条件、因场地原因中止或数据记录不完整的架次应注明原因，不计入有效架次。

## 七、评价指标

| 环节 | 主要指标 |
|---|---|
| 双光电侦察 | 单站航迹精度与覆盖度、双站关联精度与覆盖度、定位误差、身份切换次数 |
| 区域搜索 | 首次发现时间、规定时间内发现目标比例、重复搜索比例、漏搜目标数 |
| 中心与机载关联 | 航迹关系精度、目标平均纯度和完整度、正确形成独立目标簇的比例、身份混合目标数、未完成配准目标数 |
| 任务分配 | 正确任务关系、任务切换次数、重新分配时间、未分配目标数、航迹冲突次数 |
| 末段接近 | 目标保持时间、接近误差、最小机间距离、人工接管触发误差、安全中止次数 |
| 人工脱离 | 接管响应时间、脱离完成时间、轻接触情况、操纵输入和异常情况 |

评价结果按目标数量、飞行条件和干扰条件分别统计，不将不同试验配置的数据混为一组。仿真、数字目标联合试验和真实飞行结果分别列示。

## 八、数据记录与复核

每个架次统一记录相机原始视频、检测结果、单站航迹、双站关联关系、交汇定位结果、任务分配计划、无人机位置姿态、云台角度、控制指令、通信状态、告警信息、人工接管信号和安全事件。所有数据使用统一时钟或保存可追溯的时间偏差。

架次结束后自动生成摘要，现场确认关键数据是否完整。正式结论应能够回溯到具体日期、场景、软件版本、设备标定文件和原始记录。发生错误关联、目标漏搜、计划冲突或异常接近时，应保存前后完整时间窗的数据，单独开展复盘。

## 九、现场组织与停止条件

总指挥负责决定试验开始、暂停和终止；光电操作员负责设备工作状态；无人机操纵员分别负责目标机和拦截机；安全观察员独立监视空域边界、人员活动和飞行间隔。人工接管岗位在近距试验全过程保持专人值守。

出现以下任一情况时立即停止当前架次：

1. 无人机越出批准空域或接近人员、车辆及无关设备；
2. 人工控制链路、近距测距、关键图传或飞控状态异常；
3. 目标身份不明确、任务版本冲突或两架无人机进入同一危险接近区域；
4. 风速、能见度、照度或卫星状态超出当日试验条件；
5. 0.5米告警未正常触发，或0.01米人工接管信号不可信；
6. 总指挥、操纵员或安全观察员认为继续试验存在风险。

## 十、实施周期建议

首轮外场建议安排12至15个有效试验日：前2至3日完成场地测绘、设备架设和标定；随后3至4日完成双光电定位与区域搜索；3至4日完成中心航迹与机载航迹关联和任务分配；最后2至3日完成末段接近、人工接管与脱离验证。每日试验结束后完成数据备份和问题复核，关键问题未关闭前不进入下一阶段。

首轮试验完成后，根据实测误差、航迹连续性、通信时延和人工接管表现调整参数，再开展扩大规模和复杂条件试验。后续试验重点增加多目标交叉、无人机退出、通信中断和目标机动等情况，逐步形成可重复的外场验证方法。
