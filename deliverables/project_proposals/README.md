# 项目建议书

本目录收纳三个相互衔接的项目建议书。资料与事实证据截止日期为 2026 年 7 月 19 日。文中技术指标属于建议验收目标，已有能力、仿真证据和待建能力分别标注，不以仿真结果替代半实物、外场或装备验收结果。

## 文档目录

- 无人机协同探测项目建议书：[Markdown](./无人机协同探测项目建议书.md)｜[Word](./无人机协同探测项目建议书.docx)。研究地面与空中异构传感器协同观测、时空统一、多目标关联、高空机动补盲和全局航迹维护。
- 无人机协同拦截项目建议书：[Markdown](./无人机协同拦截项目建议书.md)｜[Word](./无人机协同拦截项目建议书.docx)。研究威胁排序、滚动分配、三级协同、末端视觉配准、中末段导引和安全门控。
- 大模型辅助评估项目建议书：[Markdown](./大模型辅助评估项目建议书.md)｜[Word](./大模型辅助评估项目建议书.docx)。研究本地大模型在离线日志分析、失败分类和报告草拟中的应用，正式指标仍由确定性程序计算。

## 使用说明

1. 项目申报前应按申报指南复核篇幅、经费口径、考核周期和指标数量。
2. 设备性能、通信能力和外场效果应在设备选型或基线试验后更新，不能直接采用建议指标作为现状数据。
3. 总体技术方案图采用高分辨率 PNG，可直接插入 Word。转为 Word 或 PDF 后仍需检查图片宽度、分页和图中文字。
4. 修改 Markdown 或总体技术方案图后，运行 `python3 deliverables/project_proposals/build_word.py` 重新生成三份 Word。
