# 交付文档集

本目录收纳面向方案论证、项目汇报和背景研究的可交付文档。项目源码、模块评审和实验原始输出仍分别保存在 `research_modules/`、`subagent_reviews/` 和各实验输出目录中。

## 目录

- `leadership_report/`：体系方案与阶段进展报告，包含 Markdown 源文档、生成脚本、证据清单和发布版 Word/PDF。
- `background/`：威胁、探测、指控、拦截和验证背景材料。章节稿与分册稿分别保留，不能混作同一套定稿。
- `system_improvement_argument/`：体系改进论证图及其适用范围说明。

## 使用原则

1. 报告中的“已实现”“已测试”必须能追溯到当前代码、测试命令或实验产物。
2. 设备性能、探测距离、天气衰减和作战效果等缺少本项目实测证据的内容，只能标为建议指标、背景假设或待验证项。
3. AirSim 和质点模型结果属于仿真证据，不表述为实飞或设备验收结果。
4. 生成报告时以 Markdown 和生成脚本为源，Word/PDF 是发布产物。
