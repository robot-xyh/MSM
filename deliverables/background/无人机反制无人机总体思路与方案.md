# 无人机反制无人机总体思路与方案

## 一、任务定位

低慢小无人机具有目标特征弱、飞行高度低、航迹变化快和单机成本低等特点。固定式防空装备在城市、山地和重要设施周边容易受到视距、杂波和附带损伤约束。面对多方向、多批次来袭目标，单一探测设备或单一拦截手段难以持续维持态势和处置能力。

本项目拟研究“以无人机反制无人机”的体系方案。地面雷达、光电、声学等设备负责早期发现和连续跟踪，高空侦察无人机补充区域图像和通信覆盖，多架拦截无人机按任务分配实施机动拦截。系统采用中心指挥、二级接管和完全分布式协商三级结构，形成从发现、跟踪、分配到末端确认和效果评估的闭环。

该方案适合要地周边和临时任务区域。拦截无人机可从不同方向接近目标，根据威胁程度采用单机拦截、多机协同或主备配置。处置载荷可根据任务条件选用阻拦网、碰撞式拦截器或其他经授权设备。本阶段研究集中在感知、决策、协同和导引，不预设具体毁伤装置已经完成集成。

## 二、体系组成

系统由中心节点、区域探测设备、高空侦察无人机、拦截无人机和评估节点组成。

| 组成 | 主要任务 | 信息关系 |
|---|---|---|
| 中心节点 | 汇总全局态势，维护目标编号，评估威胁，发布资源分配计划 | 接收雷达、光电和节点状态；向二级节点及拦截无人机发布带版本的任务 |
| 区域探测设备 | 提供目标位置、速度、方位、类别提示和观测误差 | 所有观测保留测量时间、到达时间、坐标基准和协方差 |
| 高空侦察无人机 | 提供高视角图像、局部目标线索和通信中继；中心失效后承担区域协调 | 与中心和拦截无人机传输数据，按需向执行节点发送图像或目标框线索 |
| 拦截无人机 | 执行中段接近、末端视觉确认和比例导引 | 接收当前分配和全局航迹，回传本机状态、局部视觉航迹和任务结果 |
| 评估节点 | 记录探测、跟踪、分配、降级、配准、导引和安全事件 | 独立消费日志，不参与在线目标身份和任务授权 |

中心节点维护规范的全局目标编号。拦截无人机只能执行当前有效计划，不能根据局部图像自行改绑目标。每份分配计划均带有版本号和有效期，旧版本在通信恢复或节点切换后自动失效。该约束用于减少多机重复拦截、目标漏分配和友方误判。

## 三、运行流程

系统运行流程为：

**异构观测采集 → 时间与坐标统一 → 全局航迹生成 → 目标身份关联 → 威胁评估 → 资源分配 → 中段比例导引 → 末端视觉配准 → 视觉比例导引 → 效果评估与重规划。**

雷达构成中远距离跟踪骨架。融合模块将雷达位置、声学方位和光电检测转换到北东地坐标系，依据距离、遮挡、杂波和量测时延调整协方差。数据关联模块根据运动一致性、类别线索和量测新鲜度维持目标编号，目标交叉或短时漏检时保留身份连续性。

资源分配采用滚动优化。代价由接近时间、航迹不确定性、目标威胁、资源剩余能力、视场条件和资源冲突共同构成。计划只有在收益达到设定门限并满足最小保持时间后才进行切换。高威胁目标可配置两架主拦截无人机和一架备用无人机。当前研究优先保证任务成员、计划版本和执行顺序一致，同时到达控制列为后续验证内容。

拦截无人机在中段根据全局航迹实施比例导引。进入相机有效作用范围后，系统把目标预测位置和协方差投影到各机图像平面，与局部目标框和运动历史进行匹配。匹配唯一、连续稳定、身份无冲突且飞行机动余量满足要求时，导引切换到末端视觉信息。目标不唯一、友方身份重叠、图像中断或计划版本不一致时，执行保持、重新搜索或请求重规划。

## 四、协同与降级

中心节点正常时负责全局分配，高空侦察无人机提供区域图像、目标线索和通信中继。局部视觉结果与中心计划一致时继续执行。航迹误差增大、计划过期或末端匹配持续不一致时，系统先请求中心重新计算，并可调用高空侦察无人机补充观测。

中心节点失效后，具备有效航迹、资源状态和通信覆盖的高空侦察无人机接管局部协调，发布新的计划所有者和版本。中心与二级节点均不可用时，拦截无人机交换压缩后的航迹摘要、资源状态和任务出价，在限定区域内形成临时分配。缺少必要成员确认、通信租约过期或节点间结果冲突时停止任务切换。中心恢复后按时间范围和计划版本进行保守合并。

拦截无人机之间允许交换航迹摘要和任务状态。视频数据采用按需定向传输，优先保障控制指令、位置状态、计划版本和安全事件。该通信分层可减少多路视频对无线链路的占用，并为通信丢包、时延和网络分区试验保留明确接口。

## 五、技术重点

一是异步多传感器融合。系统分开记录观测发生时间和数据到达时间，处理延迟观测和坐标转换误差。每条观测和航迹携带协方差，后续关联、分配和末端门限使用同一套不确定性信息。

二是多目标身份保持。近期采用全局最近邻和匈牙利算法满足实时运行，密集交叉和长时间遮挡场景预留联合概率数据关联及多假设跟踪对照。身份交换次数作为强制指标进入系统评估。

三是多资源滚动分配。系统支持资源数和目标数不相等的场景，也支持一个高威胁目标由多架无人机协同拦截。计划迟滞、版本控制和主备关系共同限制频繁重分配。

四是多相机末端配准。各相机独立形成局部视觉航迹，再由全局航迹投影、目标框位置和尺度变化、运动方向及时间一致性完成跨视角配准。高空侦察图像作为辅助证据，不能替代规范目标编号。

五是受约束导引。中段使用雷达航迹比例导引，末段使用目标视线变化进行视觉比例导引。切换条件同时检查视觉稳定性、目标距离、闭合速度、相机可见性和无人机机动能力。

## 六、研究基础与预期成果

项目已完成多传感器融合、目标关联、资源分配、分级降级、末端视觉配准、比例导引和指标评估的算法原型。现有流程已在质点模型、AirSim计算机视觉模式和SimpleFlight飞行模式中进行接口与场景验证，覆盖目标交叉、资源与目标数量不等、中心失效、二级接管、局部视场缺失和多机拦截等情况。

当前结果用于验证信息流、状态机和算法衔接。真实雷达误差、光电识别距离、无线通信容量、机载计算时延、飞行平台机动边界和实际处置效果仍需通过设备选型、半实物试验和靶场试验确定。申报阶段不宜将仿真参数直接写成装备指标。

项目拟形成综合反制指挥控制原型、无人机协同拦截算法组件、统一数据与通信接口、典型场景库、数字孪生与半实物验证环境以及系统评估方法。后续试验按“单模块标定—分系统联调—多机闭环—通信与故障注入—第三方测试”推进，逐步冻结探测距离、识别距离、稳定跟踪距离、反应时间和有效处置距离。
