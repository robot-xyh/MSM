# 背景材料

背景材料用于形成任务假设、指标候选和体系方案，不直接代表项目已实现能力。

## 内容分组

- `无人机综合反制装备能力与发展现状项目申报调研.md`：装备现状、研究问题和申报指标调研。
- `无人机反制无人机总体思路与方案.md`：以无人机反制无人机的申报方案简稿。
- `无人机反制无人机能力提升专题.md`：能力提升专题的目的、内容、指标与技术途径。
- `200V200_强化学习与图神经网络能力增强综合方案.md`：200对200确定性基线、D3与D4强化学习、D5跨视角图网络和主动视觉的综合方案及当前证据。
- `200V200_三维全流程程序综合方案.md`：200对200三维程序架构，覆盖D1至D7确定性主线、区域与目标分配、降级接管、跨视角配准、学习增强、安全回退、实验设计和当前证据。
- `大模型辅助自动评估与报告生成方案.md`：本地大模型日志分析、失败分类和报告生成方案。
- `chapters/`：按章组织的体系论证稿。
- `booklets/`：按专题分册组织的资料稿。
- `source/`：原始 Word 资料。

章节稿和分册稿存在内容重叠，当前均作为来源保留。后续引用时应注明采用的版本，并核对相互冲突的假设。声学阵列是否纳入基线、雷达距离与精度、命中率、技术成熟度、极端天气衰减和自治边界均属于待冻结事项；当前系统 D1 仍保留声学方位与声纹提示接口。
