5. **怎么区分敌我？**（第三章）——IFF五层递进识别，每层失效自动降级。

6. **侦察图像能否回传拼图？**（第四章）——R型机回传→地面站全景拼接→操作员态势GUI方案。

## 第一章 Ku波段雷达与X波段对比论证

### 1.1 为什么选Ku——三维物理对比

Ku波段（12-18GHz，典型16GHz，λ≈1.875cm）与X波段（8-12GHz，典型10GHz，λ≈3.0cm）的核心差异体现在三个物理维度：

#### 维度一：小RCS目标散射增强

对于固定翼无人机（翼展0.75-3.1m），在Ku波段（λ=1.875cm）处于**光学区/谐振区过渡**（d/λ≈40-165），RCS趋于物理截面稳定值。Ku波段的优势在于：表面粗糙度灵敏度更高，机身的铆钉、接缝等毫米级特征在Ku波段产生额外绕射反射，RCS波动幅度±3-5dB。

经验估算：Ku波段对Shahed-136级目标（标称RCS=0.01m²）的探测距离增益约为X波段的**1.15-1.25倍**（等效增益0.6-1.0dB），取保守值1.2倍。注意不适用瑞利区σ∝(d/λ)⁴的6.55倍——该公式仅对球形瑞利散射体成立。

#### 维度二：角度分辨率

同口径天线（D=1.2m），半功率波束宽度θ_3dB≈1.22λ/D：

| 参数 | X(10GHz) | Ku(16GHz) | Ku/X比 |
|:---:|:---:|:---:|:---:|
| 波束宽度 | 1.75° | 1.09° | **62%** |
| 10km处方位分辨率 | 305m | 190m | 62% |

Ku的角度精度比X高38%，对光电预置引导更精确——直接影响2.5秒光电锁定时间链的可靠性。

#### 维度三：大气衰减——Ku的致命弱点

根据ITU-R P.676建议书：

**表1-1：X波段与Ku波段大气衰减全量化对比**

| 气象条件 | X单程(dB/km) | Ku单程(dB/km) | X双程10km(dB) | Ku双程10km(dB) | X保留率 | Ku保留率 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 晴天 | 0.012 | 0.018 | 0.24 | 0.36 | 99.9% | 99.8% |
| 小雨(1mm/h) | 0.02 | 0.05 | 0.4 | 1.0 | 97.7% | 94.4% |
| 中雨(4mm/h) | 0.08 | 0.25 | 1.6 | 5.0 | 91.2% | 75.0% |
| **大雨(16mm/h)** | **0.30** | **1.0** | **6.0** | **20.0** | **70.8%** | **31.6%** |
| 暴雨(50mm/h) | 0.60 | 2.5 | 12.0 | 50.0 | 50.1% | 5.6% |

> **公式**：R_new/R = 10^(−L_two_way_dB/40)，其中L_two_way=2×α×R。
> **Ku大雨验证**：L=2×1.0×10=20dB → R_new=10^(-20/40)=0.316 → **3.16km**。
> **X大雨验证**：L=2×0.3×10=6dB → R_new=10^(-6/40)=0.708 → **7.08km**。

**关键结论**：Ku在大雨（16mm/h）下探测距离从10km压缩至3.16km（缩减68.4%），这是本体系在大雨下必须依赖被动节点光电（MWIR在5km处透过率约0.44→识别距离约3.32km）和X波段体系支援的根本原因。

### 1.3 EO光电转塔：30目标/18秒推导

**物理推导——逐秒拆解**：

```
步骤1：周扫探测（宽视场，150mm焦距，FOV 5.87°×5.87°）
  周扫速度400°/s → 360°完整一圈=0.9s
  30个目标均匀分布360°→相邻目标平均12°→掠过12°需0.03s
  MWIR积分1-2ms→每帧33ms@30fps→每目标至少可采集1帧

步骤2：宽视场捕获（300mm焦距）
  雷达预置角度引导光电转向目标（伺服206ms到位）
  300mm FOV=2.93°→5km处覆盖256m×256m
  雷达方位误差0.3°→5km处仅26m<<FOV 256m→目标一定在内
  MWIR检测热源斑点→背景抑制+CFAR→约0.15s/目标

步骤3：窄视场凝视确认（600mm焦距）
  FOV=1.47°→5km处覆盖128m×128m
  Shahed-136(翼展2.9m)@5km@600mm→IFOV 0.025mrad→23.2像素
  Johnson识别>20像素→可识别 ✓
  2帧确认(含AI YOLOv8-m<10ms)→约0.15s

步骤4：激光测距(1.5μm人眼安全)→约0.1s

单目标总耗时=0.15+0.15+0.1+0.15(伺服余量)+0.05(处理开销)=0.60s
30目标×0.60s=18秒（含伺服加减速余量）
```

> **30目标/18秒的物理约束**：瓶颈不在伺服转速（400°/s高端），而在MWIR帧率（30fps）/AI推理延迟（BM1688<10ms可忽略）/激光测距重频（~10Hz）。18秒是保守设计值，极限可达10.5秒（仅分类不识别）。

## 第二章 公式2：战场侦察节点部署几何→打击指标闭环

### 2.1 公式2的定位

公式1（分册1）是"从探测到导引头"的**线性**指标闭环。公式2是从"战场空间"角度反向求解——**先确定节点间距的几何上下界，然后代入极端天气衰减，验证最坏情况下公式1全链是否仍然闭合**。

```
┌────────── 公式2：战场部署→打击指标闭环 ──────────┐
│                                                       │
│ ① 部署间距上限 → d_max ≤ R_EO × cos(α/2)             │
│    被动节点EO=5km, R型=2.5km, 重叠角α=63°(30%重叠)   │
│    d_max(EO主导)=5.0×cos(31.5°)≈4.26km               │
│    d_max(R型主导)=2.5×cos(31.5°)≈2.13km              │
│    ↓                                                   │
│ ② 极端天气探测缩减 → R'_EO = R_EO × √T_atm           │
│    大雨MWIR T≈0.44→R'≈3.32km(EO)/1.66km(R型)         │
│    d_max(大雨)=3.32×cos(31.5°)≈2.83km                 │
│    菱形边长=2.83×√2≈4.00km, 节点距中心≈2.83km        │
│    ↓                                                   │
│ ③ 火力解算（套用公式1-③）→ t_fire(大雨)              │
│    R_detect(Ku大雨)=3.16km, t_window=3,160/51.4=61.5s  │
│    OODA 12+助推2+冲刺15=29s→仅剩32.5s巡航              │
│    迎头Vrel=120.8→32.5s闭合3,926m>剩余~400m ✅         │
│    尾追Vrel=18.0→32.5s闭合585m→**尾追不可行！**        │
│    ↓                                                   │
│ ④ 大雨拦截结论：**必须迎头**，命中率70-80%，消耗比2:1  │
│    节点间距从7.07km缩至~4.0km                            │
│    5-6个节点替代原4个节点（见分册6）                     │
│    ↓                                                   │
│ ⑤ 中末制导交接（大雨）：MWIR T=0.44→R型识别~1.1km     │
│    中制导精度σ≈100m, 导引头FOV覆盖半径295m              │
│    σ=100<197(余量1.5×)→**交接勉强闭合**                 │
│    ↓                                                   │
│ ⑥ 末端命中（大雨）：AI 55帧+红外衰减→命中率60-70%      │
│    X3近炸引信容错为最后保障                              │
│    ↓                                                   │
│ ⑦ 大雨下效能判定：**可作战但降级至60-70%**               │
│    永不归零（降级不归零设计的实战验证）                   │
└───────────────────────────────────────────────────────┘
```

### 2.2 正常天气部署间距几何推导

被动节点EO识别距离5km（600mm焦距，Johnson识别级≥20像素），4节点菱形部署（正方形四角）：

- 菱形边长（节点间距）= 5×√2 ≈ **7.07km**
- 相邻覆盖重叠：7.07<5+5=10km→两个覆盖圆重叠 ✅
- 重叠率≈(10−7.07)/5=58.6%→至少2节点同时覆盖 ✅

**三条拦截线**：
| 拦截线 | 距中心 | 方式 | 说明 |
|:---:|:---:|------|------|
| 第一道(远界) | 15km(5+10) | 主车Ku雷达迎头拦截 | 雷达10km+d=5km |
| 第二道(中界) | 10km(5+5) | 被动节点EO识别+迎头 | EO 5km→引导F型迎头 |
| 第三道(近界) | 7.5km(5+2.5) | 尾追补刀 | R型机前出引导占位 |

### 2.3 大雨下部署重算

## 第三章 IFF敌我识别五层融合

### 3.1 五层递进架构

```
L1 合作式微型应答机 → 通过→"友方"(99%)；未通过→L2
L2 红外LED编码闪烁 → 通过→"友方"(95%)；未识别→L3
L3 飞行包线匹配   → 匹配→"可能友方"(90%)；异常→L4
L4 航迹约束       → 在友方航路内→"可能友方"(85%)；未知→L5
L5 上级空情图      → 接入交叉确认(按需)；不可用→输出"未知"
```

每层失效自动降级至下一层，永不陷入"无法识别"的死锁。各层识别率：L1≥99%、L2≥95%、L3≥90%、L4≥85%、L5按体系融合。

### 3.2 各层机制简述

**L1-应答机**：<0.5g SMD微型应答机，868MHz AES-128滚动码，5km范围内SNR>20dB，防重放。

**L2-红外LED**：尾翼850nm LED阵列，16bit编码（65,536种组合），10Hz闪烁，2-3周期解码（0.2-0.3s）。

**L3-飞行包线**：特征向量{速度/高度/航向/加速/转弯}，随机森林分类器（100棵树，8维）。友方拦截弹（发射后111m/s→巡航69m/s），敌方Shahed（51.4m/s匀速，100-4,000m）→特征空间分离度>3σ。

**L4-航迹约束**：已知友方航线库匹配，最小距离>阈值（3σ+500m缓冲区）→判定为敌。

**L5-上级空情图**：接入联合防空C4I系统，交叉确认。

> **诱饵处理**：五层IFF完成后，输出五级置信度（敌/我/中/诱饵/未知）。诱饵标记依据微多普勒（无活塞发动机振动分量的滑翔体→L3飞行包线异常）、红外分布（无排气管热点→L2/L3特征异常）、可见光纹理（简化结构→光电图像分类）。**诱饵识别为"敌"子类**——必须拦截（用户明确要求1:1硬拦截）。

## 第四章 侦察图像回传与地面站全景拼接

### 4.1 回传链路

R型侦察指挥机通过L2侦指链（5Mbps）向地面站回传图像：

| 参数 | 值 | 说明 |
|:---:|:---:|------|
| 回传周期 | 3秒/帧 | 与光电搜索周期匹配 |
| 图像规格 | 640×480，JPEG压缩 | ~100KB/帧（压缩后） |
| 带宽占用 | 100KB/3s≈267kbps | 远小于5Mbps上限 |
| 剩余带宽 | >4.7Mbps | 供航迹/遥测/火力指令共用 |

**4架R型共占用≈1.07Mbps**，L2侦指链充裕。

### 4.2 地面站全景拼接方案

**算法流程**：
1. **ORB特征提取**：对相邻扇区回传的红外图像提取Oriented FAST关键点+BRIEF描述子（BM1688 NPU加速，<5ms/帧）
2. **特征匹配**：BRUTE-FORCE Hamming距离匹配+RANSAC剔除外点
3. **单应矩阵估计**：至少4对匹配点→计算Homography矩阵H（3×3），将一帧变换到另一帧坐标系
4. **图像拼接**：重叠区多频段融合（Laplacian金字塔），消除拼缝
5. **叠加航迹GUI**：在拼接全景图上叠加融合航迹（10Hz更新，显示目标ID/距离/速度/威胁等级），操作员获得360°实时态势全景

**处理延迟**：拼接≤200ms，全景显示延迟<1s（含拼接+渲染），满足<12s OODA中的观察阶段需求。

## 第五章 结论与待验证项

### 5.1 本册核心结论

1. **Ku波段是正确选择**——对小RCS目标和角度精度优于X波段，但大雨是致命弱点（3.16km），必须依赖双模互补。

2. **30目标/18秒**：EO光电转塔在物理上可实现，瓶颈在MWIR帧率而非伺服转速。

3. **公式2闭环**：正常天气下4节点菱形部署（间距7.07km）满足三条拦截线全覆盖；大雨下节点间距缩至~4km，需增加至5-6节点（详见分册6极端天气方案）。

4. **X/Ku/光电大雨互补**：Ku晴天主力（80%日），X波段体系支援（大雨），纯光电+前出R型（暴雨）——气象自适应是唯一可行路径。

5. **IFF五层永不归零**：诱饵必须拦截，识别为"敌-诱饵"子类后执行1:1消耗比。
