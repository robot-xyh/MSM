## 第一章 威胁目标全参数矩阵与公式1

### 1.1 排序逻辑

按目标巡航/攻击速度**由低至高**排列。速度是第一决策变量——尾追拦截前提 Vi > Vt。前13型目标均可尾追，后3型（Lancet-3俯冲/ Geran-4 / Shahed-238）须迎头/侧方/多角度围捕。速度升序使指挥员从上到下直观判断各目标的拦截策略选择空间。

### 1.2 公式1：侦察→火力→导引头 指标闭环链

公式1是整个体系论证的**核心骨架**——它将"能探测到→能识别到→能打到→能命中"的物理链形式化为一组可验证的数学关系：

`
┌────────────── 公式1：侦察+火力拦截+导引头指标闭环 ──────────────┐
│                                                                   │
│  ① 雷达探测 → R_detect = f(P_t, G, λ, σ, SNR_min)               │
│     输出：(R_detect, σ_方位, σ_俯仰, σ_距离)                     │
│     ↓                                                             │
│  ② 光电精确认 → R_EO = f(D_aperture, λ_IR, NETD, Johnson_n)     │
│     输出：(R_EO_识别, σ_EO_角, 激光测距σ)                        │
│     ↓                                                             │
│  ③ 火力解算 → t_fire = t_OODA + t_boost + t_sprint + t_cruise   │
│     t_OODA = 6s(雷达两圈) + 4s(AI+否决) + 2s(发射) = 12s         │
│     t_boost = 2s (500Ns→80m爬升, v₀=80m/s)                       │
│     t_sprint = 15s (v=111m/s, 冲刺加速)                          │
│     t_cruise = f(R_remaining, Vrel)                               │
│     ↓                                                             │
│  ④ 拦截几何选择 → mode = f(d_target, v_target, ΔV, 窗口压力)    │
│     决策矩阵：{迎头(θ=0°), 偏迎头(θ=30°), 侧方(θ=90°),          │
│              偏尾追(θ=150°), 正尾追(θ=180°)}                      │
│     ↓                                                             │
│  ⑤ 中制导精度 → σ_midcourse = f(更新率, 测角精度, 距离精度, 时延)│
│     σ_midcourse < FOV_seeker × R_handoff × k_safety (k≥1.5)      │
│     ↓                                                             │
│  ⑥ 导引头FOV余量 → FOV_seeker=30°, R_handoff=2km                  │
│     覆盖半径 = R_handoff × tan(FOV/2) = 2000×tan(15°) = 536m     │
│     需求：σ_midcourse < 536m / 1.5(安全余量) = 357m              │
│     ↓                                                             │
│  ⑦ 中末制导交接 → 中制导误差 < 导引头FOV覆盖半径 × 余量          │
│     σ_midcourse_total = √(σ_雷达²+σ_EO²+σ_IMU²+σ_数据链²)       │
│                         = √(30²+20²+50²+15²) ≈ 65m               │
│     65m << 357m → 闭合适过✅ (5.5倍余量)                         │
│     ↓                                                             │
│  ⑧ 末端命中：弹载AI(BM1688 YOLOv8-m<10ms) → Kalman预测 → 撞击    │
│     命中率 = f(n_AI_frames, 过载余量, X3复合模式)                │
└───────────────────────────────────────────────────────────────────┘
`

**公式1的物理意义**：八个环节中任一环节的指标不闭合，整个链条就断裂。反向看——导引头FOV决定了中制导精度的上限，中制导精度决定了光电精确认的距离下限，光电识别距离决定了雷达必须探测到的最远距离底线。这是**从末段往回推的指标分配方法论**。

**具体代入实例（以Shahed-136为例）**：
- ①雷达：Ku波段，10km@σ=0.01m²，σ_方位=0.3°, σ_距离=10m
- ②EO：1024×1024 MWIR+600mm，5km识别(Johnson~23pixels)，σ_角=0.1mrad
- ③火力解算：
  - t_OODA=12s → 目标位移=51.4×12=616.8m
  - t_boost=2s → 目标位移=51.4×2=102.8m
  - t_sprint=15s → Vrel(迎头)=162.5m/s, 闭合=2,438m
  - Remaining cruise=10,000-616.8-102.8-2,438=6,842m, @120.8m/s=56.6s
  - Total=12+2+15+56.6=85.6s < 194s窗口 ✅
- ④几何选择：Vt=51.4<60m/s低速→优先尾追；距离<5km→迎头也可（相对速度高）
- ⑤中制导精度：65m
- ⑥导引头FOV：30°→536m覆盖半径
- ⑦交接：65m << 357m(安全) ✅

### 2.2 500Ns/2s助推物理推导

**给定**：总冲500Ns，工作时间2s，弹体质量5kg。

**推导**：
- 平均推力 F_avg = 500/2 = 250N
- 弹体净加速度 a_net = F_avg/m − g = 250/5 − 9.8 = 40.2 m/s²
- 助推末速 v_boost = a_net × t = 40.2 × 2 = **80.4 m/s**（约290 km/h）
- 竖直爬升高度 h_boost = ½ × a_net × t² = ½ × 40.2 × 4 = **80.4m ≈ 80m**
- 水平位移（假设45°发射角）：d_水平 = h_boost ≈ 80m（可忽略不计入航程）

**对比旧版**：
| 参数 | 旧版(500g×3s→400m) | 新版(500Ns×2s→80m) | 影响 |
|------|:---:|:---:|------|
| 助推时间 | 3s | 2s | OODA+缩短1s |
| 爬升高度 | 400m | 80m | 需要冲刺段补爬升 |
| 末速 | ~261m/s(不合理) | **80m/s** | 更合理，与冲刺111m/s衔接 |
| 水平贡献 | 计入400m | 忽略(~80m) | 航程重算 |

**关键工程含义**：助推末速80m/s已接近巡航速度(69m/s)——通过冲刺段（111m/s/15s）进一步提升至拦截速度后，转入巡航。

### 2.3 冲刺15s航程贡献

冲刺段Vrel（迎头）= 111.1 + 51.4 = **162.5 m/s**
冲刺段闭合距离 = 162.5 × 15 = **2,438 m**

冲刺段Vrel（尾追）= 111.1 − 51.4 = **59.7 m/s**（注意：69.4−51.4=18.0m/s是巡航段Vrel[尾追]，冲刺段使用59.7m/s）
冲刺段闭合距离(尾追) = 59.7 × 15 = **895 m**

## 第三章 12秒OODA时序论证

### 3.1 为什么是12秒？

OODA=12s是**物理约束叠加计算**的结果，不是任意值。本节逐秒分解12秒的每项构成，论证其在工程上的可实现性。

|:---:|:---:|------|:---:|------|

## 第五章 迎头/尾追动态决策矩阵

### 5.1 不是二选一：三维决策模型

拦截几何选择取决于三个变量的组合：**目标距离（d）× 目标速度（Vt）× 剩余反应窗口（ΔT）**。

| 场景 | d(km) | Vt(m/s) | ΔT(s) | 首选几何 | 备选几何 | 理由 |
|:---:|:---:|:---:|:---:|:---:|:---:|------|
| 中远距低速 | >5 | <60 | >100 | **正尾追** | 偏尾追 | 命中率最高(88-95%)，AI帧充裕(151+帧)，但需R型机前出引导占位 |
| 中远距中速 | >5 | 60-100 | >80 | **偏尾追/侧方** | 迎头 | Vi(111)>Vt但窗口紧，侧方平衡命中率与窗口 |
| 中远距高速 | >5 | >100 | >50 | **迎头+多角度** | — | Vi<Vt尾追不可行，必须迎头围捕 |
| **近距低速** | **<5** | **<60** | **<50** | **迎头优先** | 偏迎头 | ⚠️ 距阵地过近尾追来不及！即使低速目标在<5km时也优先迎头！Vrel=162.5m/s→5km仅需30s，尾追需120s→目标早到了 |
| 近距中速 | <5 | 60-100 | <30 | **迎头(冲刺)** | 侧方 | 冲刺段闭合2.44km后仅余~2.6km，巡航~21s即命中 |
| 近距高速 | <5 | >100 | <20 | **迎头全速冲刺** | 偏迎头围捕 | Vrel=266m/s→5km仅需~19s，AI仅34帧→近炸依赖 |
| 超低空FPV | <3 | 30-60 | <50 | **R型机俯视引导+迎头俯冲** | 侧方拦截 | FPV在3km内大概率已进入雷达盲区，依赖R型光电俯视 |

### 5.2 核心原则

1. **距离是第一决策变量**——<5km时，即使在低速目标上，尾追的充裕窗口优势也被距离压缩耗尽。近距来袭必须迎头拦截，牺牲命中率换取反应时间。
2. **速度是可行性判断**——Vi>Vt才能尾追。Shahed-238(Vt=155>Vi=111)永不尾追。
3. **窗口压力决定激进程度**——ΔT<30s时关闭人否决（Lv1反射式），全自主。

### 5.3 决策实例：为什么"5km"是迎头/尾追分界线？

假设Shahed-136(Vt=51.4m/s)在5km处被探测（实际10km，此处以5km为例演示）：
- 迎头总耗时：OODA 12s+助推2s+冲刺15s(闭合2,438m)+巡航~21s(剩余2,562m@120.8m/s)=50s
- 目标到达时间：5,000/51.4=97s → 余量47s ✅
- 尾追总耗时：需绕后占位+加速+尾追闭合。假设R型引导占位15s+尾追从3km处开始(耗时~140s)=155s → 不足！
- **结论**：<5km时尾追需要绕后+占位的时间成本太高，迎头是唯一可行选择。>5km时尾追的命中率优势压倒迎头。
