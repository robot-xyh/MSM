## 第一章 战场态势的形成——雷达/EO/R型/F型四层视界

### 1.1 用户核心问题："雷达看到了，光电看到了，火力拦截机也看到了，与光是雷达看到有什么区别？"

**答案**：四种"看到"有**截然不同的物理意义、时延、精度和置信度**。它们不是"谁替代谁"的冗余，而是**逐层细化的态势拼图接力**。

| 视界层 | 传感器 | 距离 | 精度(1σ) | 更新率 | 看到什么 | 看不到什么 |
|:---:|------|:---:|:---:|:---:|------|------|
| **L1-雷达** | Ku波段一维机扫 | 10km | σ_方位=0.3°, σ_距离=10m | 3s/圈 | "东南135°方向、10km处有1个目标块（30架融合）"——模糊位置+粗糙计数 | 单机分辨（方位分辨率190m@10km >> 50m间距）、目标型号（无分类能力）、诱饵区分（无微多普勒高分辨模式）、<100m超低空目标（地杂波盲区） |
| **L2-光电转塔** | 1024×1024 MWIR+600mm可见光 | 5km | σ_角<0.1mrad, 激光±2m | 10Hz | "目标#3是Shahed-136，翼展2.9m，速度51.4m/s，高度250m"——精确定位+型号识别 | 诱饵精细区分（需更近距离纹理细节）、超5km目标（Johnson准则限制）、大雨下（透过率衰减） |
| **L3-R型机** | 二轴微型光电吊舱（可见光+LWIR） | 2.5km | σ_角<0.5mrad | 3s/帧回传 | "编队实际30架（非雷达说的1个块），其中20架Shahed实弹+10架Gerbera诱饵"——精确计数+诱饵初步分辨 | 同样受距离限制（2.5km），500g吊舱约束→分辨率低于地面转塔 |
| **L4-F型导引头** | 捷联双光(可见光+红外)FOV 30° | 2km | σ_角<1mrad | 30fps | "目标#7在正前方2km、翼展25像素→确认为Shahed-136→启动末段制导"——自主截获+末段制导 | 仅盯住已分配目标，不对全局态势做任何贡献（"管中窥豹"） |

### 1.2 四层态势拼图的核心差异

**雷达看到=模糊位置+粗略目标数**：30架Shahed-136编队（间距50m、纵深1,500m）在10km处的雷达回波=1-2个"目标块"。雷达的分辨率（190m@10km）远大于机间间距（50m），所以雷达"看到"的是一条1,500m长的回波带→IFCM只能知道"东南方向有大量目标"，但不知道具体是28架还是32架、是Shahed还是Lancet。

**光电看到=精准识别+精确定位**：地面EO 600mm凝视在5km处看到Shahed-136=23像素（Johnson识别级）→可以确认"这确实是Shahed-136，高度250m，速度51.4m/s"。但光电需要雷达先告知"往哪个方向看"（事件触发模式）——没有雷达的目标方位预置，光电不可能在360°内独立搜索5km外的所有目标（搜一圈需18s×N次凝视，不现实）。

**R型机看到=前出近距精确认+诱饵初分**：R型在2.5km处（比地面EO近一半）看到更清晰的目标细节——分辨诱饵和实弹的微多普勒差异（发动机振动 vs 滑翔体）、翼面结构差异（弹头简化 vs 完整）。但R型的500g吊舱分辨率远低于地面EO转塔，只做"近距离抵近确认"，不做"远距离探测"。

**F型看到=末段独立截获**：F型导引头FOV 30°、2km处自主搜索→发现目标→锁定。**这是最后一道防线**——即使地面所有引导链路均失效，F型在2km处仍可以自主"看到"目标并发起攻击。但F型"看到"的视场太窄（FOV 30°≈536m覆盖半径@2km），它只能看到地面告诉它"目标大概在这"的那一小片天空，对全局态势毫无贡献。

### 1.3 态势形成机制：逐层接力而非并行冗余

```
时间轴    距离      态势贡献
  ↓        ↓           ↓
T+0      10km    雷达：发现目标块（模糊）→ IFCM C1=0.3(初步)
T+3      10km    雷达第二圈：航迹确立→ IFCM C1=0.5(确认)
T+3.1    9.9km   光电预置引导：粗锁定→ "至少30个热源"
T+6      9.8km   光电精跟踪：第一批10目标型号确认→ IFCM C5=0.6
T+9      9.6km   R型升空，前出5km
T+29     7.5km   R型到达前出点，开始光电搜索
T+35     7.0km   R型回传：精确计数30架(20实弹+10诱饵)→ IFCM C5=0.85
T+38     6.5km   IFCM全态势确立：C7=0.6(反应式)，触发MILP分配
```

**态势形成的三个关键时间节点**：
1. **T+6（初步态势）**：雷达两圈航迹确立→知道"有威胁，方向东南，数量大"→足够触发防御态势但不满足火力分配精度
2. **T+35（精确态势）**：R型回传精确计数+诱饵初分→知道"30架（20实弹+10诱饵）"→足以MILP精确分配
3. **T+38（完整态势）**：全部传感器融合输出→知道每架的位置/速度/类型/置信度→完整火力分配

**这就是"雷达看到 vs 光电看到 vs R型看到"的本质区别**——它们是**相同信息的三个连续时间截面**，每过一层就把态势从"模糊"向"明确"推进一级。在这个接力的末端，F型导引头是最后的"确认者"而非"发现者"。

### 1.4 近距突然出现目标如何决策？

**场景**：一架FPV从建筑物后方突然出现在3km处（雷达/光电因遮挡未提前发现）。

**传统防空体系**：需要30-60s人工判断→重新分配火力→发射→拦截。在3km距离上，FPV以30m/s速度→100秒到达。60s决策后仅剩40s飞行时间→拦截弹需要40s到达3km点→边界可行但紧。

**本体系——事件触发应急流程**：

```
T+0      FPV突然出现（3km，高度50m，速度30m/s，航向正对阵地）
T+0.01   被动节点高架EO(12m桅杆)检测到异常热源→CFAR触发
T+0.05   热源与已知友方航迹库比对→不匹配→标记为"未知-敌嫌疑"
T+0.1    IFCM C7紧急评估：
         - 距离3km(紧迫度↑)
         - 速度30m/s(中等)
         - 未知类型(C5=0.1，极低)
         - 航向正对阵地
         → C7=0.92 > 0.8 → **反射式自动触发！**
T+0.15   跳过MILP精细化分配（来不及）→ 直接查应急策略库：
         - 规则：距离<5km + 航向正对 + 未知类型 → 立即拦截
         - 分配：最近弹药车→发1发F型→迎头冲刺（3km/162.5m/s=18.5s）
T+0.2    发射指令下达（无需合同网——单车独立决策）
T+0.2-1.7 发射准备+弹射
T+1.7   火箭点火，助推开始
T+3.7   助推完成(2s)，v₀=80m/s
T+3.7-18.7 冲刺15s，Vrel(迎头)=162.5m/s → 闭合2,438m
T+18.7  剩余616m@120.8m/s=5.1s巡航
T+23.8  末段导引头截获→YOLOv8识别<10ms→X3撞击/近炸
```

**总耗时~24秒**。目标到达时间=3,000/30=100秒。**剩余76秒余量**。

**关键设计**：
- 触发机制：事件驱动（异常热源出现→IFCM C7急跳）而非周期轮询
- 决策路径：跳过MILP/合同网两个最耗时环节（~1s）→直接应急策略库查表（<50ms）
- 无需人工审批：C7>0.8自动触发反射式→零人工干预
- 弹药代价：1发拦截弹换1架FPV→2:1消耗比下可接受

## 第二章 F型火力拦截机——捷联双光导引头设计

### 2.1 导引头总体方案

F型搭载**捷联双光导引头**（Strapdown Dual-Optical Seeker），由可见光CMOS+红外LWIR非制冷双通道组成，FOV 30°，固定在弹体头部（无万向架，全弹机动实现视场扫描）。

| 参数 | 可见光通道 | 红外通道 | 说明 |
|:---:|:---:|:---:|------|
| 传感器 | 1/2.3" CMOS, 12MP | 320×256 LWIR, 13mm | 双通道同时运行 |
| FOV | 30°×20° | 30°×20° | 宽视场，省去万向架 |
| IFOV | 0.08mrad(等效) | 1.0mrad | 可见光分辨率远高于红外 |
| 2km处单像元 | 0.16m | 2.0m | — |
| Shahed(2.9m翼展)像素@2km | 18像素(可见光) | 1.5像素(红外) | 可见光可识别，红外仅检测 |
| YOLOv8-m推理 | <10ms(BM1688) | <10ms | 共享NPU |
| 识别距离(Shahed) | 1.5-2.0km | 0.5-1.0km(仅检测) | 可见光为主，红外为辅(夜间/大雾) |
| 重量 | ~35g(模组+镜头) | ~35g(模组+镜头) | 总导引头<150g(含结构) |

> **设计取舍**：不用万向架（传统红外导引头配备2轴万向架→500-800g），采用弹体机动+宽FOV完成目标搜索。30°FOV在2km处覆盖1,072m宽的天空区域→即使中制导精度σ=65m，目标也在FOV的中心附近（偏移仅0.06×FOV=1.8°→远小于15°半角）。**"捷联"的代价是弹体必须有机动能力（8G过载足够），收益是重量/成本大幅降低。**

### 2.2 导引头工作模式

| 模式 | 触发条件 | 动作 | 帧率 |
|:---:|------|------|:---:|
| **搜索** | 距离<2km，无目标锁定 | 弹体±15°蛇形扫描，双光宽视场搜索 | 10fps |
| **截获** | YOLOv8-m置信度>0.7 | 停止扫描，转入目标跟踪 | 30fps |
| **跟踪** | 目标持续在FOV内 | Kalman目标状态估计+比例导引(ProNav) | 30fps |
| **识别** | 距离<1km | 可见光700万像素裁切→25+像素确认 | 单帧<10ms |
| **撞击/X3** | Kalman协方差评估 | 协方差<0.5m→撞击(97%)；>3m→近炸(3%) | 实时 |

### 2.3 中末制导交接条件（公式1第⑤-⑦步展开）

**中制导精度**（地面雷达/EO引导）：σ_midcourse = √(σ_雷达²+σ_EO²+σ_IMU²+σ_数据链²) = √(30²+20²+50²+15²) ≈ **65m**

**导引头FOV覆盖**：30°FOV @2km → 覆盖半径=2,000×tan(15°)=**536m**

**交接条件**：σ_midcourse < 536m / k_safety(k≥1.5) = **357m**

**实际**：65m << 357m → **交接余量=5.5倍** ✅

**大雨下**：σ_midcourse≈100m（传感器噪声增大）→ 100 < 357 → 余量**3.6倍** ✅ 仍通过但接近边界

**暴雨下**：σ_midcourse≈150m → 150 < 357 → 余量**2.4倍** → 通过但末段校正难度增大

## 第三章 预演评估——发射前的最后一道数学验证

### 3.1 为什么需要预演评估？

MILP求解的分配方案是**静态最优解**——它在求解时刻的最优性不保证在弹道飞行过程中（目标可能机动、气象可能变化、弹药在线状态可能改变）仍然成立。**预演评估是在真实发射前，用数字孪生快速模拟分配方案的执行结果，确认"这个方案大概率能成"。**

### 3.2 预演评估流程

```
输入：全局分配方案{x_ijk}（环节⑤输出）

步骤1：数字孪生初始化
  - 加载当前战场状态（全部目标的六维状态向量）
  - 加载气象参数（风/雨/雾，取自气象传感器）
  - 加载传感器质量（雷达SNR/EO透过率，取自分册2）
  - 加载弹药在线状态（剩余/故障/重新装填中）
  - 耗时：~50ms（状态快照+环境参数注入）

步骤2：蒙特卡洛快速推演（~100次）
  - 每个推演独立注入随机扰动（目标规避机动±2G/风偏±5m/s/传感器噪声±1σ）
  - 简化动力学模型（不计精细气动，用Vrel闭合公式1的③-⑦）
  - 每次推演输出：hit/miss + 弹药消耗 + 拦截位置
  - 100次并行在BM1688 17.6TOPS NPU上运行
  - 耗时：~400ms（每推演~4ms×100=400ms）

步骤3：三维指标评估
  ┌─────────────────────────────────────┐
  │ ①期望命中率 P_hit_mean              │
  │   达标线：≥70%（迎头）/≥85%（尾追）   │
  │   实际：_____%                       │
  │                                      │
  │ ②弹药消耗比 ratio                   │
  │   达标线：≤1.3×理论最小弹药          │
  │   实际：_____                        │
  │                                      │
  │ ③漏网概率 P_leak                    │
  │   达标线：≤5%（任一目标击中要地）     │
  │   实际：_____                        │
  └─────────────────────────────────────┘
  耗时：~50ms（统计处理）

步骤4：决策
  全部通过？──YES──→ 批准发射（步骤⑤）
      │
      NO──→ 返回MILP重求解（调整约束/权重/初始解热启动）
            重求解后重新预演（最多3次循环）
            3次仍不通过→降级：接受次优解+增加弹药配给（消耗比放宽至1.5:1）
```

**总耗时**：~500ms（在环节⑤合同网签约完成后、环节⑦发射前插入）

## 第八章 结论

1. **IFCM→MILP→合同网→预演→发射是一根完整的链条**，缺一不可。IFCM感知、威胁排序定优先级、MILP求最优解、合同网多车协商、预演做最后验证、发射执行。

4. **F型捷联双光导引头**使末段制导完全自主化——地面引导至2km，弹载AI接管至命中。

5. **模块化嵌入已删除道尔M1引用**，改为"现役近程防空系统（如红旗-17）"。
