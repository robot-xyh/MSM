## 引子：本册内容逻辑串联

本册是体系的**决策中枢**——它回答"谁来决策、怎么决策、决策多快、决策错了怎么办"四个根本问题。

**逻辑主线**（从左到右逐环节串联）：

```
分册2融合航迹(目标三维坐标+分类+置信度)
  → IFCM态势推理引擎(7节点因果矩阵→输出态势等级)
    → OODA模式自动切换(审慎/反应/反射，人机权责边界)
      → 多维威胁排序(距离0.40+速度0.25+弹头0.20+方向0.15)
        → 动态权重自适应(弹药/雷达/通信质量→实时调权)
          → MILP火力分配优化(目标函数+6项硬约束)
            → 分布式合同网协议(投标→评标→签约，含0/1/2-3/4/多架R型边界)
              → 预演评估(数字孪生模拟→命中概率判定→决策确认)
                → 发射指令→分册4执行拦截
```

这条链路中，**IFCM是起点的态势感知器**——它不入发射指令，只输出"当前的战场态势等级"。态势等级驱动OODA模式切换，模式决定了人机权责分配，权责决定了后续排序/分配/协商的执行逻辑。

**三个核心设计原则贯穿本册**：
1. **时间压力决定自主程度**——窗口越大，人的决策权越大；窗口越小，AI接管越多。这不是"AI"vs"人"的对立，而是"时间"vs"认知负荷"的物理约束。
2. **态势驱动而非事件驱动**——不因为"来了一个新目标"就重算全部火力分配，而是IFCM判断"态势变了"（如紧迫度C7从0.3→0.8）才触发重新分配。避免频繁重算造成的振荡。
3. **降级永不停机**——R型数量从4降到0，合同网协议仍然工作（退化为单车独立MILP）。网络的每一层失效都有协议上的降级路由。

**向下衔接**：分册4（IFCM输出→态势驱动的火力分配→预演评估→发射→末段制导，本册给出分配结果，分册4给出执行细节）。

## 第一章 三级OODA自动切换机理——为什么这么分？

### 1.1 不是拍脑袋：物理约束与认知负荷的严格推导

三级OODA（审慎式/反应式/反射式）不是"三个好听的名字"，而是**来袭数量、可用时间窗口、人类认知处理能力**三者叠加后的物理必然。

**核心参数——人类在防空决策中的认知边界**：

| 参数 | 值 | 依据 |
|:---:|:---:|------|
| 单目标态势判断耗时 | 15-20s | 军事人因工程标定（读屏→确认→判断→决策） |
| 多目标并行处理上限 | 3-4个 | 工作记忆容量（Miller定律，7±2组块，防空目标每组块消耗2个槽位） |
| 压力下认知表现衰减 | 15-30% | Yerkes-Dodson定律（中等压力最优，高压力下降） |
| 操作员可持续决策时间 | <30分钟 | 决策疲劳实验数据（30分钟后错误率上升3-10倍） |

**推导三级分界**：

```
时间窗口 = R_detect / Vt
假设Ku雷达10km探测至Shahed-136(51.4m/s) = 194s

如果只有1个目标：操作员有194s→绰绰有余→人主导（审慎式）
如果10个目标同时：操作员需处理10组航迹→超出认知上限(3-4)→必须AI预排序→AI推荐+人确认（反应式）
如果30个目标饱和攻击：处理30×10组参数=300个认知槽位→远远超出人类→AI全自主（反射式）
```

**三条物理红线**：

| 级 | 触发目标数 | 时间窗口(s) | 人认知处理(s) | 剩余差 | 模式 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| L3 | 1-3 | ≥60 | 15-50 | ≥10 | **审慎式(人主导)** |
| L2 | 4-15 | 12-60 | 45-225(超负荷) | 负值 | **反应式(AI推荐+人否决)** |
| L1 | 16+ | <12 | 240-480(严重超负荷) | <<0 | **反射式(全自主)** |

> **L1反射式的12s是物理上界**：雷达扫两圈=6s，剩余6s供AI完成从态势推理到发射指令的全流程。这6s内，人类连读完30行目标信息都来不及——不是"不想给人"，是"物理上人来不及"。

### 1.2 审慎式（Lv3，1-3架，≤60s）

**触发条件**（满足任一条）：
- 来袭目标1-3架
- AI置信度<50%（目标类型未知或特征库未匹配）
- IFCM C5识别置信度<0.3
- 政治敏感空域（民用航线、国界线附近）

**人机分工**：
- AI角色：目标检测+航迹关联+基本参数计算（方位/距离/速度），以辅助信息呈现，**不提供拦截建议**
- 人角色：完全主导——自行判断→选择优先目标→选择拦截方案→下达发射指令
- 否决权：不适用（人从零开始决策，不存在"AI预先做了决定需要人否决"的场景）
- 时间分配：人决策≈30-60s，AI仅做态势显示

**为什么单目标需要人的完全主导？**
1. 时间充裕（>100s）——不急于决策
2. 误击风险远大于漏打风险——在政治敏感空域，打错一架客机的后果远大于放跑一架无人机
3. 诱饵/电磁欺骗/友军误入——这些"非标准"场景需要人的常识判断，AI无法覆盖

### 1.3 反应式（Lv2，4-15架，≤12s）

**触发条件**（默认模式，系统启动即此）：
- 来袭目标4-15架
- AI置信度50-90%
- IFCM C5识别置信度>0.5

**人机分工**：
- AI角色：自动完成IFCM推理→威胁排序→MILP分配→合同网协商，输出**完整推荐拦截方案**（"优先打这几架，用这个角度，分配这几发拦截弹"）
- 人角色：观察AI推荐方案（3秒窗口），可以**否决**（"这个不对，别打这架"），但无需自行生成替代方案
- 否决权：3秒否决窗口——AI在T+7秒完成推荐方案显示在屏幕上，操作员有3秒说"否"。不操作=默认同意执行
- 解释要求：AI必须输出**人类可理解的推荐理由**（"目标#3优先度最高：距离5km(最近)+速度155m/s(最快)+航向正对阵地"），而非黑盒数字"priority=0.87"

**为什么3秒否决而不是更长时间？**
雷达两圈=6s，IFCM+MILP+CNP≈1s，累计7s。12s OODA总预算减7s=5s用于否决+发射。发射需1.5-2s→否决窗口≤3.5s。3秒取整是12s预算下的人机工程最优——既保留了人的司法权，又不突破12s总时限。

**为什么4-15架是反应式的目标数量区间？**
- 下限4架：3架以下人可以直接处理每一架，不需要AI预排序；4架开始超出工作记忆容量（3-4个槽位），需要AI卸载认知负荷
- 上限15架：15架时每架需2发=30发火力分配，MILP解空间≈C(60,30)≈1.18×10^17个组合，人类不可能在12s内穷举。但15架在反应式12s窗口内仍有余量（12s vs目标到达时间~100s+），有条件给人3秒否决
- 16架以上（16×2=32发，194s窗口变相压缩，且MILP解空间>C(60,32)≈6.5×10^18）→时间窗口已不容人否决→触发反射式

### 1.4 反射式（Lv1，16+架，≤6s）

**触发条件**：
- 来袭16+架饱和攻击
- IFCM C7紧迫度>0.8
- FPV超低空突防（高度<100m，时间窗口<30s）
- 全频段通信阻塞（人机链路中断→自动进入反射式）

**人机分工**：
- AI角色：**全自主**——从探测到发射，全程无人工干预。IFCM自动切换→威胁排序→MILP分配→合同网→全自动发射
- 人角色：**旁观监督**——操作员可以看到AI的决策过程（事后审计日志），但在反射式运行期间不能也不应干预
- 否决权：**无**。原因不是"不想给人"，而是：
  - 时间约束：16+架饱和时，OODA压缩至≤6s。否决延迟>2s=至少1架漏网=大概率击中要地。否决的代价>误打的代价。
  - 决策容量：16架×4维排序参数=64个独立变量→即使给人3秒否决，人也无法在3秒内判断"AI打错哪架"
  - 物理必然：如果16架饱和攻击发生，唯一选择是"相信AI"。不信任AI=在物理上无法防御饱和攻击

**为什么16架是反射式的触发线？**
以Shahed-136(51.4m/s)基准想定：16架编队纵深≈800m(16×50m)，到达窗口≈15.6s。OODA 6s+发射1.5s+助推2s+飞行最短时间~9s=18.5s>15.6s。如果在T+6发射完毕仍有最后几架在发射窗口内——留给人的否决时间=0秒。这是**硬物理约束**，与人机工程无关。

### 1.5 三级切换的状态机

```
         ┌──────────────────────────────────────────┐
         │         IFCM态势推理引擎 (每500ms更新)      │
         │  C1威胁等级 C2弹药余量 C3雷达质量           │
         │  C4通信质量 C5识别置信度 C6 GPS可用性       │

    ┌────────────┐  ┌────────────┐  ┌────────────┐
    │ Lv3 审慎式  │  │ Lv2 反应式  │  │ Lv1 反射式  │
    │ 人主导 ≤60s │←→│ AI推荐+人否决│←→│ AI全自主 ≤6s│
```

**降级路径（通信全阻）**：当L2/L3车际链中断时，IFCM态式引擎失去外部输入，自动退守弹载AI预编程模式。F型拦截弹从发射管弹出后，按预编程航线飞向指定的拦截扇区，导引头自主搜索→识别→攻击。这是"纯弹载AI反射式"——体系从三级OODA退化为单级全自主。

## 第二章 多维威胁排序与动态权重自适应

### 2.1 四维加权模型

威胁得分 T_i = **0.40×D_i + 0.25×S_i + 0.20×W_i + 0.15×H_i**

| 维度 | 符号 | 权重 | 物理含义 | 归一化方法 |
|:---:|:---:|:---:|------|------|
| 距离 | D | 0.40 | 目标距要地距离 | d^(-1)，越近D越大 |
| 速度 | S | 0.25 | 飞行速度 | v/v_max (v_max=155m/s) |
| 弹头 | W | 0.20 | 战斗部当量等级 | 50kg=1.0，无战斗部=0.05 |
| 航向 | H | 0.15 | 航向与阵地夹角余弦 | cos(θ)，0°=正对→H=1.0 |

**距离权重的首要地位**：在饱和攻击场景中，一个8km处的Shahed-238（高速155m/s）和一个3km处的FPV（低速30m/s），排序结果必须优先打3km的FPV——因为"它先到"。这不是"FPV更危险"，而是"先到的先打"的时间优先原则。距离权重0.40确保了"近距优先"在任何场景下不被其他维度的权重淹没。

### 2.2 动态权重自适应机制

固定权重在许多极限场景下会出问题。当弹药余量很低时（C2<0.2）：
- 继续按距离（0.40）优先→会先把近处诱饵全打一遍→弹药耗尽→实弹全部漏网
- 动态调整：权重自适应→D=0.25, S=0.30, W=0.35, H=0.10→**弹头权重跃升为首位**→优先打实弹而非诱饵

| IFCM触发条件 | 调整为 | 意义 |
|:---:|:---:|------|
| 弹药<20%（C2<0.2） | W=0.35(↑) D=0.25(↓) | 弹药不足时优先打最高价值目标 |
| 雷达质量下降（C3<0.3） | D=0.50(↑) S=0.15(↓) | 雷达不准时优先用距离（最可靠参数） |
| 通信丢包>50%（C4<0.3） | H=0.30(↑) D=0.30 | 无法协商时，各车优先正对自己的目标 |
| C7紧迫度>0.7 | D=0.50(↑) S=0.30(↑) W=0.10(↓) H=0.10(↓) | 极端紧迫时距离+速度压倒一切 |

### 2.3 IFCM态势推理引擎

IFCM（直觉模糊认知图，Intuitionistic Fuzzy Cognitive Map）是**态势推理器**，不是火控决策器。它的唯一输出是：**当前战场态势等级 + 七项仪表盘的定级**。

7节点因果权重矩阵（专家知识初始化，在线贝叶斯修正）：
- C1（威胁等级）→ +0.9→C7（紧迫度）：威胁越多越紧迫
- C2（弹药余量）→ -0.7→C7：弹药越少越紧迫
- C3（雷达质量）→ +0.6→C7：雷达越好，能发现更多威胁→紧迫度上升
- C5（识别置信度）→ -0.5→C7：识别越准，不需要反射式→紧迫度下降

迭代推理：A^(t+1) = sigmoid(A^(t) + A^(t)·W)，收敛至稳态后输出C7值（0-1之间的连续标量）。C7>0.8→反射式触发；C7 0.5-0.8→反应式；C7<0.5→审慎式。

## 第三章 MILP火力分配优化

### 3.1 问题形式化

**场景**：M个威胁目标，K辆拦截车（每车N发拦截弹），最小化总威胁值。

**决策变量**：x_ijk ∈ {0,1}——车k的第i发拦截弹是否分配给目标j

**目标函数**：max Σ_j w_j × [1−Π_k Π_i (1−P_kill(i,j)×x_ijk)]

**6项约束**：
1. 弹药约束：Σ_i,j x_ijk ≤ N_k
2. 每发单目标：Σ_j x_ijk ≤ 1
3. 消耗比下限：Σ_k,i x_ijk ≥ CR_j（低速2/中速2.5/高速3/诱饵1）
4. 时序约束：t_launch + t_fly(i,j) ≤ t_impact,j（拦截弹必须在目标到达前命中）
5. 扇区约束：每车火力扇区≤120°
6. 速度约束：Vt < Vi 的尾追前提；Vt ≥ Vi 强制迎头

### 3.2 时间自适应解算管线

| 剩余时间 | 算法 | 精度 | 计算资源 | 适用模式 |
|:---:|------|:---:|------|:---:|
| ≤1s | 预存应急策略库（查表） | 90-95% | NPU <5ms查表 | 反射式应急 |
| 1-5s | 快速贪心+局部邻域搜索 | 85-95% | 2TOPS | 反射式标称 |
| 5-12s | MILP精确求解（热启动） | 95-98% | 10TOPS | 反应式标称 |
| 12-60s | MILP+粒子群优化(PSO) | 98-99% | 10TOPS×4核 | 审慎式 |
| ≥60s | 全维度MILP+数字孪生自优化 | 99%+ | NPU集群 | 审慎式训练态 |

## 第四章 分布式合同网协议——R型数量边界全场景

### 4.1 三阶段协议（投标→评标→签约）

**投标函数**：Bid_r(j) = P_kill(j) × (1/t_engage(j)) × (avail/total) × (1−d/d_max)

**评标收敛**（平均一致性算法）：x_i^(t+1) = x_i^(t) + ε Σ(x_j−x_i)

4架R型在完全图拓扑下：λ_2≈0.82，ε≈0.71，8轮迭代 → 400ms < 1s ✅

### 4.2 R型数量边界——全部五种场景

| R型数 | 协议行为 | 收敛时间 | 覆盖 | 冗余 | 适用想定 |
|:---:|------|:---:|:---:|:---:|------|
| **0架** | **无CNP**。地面雷达+EO独立处理。MILP由单车或指控中心单节点求解。火力分配指令通过L3车际链直接下发至各车。F型发射后依赖预编程航线+导引头自主 | 0s(无需协商) | 依赖地面传感器 | 无 | 单车独立作战、所有R型被毁的降级场景 |
| **1架** | 单R型担当集中分配器。无需CNP（无对等节点可协商）。1架覆盖90°扇区后需重新前出至下一扇区（耗时~30s），导致覆盖不连续 | <0.1s(单节点无协商) | 90°/次，旋转覆盖 | 无(单点故障) | 小型袭扰（<10目标）、R型消耗后仅剩1架 |
| **2-3架** | CNP运行但参与节点减少。平均一致性收敛更快（2节点仅需~200ms），但覆盖扇形有缺口（2×90°=180°，缺口180°）：R型飞行覆盖需机动补位，覆盖率约60-75% | <0.5s | 2-3×90°, 有机动缺口 | 有限 | R型部分损耗、非饱和作战 |
| **4架** | 标称配置。4×90°=360°全覆盖。CNP 8轮迭代→400ms。拜占庭容错：容忍1架异常（连续3轮报价偏离>3σ→标记隔离→剩3架重收敛~1.5s） | <1s | 100% | 单机容错 | 标准作战想定 |
| **>4架** | CNP可扩展至N个投标节点。收敛速度随N增大缓慢上升（O(N²)通信复杂度），但N≤8时仍<1s。冗余度上升（N−1容错）。多余R型可做扇区重叠覆盖提供双重确认 | <1.2s(N=8) | 100%+重叠 | 多机容错 | 重点防卫、高威胁方向 |

**0架R型时的F型自主协同方案**（v4.1新增）：
当所有R型被毁或未出动时：
1. **探测链路**：地面Ku雷达+EO光电转塔持续输出目标三维航迹（无前出引导，但探测距离不变——Ku 10km/EO 5km）
2. **火控链路**：指控中心单节点MILP求解→通过L3车际链下发分配给各车
3. **中制导链路**：地面雷达/EO通过L1火力链上行更新拦截弹中段航迹（10Hz），拦截弹依赖地面引导直至末段
4. **末段交接**：F型导引头（捷联双光，FOV 30°）在2km处自主截获目标（地面引导精度σ≈65m，导引头覆盖半径536m→余量8.2×→交接充裕）
5. **效能损失**：约-20%（无R型前出侦察→失去诱饵精细识别+编队精确计数+低空补盲）→命中率降至70-80%（vs 标称88-95%尾追）

> **物理限制**：0架R型时FPV超低空（<50m）的探测完全依赖被动节点高架EO（12m桅杆）。Ku雷达在大雨下探测仅3.16km且不能覆盖<100m低空。这是本体系在"0架R型+大雨+FPV"三重复合条件下的能力底线。

### 5.1 三层递进训练架构

| 层级 | 方法 | 数据规模 | 周期 | 输出 |
|:---:|------|:---:|:---:|------|

### 5.2 训练架构的扩展性设计（v4.1新增）

**Phase 1：单车模块训练（当前设计）**
- 单车主战车辆独立完成探测→决策→拦截全流程
- 策略模型：单智能体PPO/MAPPO（1车=1个多弹协同智能体）
- 训练环境：单车 vs 红方蜂群（5/10/20/30架）

**Phase 2：多车协同训练（扩展接口预留）**
- **接口设计原则**：不改变Phase 1训练的弹载AI模型，仅新增"多车协同元策略层"
- 扩展点1——**观测空间可插拔**：Phase 1的观测向量 [本车雷达/EO/弹药] → Phase 2可扩展为 [本车感知 + 邻车padded感知 + 车际信息丢弃mask]
- 扩展点2——**动作空间分层**：Phase 1的F型动作 [发射时机/拦截几何/末段机动] → Phase 2增加R型动作 [扇区分配/前出距离/搜索模式]，车际动作 [协同目标覆盖/弹药互助/扇区交接]
- 扩展点3——**奖励函数模块化**：Phase 1单车主奖励 R_solo → Phase 2分解为 R_local + R_global×(1−α_decay)，α_decay从0(start)→0.3(训练末)逐步降低全局权重→鼓励独立生存能力
- 扩展点4——**通信接口标准化**：车际信息交换使用gRPC Protobuf流，字段预留扩展（当前20字节/包→预留至256字节），Phase 2直接复用不更改协议

**Phase 3：融入大体系（兼容性预留）**
- C4I接入：ACSI/ADatP-3标准格式（ASTERIX CAT-048航迹 + Link-16 J-series火力指令）
- 上级空情图融合：L5 IFF通过JSON REST API查询联合空情服务器
- 体系火力协调：上级MILP超解算器可在60s级时间预算内下达"优先目标覆盖"指令，本体系接收上级指令后在各车本地求解并执行

> **不锁死设计**：MAPPO框架的观测/动作/奖励空间全部通过配置文件定义（YAML），不需要重新编写训练代码。多车扩展只需修改配置文件→重新训练→部署。

## 第六章 五大关键技术突破（v4.1重定义）

### 关键一：IFCM态势推理+多维威胁排序+动态权重自适应

**问题定义**：如何从原始的传感器数据流中，实时感知"当前战场是平静、紧张还是饱和"？如何据此自动调整威胁排序的依据？

**技术路线**：七节点直觉模糊认知图（IFCM）+ 四维加权动态威胁排序。IFCM以7个概念节点迭代推理，收敛至稳态后输出态势等级C7（0-1连续标量）→ 驱动OODA切换→ 触发排序权重动态调整（弹药不足→弹头优先；雷达不准→距离优先；通信不佳→航向优先）。

**TRL评估**：TRL 4（仿真验证），目标TRL 6。

### 关键二：MILP火力分配+分布式合同网协议

**问题定义**：在弹药/射程/时间窗口等6项硬约束下，求最小化总威胁值的最优火力分配方案，并在多车之间通过分布式协议协商一致。

**技术路线**：离线MILP精确求解（Gurobi/CPLEX）→ 在线贪心+局部搜索近似（<100ms）+ 合同网CNP投标→评标（平均一致性）→签约。覆盖R型0-4+架全部场景（见第四章）。

**TRL评估**：TRL 4（仿真验证+多智能体博弈），目标TRL 6。

### 关键三：新战法快速迭代更新（v4.1新增，替代原诱饵识别）

**问题定义**：敌方持续发展新战术，如沙希德-136挂载多架FPV旋翼无人机（"母机带子机"），在接近目标区时释放FPV实施第二波打击。这种"两阶复合攻击"不在现有训练数据中——AI需要在新战法出现的24小时内完成战术识别、对策生成和模型更新。

**技术路线**：
1. **战术特征自动提取**：R型回传图像+雷达航迹→新出现的飞行剖面（母机减速→释放FPV→FPV加速）自动聚类→标记为"异常模式"
2. **数字孪生快速建模**：将新战术特征注入仿真环境→在1小时内生成1,000个变体场景（母机速度±20%/释放点±1km/FPV数量±50%）
3. **紧急增量学习**：在生成数据上微调MAPPO策略（不重训基础模型，仅更新最后一层+注意力头）→训练时间<4小时（8×A100 GPU）
4. **仿真验证**：红方新战术 vs 蓝方更新后策略，1,000次蒙特卡洛评估→拦截成功率>基线×80%为通过
5. **OTA推送**：通过L3车际链推送更新权重（<10MB压缩包）→BM1688本地解密+双分区存储（保留旧版回退）→空中切换无需重启动
6. **目标全周期**：从发现新战术到部署更新→**<24小时**

**与"诱饵识别"的技术继承**：原诱饵识别的多光谱微多普勒分析技术并入新战法识别的"特征自动提取"模块——诱饵只是新战法的一种（敌方用假目标），沙希德带FPV是另一种（敌方用复合攻击）。框架统一，特征库持续扩展。

**TRL评估**：TRL 3（仿真概念验证），目标TRL 5。

### 关键四：F型无人机自主作战——目标配准与决策（v4.1新增，替代原人在回路可解释性）

**问题定义**：F型火力拦截机搭载**捷联双光导引头（可见光+红外，FOV 30°）**，具备末段自主寻的能力。但自主的前提是：F型必须知道"谁是目标、目标在哪、我怎么撞上去"——这就是"目标配准+自主决策"问题。

F型自主作战的**不是"AI取代指挥员决定打谁"**（打谁由地面火控MILP分配决策），而是**"地面告诉你打#7号目标，你自己决定怎么打——是迎头撞还是侧方截？什么时候启动末段机动？导引头什么时候从地面引导模式切换到自主跟踪？"**

**技术路线——五步自主作战流程**：

```
Step 1: 目标配准（地面→F型）
  地面火控通过L1火力链上行：{目标ID: #7, 类型: Shahed-136,
    三维坐标: [x,y,z], 速度矢量: [vx,vy,vz], 翼展: 2.9m,
    优先级: 1, 分配拦截弹: F-12}
  F型弹载NPU接收后→存入目标状态向量缓存

Step 2: 中段引导（地面雷达/EO→F型）
  地面以10Hz更新目标位置通过L1链下行
  F型运行扩展Kalman滤波器：融合地面更新 + IMU + 高度计
  中制导精度 σ_midcourse ≈ 65m（500m/10Hz下）

Step 3: 导引头自主截获（F型自主触发）
  当目标距离 < 2km且地面引导精度 < 导引头FOV余量时→F型自主切换
  FOV 30° @2km → 覆盖半径536m >> 65m（地面误差）→截获成功 ✅
  捷联双光同时运行：可见光（日间主通道）+红外（夜间/大雾主通道）
  YOLOv8-m目标识别 <10ms → 锁定目标#7

Step 4: 拦截几何自主决策（F型自主）
  F型弹载NPU根据目标速度矢量+自身速度+剩余航时，自主选择：
  - Vt<60m/s（低速）→ 优先尾追（命中率88-95%）
  - Vt 60-100m/s（中速）→ 侧方/偏尾追
  - Vt>100m/s 且 Vi<Vt → 已无尾追可能（地面分配时已知），执行迎头拦截
  决策逻辑在弹载BM1688上实时运行（<5ms），不依赖地面数据链

Step 5: 末段机动+撞击/X3近炸
  Kalman预测目标轨迹（30fps图像更新）
  比例导引（ProNav）+ 提前量修正（Lead Pursuit）
  Kalman协方差超标→自动触发X3近炸（<5ms切换）
```

**F型自主 vs 人工FPV的核心差异**：
| 维度 | 人工FPV(STING) | F型自主(BM1688) |
|:---:|:---:|:---:|
| 目标配准 | 人眼+FPV图像 | 地面航迹+弹载导引头双重确认 |
| 拦截几何 | 人操控（经验依赖） | AI最优几何选择（数学模型+5模式决策矩阵） |
| 反应速度 | ~30ms（人反应+链路延迟） | <10ms（弹载本地推理） |
| 多目标能力 | 1机1人 | 1人可以监督60架F型 |

> **F型自主作战的边界**：F型**不决定打谁**（那由地面MILP分配决定），**只决定怎么打**（拦截几何+末段机动）。这是精确的权责边界——地面做战略决策，F型做战术执行。这比让F型"自主决定一切"在责任链和法律上更清晰，也比完全人工操控在物理上更快。

**TRL评估**：TRL 4（仿真验证，YOLOv8+Kalman+ProNav已集成），目标TRL 6（缩比飞行测试）。

### 关键五：实时在线学习与模型更新

**问题定义**：战场环境动态变化——新威胁类型、干扰策略演化、传感器性能退化。AI需要边打边学，同时不降低作战效能。

**技术路线**：联邦学习（R型机边缘端本地梯度→仅回传加密梯度至地面聚合）+ 增量学习（新类型加入→不需全量重训，克服灾难性遗忘）+ 安全管理（仿真验证→加密OTA→双分区存储防回退）。

**TRL评估**：TRL 3（算法验证），目标TRL 5。
