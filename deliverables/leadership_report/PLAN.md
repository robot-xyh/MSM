# 八区域空中二级节点四项智能方案报告计划

## 问题界定

中心节点只提供跨区域资源数量、粗略三维区域、目标数量区间、来袭方向、信息时刻、可信度和有效期，不直接形成可信的区内单目标分配。八个战略区域各部署一架盘旋飞行的二级节点。二级节点配备周扫红外、凝视红外、凝视可见光和区域通信设备，常态负责区内搜索、目标配准、区域临时目标维护和本地任务分配。

二级节点和拦截无人机均配备可控云台。高倍率光电视场较窄，平台运动还会持续改变观察位置和姿态，因此区域重划、协同搜索、目标配准和本地分配必须形成连续闭环。

## 报告结构

四份报告统一采用以下主体结构：

1. 背景：只说明当前任务阶段的输入、平台条件和目标，不展开整个项目背景。
2. 存在的难点：每份归纳三项直接影响该阶段运行的问题。
3. 提出的方案：分别说明传统方案、人工智能方案和两者关系。
4. 关键技术：每份提炼一个不超过50个汉字的技术名称。
5. 实施方案：说明输入、数学模型、算法流程、训练、在线运行、失效回退和验证方法。

参考资料单独列在五个主体章节之后。正文不设置当前进展、已有实现、代码或仿真结果章节。

## 算法主线

人工智能方案作为目标多、机动强、信息变化快和资源竞争明显场景的主线。传统算法作为少目标场景基线、训练示范、效果对照和模型异常回退。学习模型不得直接控制飞行或云台电机，不得改写目标身份，不得绕过任务版本和安全约束。

1. 区域重划采用图结构和时间窗口编码区域状态，通过近端策略优化强化学习输出搜索单元优先级、责任权重和重划时机，再由确定性能力加权分区形成具体任务。
2. 协同搜索采用部分可观测决策模型。强化学习选择观察单元、俯仰层、光电通道、停留时间和无人机补扫任务，确定性控制器生成云台和飞行命令。
3. 目标配准把多相机短轨迹构成稀疏关系图，由图神经网络学习同一目标评分，再由几何、一对一和多帧约束确认区域目标。
4. 本地分配由强化学习输出有界代价修正、备用启用和重规划建议，匈牙利算法或最小费用流生成最终任务；节点失效后使用确定性拍卖接替。

## 关键技术

1. 《拦截区域重划方案》：盘旋二级节点引导的三维搜索责任区智能滚动重划技术。
2. 《拦截无人机协同搜索方案》：有限视场条件下的空中节点与多机协同主动搜索技术。
3. 《多无人机目标配准方案》：不同视场目标子集的多机时空图关联配准技术。
4. 《任务组本地目标分配方案》：学习增强的多资源滚动目标分配与失效接替技术。

## 光电口径

- 周扫红外：1280×1024中波制冷InSb，300毫米焦距，15微米像元，单像元视场0.05毫弧度，水平视场2.93度、垂直视场3.67度，扫描角速度200度每秒。
- 凝视红外：640×512中波InSb，600毫米焦距，15微米像元，单像元视场0.025毫弧度，视场0.917度×0.733度。
- 凝视可见光：2600×2160 CMOS，600毫米焦距，2.5微米像元，单像元视场0.00417毫弧度，视场0.621度×0.516度。
- 吊舱融合输出频率为100赫兹。该频率用于状态更新和时间同步，不等同于各探测器原始帧率。
- 2秒完成360度周扫只作为快速告警能力。目标横向穿过2.93度视场约14.7毫秒，快速周扫不能单独形成稳定身份。
- 标准搜索建议先按4至6秒周期设计，通过降低扫描速度、多圈积累和优先重访形成连续线索；实际周期由设备试验标定。
- 设备价格不写入四份专题报告。

## 图件与版式

每份报告配置11幅中文高分辨率图件，其中保留8幅体系、几何和任务图，新增3幅人工智能算法图。新增图分别说明任务难点，学习模型的状态、动作和回报，以及学习建议进入确定性执行的流程。

图件尺寸为3600×2025像素、约300 DPI。公式使用可编辑的居中段落，不制作占据大半页的公式图片。每份报告交付Markdown和Word，Word目标页数为15至20页A4。

## 资料与写作

工程资料采用用户提供的光电参数、MAVLink云台协议、OpenCV相机标定文档、SciPy和OR-Tools求解器说明。学术资料采用概率搜索、传感器管理、部分可观测决策、近端策略优化、图神经网络、多相机跟踪、多机器人任务分配和分布式拍卖论文。

正文使用直接、克制的工程报告语言。人工智能能力统一表述为拟采用方案和待验证能力，不写成已经形成的装备能力。建议指标必须说明验证条件，仿真参数不能写成设备能力。

## 交付检查

- 检查四份报告严格按五个主体章节排列，关键技术名称不超过50个汉字。
- 检查每份Word含11幅图、15至20页A4，图片、公式、标题和参考资料无裁切。
- 复算视场覆盖、快速周扫停留时间、概率更新、相机投影和分配约束。
- 检查学习输出不直接改写身份、不直接形成控制命令、不绕过确定性硬约束。
- 执行参考链接、模板化语言、图片尺寸、Python语法、Word压缩结构和差异格式检查，并通过临时PDF逐页检查分页和图文比例。
