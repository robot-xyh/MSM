# D5 长距离二十目标冻结基线

本目录保存 2026-08-10 原始尺度 AirSim ComputerVision 单 seed 试验的精简证据。
基线用于后续短时漏检、绑定迟滞和交叉窗口修改的同口径比较，不替代多 seed 验收。

`online_replay.jsonl` 只含匿名本地轨迹、中心持有的 `GlobalTrack`、相机位姿、双时间戳和
协方差。`offline_truth_sidecar.json` 单独保存离线评分标签和已定位失败样本。在线回放不得
读取离线侧车。目录不保存截图、视频、actor 名称或完整 AirSim 大日志。

冻结结果为：1934 条可评分关联，准确率 0.9979317477；连续可见段身份切换 0；短缺口 3；
长期重发现 48；同一本地轨迹的几何绑定切换 7；31 个交叉窗口中 3 个可评分。在线真值使用、
重复分配和 `global_track_id` 改写均为 0。

`d6_evaluation/`保存D6对本冻结目录的独立离线复核。报告复现了上述准确率、3次短缺口、
7次绑定切换和3/31交叉窗口可评分结果，状态为`fail_closed`。失败原因是有效短缺口仍为3、
旧v2没有绑定振荡事件证据，以及实际交叉窗口可评分比例只有0.096774。该报告用于锁定改造前
基线，不代表新时序关联器在真实AirSim中的性能。
