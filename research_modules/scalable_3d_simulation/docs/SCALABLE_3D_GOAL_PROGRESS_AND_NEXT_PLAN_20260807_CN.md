# 200 对 200 三维体系目标实施进展与后续计划

- **更新日期**：2026 年 8 月 7 日
- **实施分支**：`feat/scalable-3d-200v200`
- **远端基线提交**：`aad6b562a500c71fb63548142df556d03c5a6a51`
- **证据边界**：本文只汇总三维质点科研仿真、软件合同、数据来源和离线评价进展，不代表实机、硬件在环或实际拦截能力。

## 一、总体判断

本目标已经完成可扩展三维质点环境、匿名在线观测、D1-D7 规则链适配、版本化实验总线、学习数据生成器和独立来源审计。系统能够在统一的北东地坐标系中生成最多 200 个来袭目标和 200 架拦截资源，执行传感器观测、航迹融合、目标关联、资源分配、降级协调、视觉配准和三维导引的软件流程。在线链路保持真值隔离，计划版本、时期、租约、联盟确认和全局航迹编号所有权均有失败关闭检查。

终极目标尚未完成。当前可作为规则科研基线使用，但 D1 密集目标召回、D2 身份连续性、D1-D3 统一消息总线、正式规则矩阵后半批、当前代际学习模型训练、组合方案和多随机种子五米物理闭环仍未闭合。现阶段没有新增运行级 P0 断链，主要工作集中在 P1 验收。已取得的来源完整性结论不能外推为模型质量、在线采用或控制权限。

## 二、已经完成的工作

1. 在独立分支 `feat/scalable-3d-200v200` 上实施三维环境、学习算法和规模化评价，保留原有 2 对 2、5 对 5、M5N2 和 AirSim 基线，未改写主线历史。
2. 场景、世界模型、总线、随机种子、模型、阈值、计划版本和联盟状态均纳入实验清单。学习来源绑定生成提交、配置摘要、种子范围、分区和文件哈希。
3. 代码、数据审计、背景报告、论文资料和领导汇报材料按子系统分组提交并推送。最近四个提交为 `ae7b06e`、`ec60183`、`8888ee8` 和 `aad6b56`。
4. 清理了三个已被当前历史包含的临时 worktree、过期预检目录和失效的 Git worktree 元数据。正式来源输出、D6 v3 审计结果和含独有证据的 D5 审计 worktree继续保留。

### （二）可扩展三维仿真内核

1. 建立六维北东地状态、三维质点动力学、速度与加速度限制、转弯率和爬升率约束，支持匀速、转弯、交叉、编队、分裂、规避和高度变化。
2. 建立统一仿真时钟和多频率调度。物理、传感器、融合、关联、分配、区域协调、视觉和导引可按不同周期执行。
3. 建立针孔相机投影、目标代理框、像素协方差、视场裁剪、遮挡、漏检、虚警、外参误差、时间偏差和通信延迟模型。200 对 200 场景不生成 200 路光栅视频，使用几何投影和匿名局部轨迹控制计算量。
4. 建立通信拓扑、时延、丢包、中心/二级节点故障和网络分区模型；建立 episode 总线、状态回写、批量运行、日志、归档和离线评估接口。
5. 五米拦截判据已进入世界和D6离线真值侧。该判据与D7在线估计停止条件分开记录，避免把控制停止误记为物理成功。

### （三）D1-D7 规则链

1. **D1 多传感器融合**已支持扫描级批量量测、六维航迹、乱序量测、量测时刻与到达时刻、协方差传播、密集航迹起始和在线真值拒绝。
2. **D2 多目标关联**已支持三维马氏门控、空间索引、稀疏连通分量、局部匈牙利匹配、显式身份交换计数和连续性指标。
3. **D3 资源分配**已支持三维可达性、区域候选边、M 对 N 需求槽、匈牙利求解、计划迟滞、版本递增和旧计划拒绝；学习接口采用有界代价修正，不替代确定性求解器。
4. **D4 降级协调**已实现中心、二级节点和现有完全分布式联盟路径，包含时期、租约、计划版本、成员确认、主动降级证据和失败关闭。
5. **D5 终端视觉关联**已实现匿名局部轨迹、几何候选门、射线交会、重投影、稀疏图网络、受约束聚类、匈牙利中心绑定和只读全局航迹编号门控。
6. **D6 系统评估**已实现逐随机种子记录、聚合指标、自助法置信区间、阶段耗时、三维图表、规则/学习变体矩阵和中文 Markdown 报告接口。
7. **D7 三维导引**已实现每个分配对独立状态、三维位置比例导引、末端视觉视线导引、加速度限制，以及D3计划、D4联盟和D5视觉锁定的联合门控。

## 四、尚未完成的关键工作

2. **D1/D2密集质量**：需要冻结多传感器密集场景，在至少20个未见随机种子上同时校准召回、协方差一致性、身份交换和航迹连续性。
3. **统一消息总线**：D1-D3仍存在同进程对象直传。需要把双时间戳、协方差、序号、来源和版本完整写入总线，并由D2、D3从消息消费。
4. **规则基线完整性**：正式R0只完成 `450/900`，shard 10-19、完整归档合并和D6最终规则后验尚未完成。
5. **当前代际训练与评价**：A1 v3、A2 v8、A3 v3尚未训练。G1也缺当前冻结版本在代表性相机域下的最终模型和中心身份绑定收益。
6. **组合与物理闭环**：C1、F1未启动，缺同一随机种子、同一外生输入下的R0/G1/A1/A2/A3/C1/F1比较，以及至少20个未见随机种子的完整时长五米物理闭环。

## 五、后续实施计划

### 阶段一：冻结训练输入和规则基线

1. D3、D4、D5分别审查来源字段边界，形成“保持现有合同”或“升级后重新生成”的书面决定。
2. 若升级合同，重新生成受影响模块来源并由D6复做完整性审计；未通过前不训练。
3. 继续完成R0 shard 10-19，按现有20 GiB保护线逐片运行、压缩、复核和归档，最后执行完整归档合并。
4. 验收条件：R0达到 `900/900`；全部清单、哈希、真值隔离和严格身份指标可用性写入D6报告。

### 阶段二：关闭D1/D2质量和总线缺口

1. D1建立冻结的多传感器密集目标场景，分解漏起始、错误合并、延迟和协方差膨胀原因。
2. D2针对交叉、编队、遮挡和漏检标定稀疏门控、轨迹生命周期和身份保持，不用在线真值调参。
3. main完善D1-D3总线DTO，D1发布双时间戳和协方差，D2/D3按版本化消息消费。
4. 验收条件：至少20个未见随机种子；D1召回达到冻结后的验收值；D2身份交换和连续性相对R0有明确改善；在线真值使用为零。

### 阶段三：分别训练A1、A2和A3

1. 训练权限按D3、D4、D5分开签发，只允许读取训练分区，不读取future-held-out，不授予shadow、assist、运行或控制权限。
2. A1训练有界代价修正；A2训练区域资源策略；A3训练主动视觉策略。规则动作掩码、版本门和回退路径保持开启。
3. 输出冻结配置、模型卡、权重SHA-256、训练曲线、显存峰值和推理时延。
4. 验收条件：训练过程无保留集读取；模型可以在新进程严格复载；失败时精确回退R0。

### 阶段四：验证、一次性保留评价和影子运行

1. 使用validation选模并冻结模型与阈值。D4需先单独冻结validation/test来源。
2. 对冻结模型一次性使用test或future-held-out，D6独立复算指标。失败后不得围绕保留集反复调参。
3. 质量门通过的模型先进入shadow-only，记录实际干预、拒绝原因、运行确认、计算时延和同键R0非退化。
4. 验收条件：身份、重复分配、硬约束、计划版本和控制权限均无退化；模型异常和分布外输入能够自动回退。

### 阶段五：同步D4和D7新增方案

1. D4将二级节点失效出口从现有完全分布式主路径调整为“推举临时中心机”。新增候选评分、唯一推举、成员确认、任期、租约、网络分区防双主、临时中心再失效和恢复交接合同。
2. 保留现有完全分布式代码作为研究对照或最终失效回退，不直接删除，先由D4 owner明确状态迁移关系。
3. D3/D4/D5/D7共同冻结三机协同任务合同。强化学习只选择协同模式、角色和进入参数；比例导引、视觉导引和防碰撞继续使用确定性算法。
4. 验收条件：旧任期、成员确认不足、网络分区、目标身份不一致和预测碰撞全部失败关闭；临时中心恢复交接不产生双主或重复资源占用。

### 阶段六：C1、F1和最终验收

1. 单模型均通过后再启动C1组合，检查模型之间的相互影响和规则回退。
2. F1加入中心故障、二级节点故障、临时中心推举、通信退化、视觉丢失、资源失效和三维导引闭环。
3. 在至少20个严格未见随机种子上运行完整时长，D6离线真值计算五米成功，同时报告身份交换、重复分配、碰撞风险、硬约束、降级状态和阶段耗时。
4. 输出逐seed CSV、聚合JSON、置信区间、三维轨迹、GIF/MP4、中文Markdown和Word验收报告。

## 八、结论

当前项目已经从“可生成200对200对象”推进到“具备真值隔离、版本约束、规则回退、来源生成和独立审计的软件体系”。规则路径可以继续用于科研仿真和对照实验。下一阶段不应直接启动全模型联合训练，先关闭来源字段、D1/D2质量、统一总线和R0后半批，再依次训练和审计单模型。单模型、降级新方案和三机协同合同均通过后，才具备启动C1、F1和最终多随机种子验收的条件。
