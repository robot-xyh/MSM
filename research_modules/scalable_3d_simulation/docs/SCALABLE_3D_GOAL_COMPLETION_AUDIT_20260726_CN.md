# 200 对 200 三维体系目标完成度审计

## 审计结论

当前专项分支已经具备三维规则闭环、D1-D7 统一总线、匿名视觉投影、学习数据管线、模型
影子运行、正式实验分片和 D6 失败关闭审计。完整目标尚未完成。主要缺口集中在学习模型
预准入、正式多随机种子矩阵、200 对 200 实时性、模型制品交付和最终综合报告。

截至 2026-07-26，当前提交为 `811e4b0`，分支为
`feat/scalable-3d-200v200`。规模化模块全量测试为 `292 passed, 1 warning`。警告来自
本机 Matplotlib `Axes3D` 导入冲突，不影响二维图表和非图形测试。当前工作树还有三份受
保护的未跟踪资料，正式实验必须使用绑定 clean commit 的独立 worktree，不能把脏工作树
结果写成正式证据。

## 版本管理

当前长期分支结构符合既定方案：

```text
main
└── feat/scalable-3d-200v200
```

`main` 保留 2v2、5v5、M5N2 和 AirSim 基线，专项分支承载三维世界、D1-D7 扩展、图神经
网络和强化学习。D1-D7 没有拆成长驻模块分支，子智能体不操作 Git 索引，由 main 分批提交。
当前没有 `scalable3d-*` 阶段标签。完整 R0、学习模型准入和最终多随机种子验收尚未完成，
因此现在不满足创建 `scalable3d-v0.2.0` 及后续标签的条件。

episode manifest 已记录 Git 提交、配置摘要、场景版本、世界合同、总线合同、D3 策略、
D4 策略、D5 模型和阈值版本。实验矩阵另行绑定完整父清单、执行范围、分片、设备和 bundle
文件树。模型权重使用摘要和模型说明管理，训练中间检查点及大规模输出不作为普通源码提交。

## 正式实验状态

正式父清单包含 R0、G1、A1、A2、A3、C1、F1 共 5700 个单元。R0 scope 为 900 个单元。
修复后的 clean source 已完成 shards 0、5、9，共 `135/900`。学习模型均无 assist 权限，
因此 G1、A1、A2、A3、C1、F1 正式 episode 均为 0。

当前规模化输出约 18 GiB，文件系统可用空间约 20 GiB，已达到正式运行器的 20 GiB保护
下限。下一轮正式分片不能直接启动。现有正式证据不得删除、覆盖或跨提交拼接。
`artifact_archive.py` 已提供逐文件清单、原子复制和双端复核，且不包含删除入口。当前
仍缺外部大容量目标目录。继续运行前需要完成以下任一项：

1. 将既有正式输出连同 SHA-256 清单迁移到可验证的外部存储；
2. 扩容当前文件系统；
3. 经用户明确授权，按证据保留清单压缩或清理可重建的开发输出。
