# D4 v4 候选准入决定

## 决定

D4 v4 区域资源候选不登记，不进入正式保留集、运行预检或 D3 后继计划实验。现有候选
作为 development/shadow 对照保留，确定性规则继续作为唯一可执行路径。

该决定不否定候选制品的完整性。D4 不可变审查和 D6 独立审计均确认文件、来源、数据
切分和关闭权限可复核。阻断项来自置信模型质量和运行收益证据缺失。

## 事实

固定置信门为 0.60。D6 独立重算得到以下结果。

| 数据用途 | 正类召回 | 负类特异度 | 最小正类越门裕量 |
| --- | ---: | ---: | ---: |
| 训练集 | 0.206897 | 1.000000 | 0.000504935 |
| 开发验证集 | 0.307692 | 1.000000 | 0.000504935 |

当前模型很少把安全可执行正样本放过固定门。已经越门的正样本又贴近门限，小幅输入漂移
即可改变处置。固定 development fixture 的有效置信度为 0.602367163，且该 fixture
来自训练输入域，只能用于软件 smoke。

正式保留集读取数为 0，运行预检未执行，运行结果和收益不可用。v4 注册常量为空，
registry 目标不存在。assist、assignment、takeover、coalition、control 和 physical
权限全部为 false。

## 后续条件

下一轮使用新的候选版本和新的内容身份，不覆盖或重签 v4。开发阶段至少满足以下固定
条件后，才交 D6 再次独立审计：

1. 固定 0.60 门不降低，训练和开发验证正类召回均不低于 0.80。
2. 训练和开发验证负类特异度均为 1.0。
3. 正类越门最小裕量不低于 0.02。
4. 参数拟合和类别权重只使用训练集；正式保留集负载读取和拟合均为 0。
5. 确定性投影、备用资源、计划版本、联盟、租约和全部权限门保持不变。

通过上述开发门仍不构成准入。D6 独立审计通过后，还需依次完成正式保留集、运行预检、
D3 可归因后继、运行确认、物理窗口、同键规则对照和非退化评估。任一阶段证据不足时
继续使用规则路径。

## v5 后续审计

D4 已按上述开发门形成新的 v5 近邻置信校准对照。原同源 TRAIN/VALIDATION 指标通过
固定门，但 D6 独立审计发现 TRAIN 350/350 均包含查询样本自身，VALIDATION 有 42/75
条与 TRAIN 完全重合。按 raw observable key 或 latent exact key 留组后，正类召回为
0.965517，负类特异度为 0.958904，已不满足“负类特异度等于 1.0”的开发条件。

去除 VALIDATION 完全重合记录后只剩 1 个正类，不能建立独立正类召回或裕量结论。冻结
v4 和 v5 的实际特征维数均为 24。D4 已修正文档中的 64 维误记，不改变候选源码和制品
身份。

main 决定不登记 v5，也不启动正式保留集和运行预检。v5 只作为记忆化开发基线保留。
下一步先构造与现有训练和验证来源独立、可观测输入不重合的开发扰动集。该数据由 main
生成、D6 独立审计，D4 只做离线评价；正式 holdout 继续隔离。
