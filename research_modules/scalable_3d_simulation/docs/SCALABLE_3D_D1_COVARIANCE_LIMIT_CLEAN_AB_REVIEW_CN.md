# D1 协方差限制 clean A/B 复核

## 结论

D1 协方差成对限制向量化通过当前 clean 准入门，默认优化路径可以保留。三轮相同冻结输入
中，D1 融合累计墙钟和单次调用 P95 均稳定下降，完整业务载荷与 reference 相同，内存没有
恶化。

本次结果不关闭 200 对 200 系统实时缺口。候选实时因子均值为 0.215，且证据只有一个
随机种子的三次 2.2 秒短回放。多随机种子、长时增长、跟踪精度、AirSim 和目标硬件容量仍
需单独验证。

## 改动原理

D1 六维状态协方差记为 \(P\)。完成预测、量测更新或固定滞后重放后，系统先限制对角元素，
再限制非对角元素：

\[
P_{ii}\leftarrow\operatorname{clip}(P_{ii},p_{\min},p_{\max})
\]

\[
|P_{ij}|\leq 0.999\sqrt{P_{ii}P_{jj}},\qquad i<j
\]

旧实现遍历六维矩阵的 15 个上三角非对角元素，每个元素单独调用一次标量裁剪。新实现复用
只读上三角索引，一次读取 15 个元素，一次计算对应上界并批量裁剪，随后镜像到下三角。算法
仍为二次复杂度；六维状态下主要收益来自减少高频 Python 标量调用。

优化不缓存任何协方差，也没有跳过预测、更新或重放。原有对角上下界、0.999 相关上界、
对称化、非法状态重置、在线协方差失败关闭和六秒固定滞后窗口保持不变。旧标量路径通过
`vectorized_covariance_limit=False` 保留，便于复核和回归。

## D6 准入

D6 只读取写盘结果，不参与控制。显式 pair 合同逐轮绑定 reference episode、candidate
episode、跨构建语义文件和两份资源记录，不根据目录名称推断实验臂。

准入门包括：

1. 三轮输入的提交、配置、运行配置、场景、种子、规模、时长和观测数一致。
2. 三轮业务语义检查通过，状态有限，在线真值使用为 0，所有进程正常退出。
3. D1 融合三轮均更快，聚合下降至少 5%，单次调用 P95 均值下降。
4. 核心墙钟均值不恶化，至少两轮更快。
5. 最大常驻内存的均值和任一轮增幅均不超过 5%。

所有门控通过，结果为：

```text
d1_optimization_admitted=true
system_realtime_gap_closed=false
```

## 证据边界

本批仅有 seed 1100。三轮重复可检查计时稳定性，不能估计跨场景和跨随机种子的方差。2.2 秒
短回放也不能说明长时固定滞后重放、日志增长和内存增长已经收敛。

业务载荷等价说明优化没有改变本批 D1-D7 在线结果。它不等于跟踪精度验收。本批没有有效的
均方根误差、归一化估计误差平方、归一化创新平方、严格身份交换或航迹连续性结果。

本批采用三维质点世界，没有 AirSim 图像、雷达接口负载、操作系统调度抖动或目标处理器容量。
候选实时因子 0.215 明确低于 1。系统仍需约 4.65 倍的总体吞吐提升才能达到当前短场景的实时
速度，长场景要求可能更高。
