## 审计边界

首轮完成度审计只读取代码、测试定义、README、PLAN、GAP、清单元数据和既有报告。随后 D6
在独立授权下只读打开 D3、D4、D5 正式来源载荷，核验路径、哈希、结构、计数、时间戳、
数值、真值隔离和切分隔离。该读取不是 validation、test 或 future-held-out 的模型消费；
没有运行训练、模型推理、任务分配、降级、相机命令或飞行控制。

状态分为四类：

- **已证实**：当前代码和测试合同直接覆盖该能力，或已有与当前代际一致的正式证据。
- **部分完成**：代码路径存在，但规模、数据代际、独立评价或运行准入未闭合。
- **未完成**：缺少目标要求的模型、实验或交付物。
- **证据不足**：存在文件或旧结果，但无法证明当前代际达到目标。

## 模块结论

### D1 多传感器融合

D1 已实现扫描级批量量测、六维 NED 状态、乱序量测处理、双时间戳、协方差传播、密集航迹
起始和在线真值拒绝。5 至 200 目标的批量合同已有测试定义。现有 200 目标多传感器证据不
完整，部分 200 目标测试只使用雷达。单种子暖机召回率记录为 `0.8183`，低于建议目标
`0.95`，尚无 20 个未见随机种子的置信区间。

主总线中的 D1 航迹摘要没有完整携带 `measurement_timestamp` 和 `arrival_timestamp`。
当前集成在发布总线后仍把对象直接交给下游模块。该实现能支持同进程研究仿真，但尚未证明
D1-D3 通过统一版本化消息闭环运行。

### D2 多目标关联

D2 已实现六维预测、三维马氏门控、`cKDTree` 空间索引、稀疏连通分量、局部匈牙利、
显式 `id_switch_count` 和在线真值拒绝。200 目标软件规模测试存在。

身份连续性尚未通过。既有 200 规模正式样本中只有 `67/90` 可计算严格身份指标，64 个
episode 出现身份交换，累计 562 次。该结果说明当前密集场景的规范航迹合并和身份保持仍是
实质缺口。D2 到 D3 目前主要是同进程顺序调用后再发布总线，独立订阅驱动合同仍未闭合。

### D3 资源分配

D3 规则主线已实现三维可达性、区域候选边、非等量 M 对 N、需求槽、匈牙利、迟滞、计划
版本和过时计划拒绝。学习路径实现有界代价修正、行为克隆、原生近端策略优化、确定性动作
掩码和 exact-R0 回退。

A1 v3 来源已生成 `300/300`，共 3086 帧和 300 个唯一 seed。当前状态为来源已生成、未
训练、未准入。旧行为克隆和旧影子结果不属于 v3 当前代际，不能替代 v3 模型、验证、保留
测试和准入结论。

### D4 分布式协同

D4 已实现中心、二级节点和完全分布式三级降级，包含 epoch、lease、计划版本、过期拒绝、
多成员联盟原子提交和主动降级证据输入。区域资源学习路径包含变长区域图、行为克隆、近端
策略优化、确定性资源投影和规则回退。

A2 v8 TRAIN 来源已生成 `324/324`。当前没有 v8 训练模型，validation/test 来源要在 actor
冻结后另行分配。旧候选仍处于开发或影子状态，不能获得分配、降级、接管、联盟提交或控制
权限。真实通信退化、多 seed 主动降级准确率、二级恢复和双轨合并仍未验收。

### D5 终端视觉关联

D5 已形成完整的软件链：针孔投影和雅可比协方差、匿名局部航迹、时间/视场/极线/射线/
重投影候选门、原生 PyTorch 图网络、受约束聚类、匈牙利中心绑定以及只读
`global_track_id` 门控。200 目标、4 相机、800 节点的稀疏图测试存在，但不能代表 200 个
资源相机的完整 episode。

G1 的高分来自冻结合成范围，真实相机泛化、中心身份绑定和物理收益仍不可用。A3 v3 来源
已生成 `104/104`，development/future-held-out 为 `72/32`，状态为
`source_generated_not_trained`。当前没有 v3 模型、校准阈值或准入 bundle。

### D6 系统评估

D6 已具备规模指标、逐 seed 输出、聚合 JSON、bootstrap 置信区间、七变体矩阵合同、阶段
耗时归因、三维图和中文 Markdown 报告代码。最新 `728/728` 来源已完成 audit-only 载荷
审计：D3/D4/D5 分别为 `300/324/104` episode，阻断项为空，真值泄漏和切分泄漏均为 0。
D3 来源不显式包含六维状态/协方差，D4 来源不包含协方差，D5 来源不包含显式 bbox 或局部
航迹几何，这些均作为生产合同边界告警保留。最终模型评价、中文 Word 生成器及 DOCX 版式
检查尚不存在。

### D7 三维导引

D7 已实现每个分配对独立状态、三维位置比例导引、视觉视线比例导引、NED 符号、加速度
限幅、D3 计划版本、D4 epoch/lease/coalition 和 D5 locked 失败关闭门。200 pair 有限命令
测试存在。

五米在线估计停止与 D6 真值侧物理成功是两个不同口径。当前没有完整时长、至少 20 个未见
seed 的 F1 物理运行和置信区间，也没有证明世界速度、爬升率、转弯率在完整闭环中全部满足
约束。

## 关键验收缺口

1. **学习来源合同完整性**：D6 来源载荷审计已关闭清单、哈希、计数、时间戳、真值和切分
   隔离门。D3/D4 当前来源没有协方差，D3 没有显式六维状态，D5 没有显式 bbox/local-track
   geometry；训练前需由模块 owner 判断是否升级来源合同，D6 不补造字段。
2. **D1/D2 质量**：在冻结的多传感器密集场景上关闭 D1 `0.8183 -> >=0.95` 的召回缺口，
   并降低 D2 的身份交换；必须使用未见 seed 和明确 availability。
3. **统一总线闭环**：D1 航迹发布保留双时间戳；D2、D3 通过版本化消息消费，而不是只依赖
   同进程对象传递。
4. **当前代际训练**：分别完成 A1 v3、A2 v8、A3 v3 的训练、模型卡、权重哈希、显存和
   推理时延记录。训练不能自动打开 assist 或运行权限。
5. **独立评价**：按冻结顺序使用 validation 选模，再一次性使用 test/future-held-out；
   失败后不得围绕保留集重新调参。
6. **规则矩阵与学习对照**：补齐 R0 shard 10-19，形成 R0/G1/A1/A2/A3/C1/F1 同键、同
   seed、同外生输入对照。
7. **物理闭环**：在至少 20 个未见 seed 上运行完整时长 F1，按 D6 离线真值计算五米成功，
   同时报告约束违规、身份交换、重复分配和降级行为。
8. **性能与交付**：解释 200 规模实时倍率不足，记录 CPU/GPU/显存和阶段耗时；生成最终
   三维轨迹、GIF/MP4、中文 Markdown 和 Word 报告。

## 授权顺序

现有 `AUTHORIZE D3 D4 D5 SOURCE GENERATION ONLY` 已完成且不可外推。后续建议按以下门分开
授权，每道门失败时保持规则回退：

1. D6 来源载荷独立审计已经通过，状态为
   `source_integrity_audit_passed_not_training_authorized`；该状态不授予训练或模型消费权限。
2. 下一步需分别授权 D3、D4、D5 执行 train-only，不读取 future-held-out，不授予运行权限。
3. 分别执行 validation 选模和模型冻结；D4 在此之前先冻结独立 validation/test 来源。
4. 对冻结模型执行一次性 test/future-held-out 评价和 D6 独立模型审计。
5. 仅对通过质量门的模型授权 shadow-only，记录回退、时延和非退化结果。
6. 单模型均通过后，才申请 C1/F1 组合运行、完整 R0 对照和物理闭环。
