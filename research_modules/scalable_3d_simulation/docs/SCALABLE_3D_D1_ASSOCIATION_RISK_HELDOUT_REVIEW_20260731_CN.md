# D1 光电关联风险留出审查

## 结论

D1 已完成光电病态投影风险证据、版本化影子分类、主总线持久化和独立离线复算。在线分类
与离线复算 `1015/1015` 一致，说明实现和序列化合同一致。留出集故障事件召回为
`11/13=0.8461538462`，低于预先冻结的 `0.90` 门限。候选未通过性能门。

`d1-eo-pathological-projection-composite-development-v2` 继续默认关闭，只能以
`shadow/evidence_only` 方式采集旁路证据。它不改变 D1 后验、协方差和航迹标识，也不得被
D2 用于拒绝关联。本留出集不得再用于调整 v2 阈值或判据。

## 试验边界

本批次使用 `5d5c174ecc722d9b5dd22f99aca5312494a4c51f` 上的开发工作树，manifest 明确记录
`repository_dirty=true`。结果属于留出执行证据，不是 clean/formal 准入证据。

场景使用 nominal 100v100 和 200v200，seed 为 2000 至 2019，每个 episode 持续 2.0 秒。

`40/40`。4 个严格身份不可用样本的原因与相机无关，因此不进入本分类器性能统计。

冻结的正式基线未改变：producer commit 为
`80e55eb43bc4a5feeac9c9af0d718d461a46401f`，执行计划 SHA-256 为
`b922ff5f95864345efa583da7256935694e5c675529989a659716522a0d7590e`。正式矩阵仍为
`450/900`，只包含 shards 0 至 9；本轮没有启动 shards 10 至 19。

## 分类方法

分类器在光电观测的一对一候选求解后、量测更新前读取旁路风险证据。正分类同时要求：

1. 门内候选不少于 2 个；
2. 已选目标投影位于图像外；
3. 至少一个保留候选投影位于图像内；
4. 检测框面积不大于 4 像素平方；
5. 检测置信度不大于 0.10。

输入只含双时间戳、投影几何、候选竞争、创新协方差、检测框和置信度。真值只在离线侧标注
“相机导致一条全局航迹对应多个真值目标”的事件，不进入在线分类器。

事件和来源去重合同；本轮不实现任何执行侧消费。
