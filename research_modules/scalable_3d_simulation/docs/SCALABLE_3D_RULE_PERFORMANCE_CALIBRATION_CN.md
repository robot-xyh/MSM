# 三维规则全栈性能校准

## 结论

2026 年 7 月 22 日在干净提交 `492979ee122610dac6c503c1aa0f91cef78251ae` 上完成
20、50、100、200 四档规则全栈校准。每档使用 seed 42000 至 42004，共 20 个 episode，
单例仿真时长 2.2 秒。20/20 状态有限，在线真值使用总数为 0，所有 episode 均发布 3 次
版本化分配计划确认。

20 对 20 已达到实时运行，平均实时倍率为 1.362。50、100、200 规模平均实时倍率分别为
0.491、0.185、0.068。200 对 200 尚未达到实时，平均墙钟 32.711 秒，范围为
28.106 至 37.244 秒。

D1 和 D3 的本轮优化有效。200 对 200 五个 seed 中，D1 融合平均 12.103 秒，D3 分配
平均 0.870 秒，D2 关联平均 7.555 秒。D3 已从主要瓶颈降为次要阶段。当前优先级转为 D1
扫描关联与发布、D2 关联与尾部收束、main 模块栈结束阶段。

本批是干净来源的描述性性能校准。episode manifest 未声明正式实验矩阵，D6 因此不把它
计为 formal acceptance。该口径符合当前证据，不应通过目录名称或人工补字段升级。

## 同 seed 对照

历史 200 对 200、seed 42000、2.2 秒 development 结果与当前 clean 结果使用相同场景和
观测数量。历史结果来自脏工作树提交 `ca83b4a328ea5ca2686e42ee9a905cd539b8186d`，只能用于
开发趋势对照。

| 指标 | 历史 development | 当前 clean | 变化 |
| --- | ---: | ---: | ---: |
| 墙钟 | 60.210 s | 28.106 s | 下降 53.3% |
| 实时倍率 | 0.0365 | 0.0783 | 提高 2.14 倍 |
| D1 融合 | 35.115 s | 10.096 s | 下降 71.2% |
| D2 关联 | 6.135 s | 5.862 s | 下降 4.4% |
| D3 分配 | 7.330 s | 1.028 s | 下降 86.0% |

两次运行的在线观测数均为 2,051，D1/D2 航迹数为 201/200，D3 分配数为 200，计划确认
数为 3，D5 binding 数为 4，D7 命令数为 199，在线真值使用为 0。删除墙钟、实时倍率和
阶段耗时后，`summary.json` 的其余内容一致。

该同 seed 全栈对照不是严格因果试验。D1 自身的未缓存/增量路径 A/B 证明逐扫描语义、终态
航迹和一致性证据哈希相同，滤波更新减少 98.07%；D3 自身的基准证明规则代价、候选数量、
匈牙利求解和计划输出不变。性能归因以这两个模块内对照为准。

## D6 复核

D6 显式读取 20 个 episode 目录，形成 4 个规模组。每组有 5 个互异 seed，可进行固定随机
种子的 bootstrap 描述。schema 匹配与有限状态均为 1.0，episode 失败原因分布为空。

下列项目保持不可用：生产者声明的 ID Switch、正式学习模型指纹、学习 assist 采用、D4 区域
建议控制采用和五米接近任务结果。本批没有五米接近事件，且 2.2 秒短时校准不用于评价拦截
成功率。D6 没有把缺失指标补成 0。

## 边界

1. 单例只有 2.2 秒，不能覆盖长历史检查点内存、航迹生命周期、持续机动和物理拦截。
2. 当前没有相同五 seed 的优化前 clean 全栈批次，跨版本速度提升只作为开发趋势。
3. 本批没有 AirSim、真实传感器、真实通信设备或飞控时延。
4. 输出目录约 954 MB，受 Git 忽略规则管理。普通提交只保存本报告、聚合表和哈希。
5. 200 规模实时倍率仍低于 0.08，系统实时性能 P1 继续开放。
