# D3 A1 来源独立评价

## 结论

D3 A1 分配代价残差候选完成了第一轮来源独立离线评价。数据、模型、评价器和输出均通过
完整性检查。预注册总体机器门通过，结果状态为“通过但未准入”。该结论只说明候选在新来源
数据上产生了有限的安全换绑，同时在负类帧保持规则基线。候选尚未进入在线分配、计划发布、
飞行控制或物理拦截流程。

D6 对同一批输入完成独立复算。D6 未调用 D3 的评价和汇总函数，重新核对了生成记录、匿名
数据集、逐帧结果、表格、模型摘要和评价源码。两套结果一致。test 子组教师完全匹配为
`0/25`，说明候选的未见子组泛化仍不足，正式保留集评价不能省略。

## 候选方法

A1 保留 D3 现有规则代价和匈牙利分配器。学习模型只输出有界代价修正：

`最终代价 = 规则代价 + 系数 x tanh(学习残差)`

模型不直接输出目标分配、计划版本或控制命令。修正后的代价仍经过硬禁边、资源容量、
M-to-N 需求完整性、换绑数量、规则成本差、分布外检测和版本检查。任一检查失败时，矩阵和
绑定恢复到同帧规则基线。该结构用于比较学习修正是否能改善困难帧，同时保留确定性安全壳。

## D6 复算

D6 使用独立标准库审计器读取全部制品。审计器强制数据集位于 generation root 的固定子目录，
拒绝符号链接、缺文件、额外文件和校验和不完整。审计过程没有导入 D3 模型、求解器、评价器
或聚合函数。

D6 从 292 个数据帧重新计算 split SHA-256 和每帧规则成本矩阵 SHA-256。固定 21 列 CSV
与 JSONL 逐行闭合，不一致数为 0。审计器随后从动作掩码、目标需求槽和资源容量复算 R0、
候选和有效三组选择边。每组包含 21,637 条边；三组的索引越界、资源容量超额、硬禁边和
M-to-N 原子性违规均为 0。

D6 得到与 D3 相同的 13/110、8/110、182/182 和 94/94 结果。数据 split SHA-256 为
`f1380dd60fded50b2550e5ce63d6d41bb6066022f9e4b201925978acfa025ca5`。
审计结论为 `offline_integrity_and_preregistered_machine_gate_confirmed_not_admitted`。

## 结果分析

总体门通过说明候选并非恒等于规则基线。110 个正类帧中有 13 帧形成安全离散换绑，其中
8 帧与教师分配完全一致。182 个负类帧全部保持规则绑定，当前来源上没有用错误换绑换取
正类变化。安全投影拒绝 94 帧，表明确定性约束仍是主要保护机制。

分组结果存在差异。train、validation、test 的教师完全匹配分别为 `5/65`、`3/20`、
`0/25`。test 子组有 `2/25` 安全换绑，但没有一次与教师完全一致。预注册合同只规定总体
门限，不能在结果产生后增加 test 门限并改写本次判定。该现象仍应作为后续正式评价的重点
风险，不支持当前候选进入默认分配路径。
