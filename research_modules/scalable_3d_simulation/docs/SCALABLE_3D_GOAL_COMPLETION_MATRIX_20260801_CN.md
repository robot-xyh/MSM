## D1 发布性能

D1 新候选只批量计算同一发布帧内二维位置协方差的 95% 误差半径。每条航迹的状态、
协方差、时间戳、谱系、质量分档和 `global_track_id` 保持原格式。默认构造继续使用逐航迹
参考路径；候选只有显式启用时才生效。

冻结回放包含 86 个扫描和 2051 条匿名观测。7 对 fresh process 的候选更快比例为
`7/7`，模块墙钟 P50 从 `0.228742 s` 降至 `0.190582 s`，中位改善
`16.682378%`。配对差 bootstrap 95% 区间为
`[-0.044637, -0.031457] s`。逐扫描后验、协方差、归一化创新平方、门控观测编号、
完整发布载荷和业务操作数均为 7/7 一致。

该结果只关闭一个局部发布热点。它没有修改扩展卡尔曼滤波、乱序量测、协方差限制、
量测时间和到达时间，也不证明 200 对 200 达到实时。候选保持默认关闭，等待完整栈多 seed
复核后再决定是否接线。

## R0 规则基线

正式 R0 仍为 20 个分片中的 shard 0-9，共 450 个单元。已完成单元均为有限状态，在线
真值使用为 0；严格身份指标在 414/450 个 episode 可用。100 对 100 和 200 对 200 的
累计平均实时倍率仍约为 `0.447` 和 `0.193`。

本轮不运行 shard 10-19。磁盘保护、归档和删除授权边界不变，不能用 D1 局部性能候选、
学习开发数据或离线诊断替代剩余正式 R0。

## G1 跨视角图网络

G1 已具备匿名局部航迹图、几何门控、边分类、受约束聚类、合成 held-out 和 D6 审计。
模型仍无编号创建或改写权限。现有高分只来自合成匿名候选图，没有覆盖代表性相机外参
误差、检测漏失、真实纹理和物理闭环。

本轮没有新增 G1 episode、授权文件或运行作用域。G1 继续只具备申请受控影子评价的条件，
不能进入默认关联链。

## A1 分配代价修正

D3 对 v2 的 100 个 episode、292 帧和 seed `20000-20099` 完成只读失败归因。
test 正类教师完全匹配仍为 `0/25`。其中 9 帧确认由特征分布外触发规则回退，16 帧在
非分布外条件下已经出现候选动作不匹配。22 帧同时经历安全投影拒绝，但没有一帧在投影前
已经精确命中教师，因此安全投影不是 `0/25` 的唯一直接原因。

v2 没有保存逐边候选集合、逐边模型排序和匿名需求槽映射。候选不可达、排序误差和需求槽
结构三类原因不能继续拆分，保持 unavailable。94 个拒绝帧全部恢复 exact R0，正式 seed
读取为 0，运行、分配、计划、控制和生产权限均为 false。

v3 只冻结数据请求：15 个场景规模单元、300 个 episode 和 300 个全新 seed。当前尚未
分配 seed，也没有生成、训练或调阈值。新来源必须直接保存匿名候选边可达性、逐边残差
排序、动作掩码、需求槽结构和投影前后原因。

## A3 主动视觉策略

D5 使用来源独立的三维质点语料完成一次固定配置行为克隆。语料包含 100 个 episode 和
159502 个样本，train/validation/test 为 `95040/24329/40133`。配置在训练前冻结，
只运行一次；test 没有参与训练或选模，正式 seed 样本读取和运行均为 0。

test 精确动作准确率为 `0.959958`，但该数值主要由多数动作贡献。宏平均意图召回为
`0.495507`，`observe_target` 和 `search_sector` 召回均为 0；拦截机和侦察机的精确
动作准确率分别为 `0.972377` 和 `0.656527`。期望校准误差为 `0.368239`。模型没有
学会两个少数动作，也没有形成可信置信度。

模型前置检查因此失败。paired shadow、assist、近端策略优化、assignment、degradation、
runtime、production、control、camera command 和 `global_track_id` write 均为 false。
规则主动视觉策略继续作为强制回退。完整 cache、bundle 和 47045 字节权重只保存在 ignored
输出，不进入普通 Git 提交。

D6 没有调用 D5 evaluator、corpus gate、precheck 或模型类。审计器独立核对 generation
元数据、33 个 cache 文件、bundle、weights、7 个 D5 源文件和 tracked 证据，并按
state_dict 张量形状重建两层 tanh actor 前向。40133 个 test 样本的逐动作、逐角色、校准
和特征边界分布外指标均在 `1e-6` 内复现 D5 结果。

D6 结论为 `completed_fail_closed_quality_gate`。审计器源码 SHA-256 为
`32e37e0b89ff79068bb776efc4845d128b7421d32f6bdc35edec8b98d59cafd0`，输入路径使用
仓库相对路径，报告和机器结果由 `SHA256SUMS` 绑定。专项 `18 passed`，D6 全量
`1384 passed, 1 warning`。该审计确认失败可复现，不授予任何运行权限。

## C1 与 F1

C1 需要 G1、A1、A2 和 A3 在独立来源上分别满足准入。F1 还需要 D4 中心/二级/完全
分布式故障矩阵、D7 三维导引和同键 R0 物理非退化。当前任一学习组件都没有运行授权，
因此 C1 和学习版 F1 的正式 episode 仍为 0。

规则版 D1-D7 总线、版本门、联盟门、五米物理判据和失败回退已开发验证。这只能支持
“规则完整链具备研究仿真基础”的结论，不能声明学习组合优于 R0，也不能创建后续阶段标签。

## 保护边界

- 不读取或运行正式 seed `1000-1019` 的 episode 数据用于调参。
- 不运行正式 R0 shard 10-19，不删除、覆盖或跨提交拼接 shard 0-9。
- 不把质点、合成图或 AirSim 结果写成实机能力。
- 不让 D5、D7 或学习模型创建、改写或本地重绑 `global_track_id`。
- 不以总体准确率覆盖少数类失败，不以数据结构门替代模型质量门。
- 不以模块局部性能收益替代完整栈实时性和正式多 seed 证据。
- 不以开发候选、单元测试或运行 ACK 替代运行授权和物理结果。
