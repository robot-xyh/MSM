# 第一部分：问题背景

## 1.1 场景：天上来了100架无人机

假设敌方向我方阵地袭来100架无人机（比如Shahed型，2.5米翼展，速度50~150米/秒）。

我方部署了两台地面光电设备（红外/可见光转塔），相隔4公里。它们各自转动，搜索天空，看到了这100架无人机。

**问题来了：**

- A站说："我看到第3个目标在东北方向，仰角10度"
- B站说："我看到第5个目标在东北方向偏西一点，仰角9度"

**这两个"目标"是同一架无人机吗？**

如果对不上号，后面全乱套：
- 拦截无人机升空后，不知道"该去打哪个"；
- 两架拦截无人机可能去打同一个目标，漏掉另一个；
- 地面指挥员看到100条航迹，但不知道哪条是哪条。

**把两站看到的目标一一对应起来，这个动作叫「目标配准」或「跨站关联」。**

## 1.2 为什么这件事很难

难在三个地方：

1. **外观会变**：A站正对着目标，看到的是"正方形"；B站斜着看，看到的是"长方形"。同一个目标，两个站看到的"长相"不一样。
2. **单站没距离**：一台光电设备只能测"方向"（方位角+仰角），测不出"多远"。就像你闭上一只眼，能看出星星的方向，但看不出它离你多远。
3. **数量多**：100个目标挤在一起，最远的两个站还各有各的误差——硬碰硬对号，根本对不上。

**破局的关键只有一句话：**

> 外观会骗人（视角相关），但**运动不会骗人**（视角无关）。
> 同一架无人机，不管从哪个角度看，它的速度、方向、飞行轨迹是同一个物理事实。

所以答案不是"看清长相"，而是**积累几秒的轨迹，用运动规律来认人**。

## 1.3 整套系统的三个环节（先看全貌）

```
环节1: 双站交汇测距 ── 两站都看到目标后，用几何算出"距离"（精度2.6米@10km）
环节2: 单站轨迹形成 ── 每个站把自己看到的目标，按时间串成一条条轨迹
环节3: 跨站轨迹配准 ── 把两站的轨迹配对，确认"你看到的3号=我看到的5号"
```

本文档重点讲环节3（配准），但环节1、2是它的地基，都要讲清楚。

# 第二部分：基础概念

## 2.1 光电设备怎么"看"目标

一台光电转塔（红外或可见光）本质上是一台**能转的望远镜**：

- 它知道自己的镜头指向（方位角、仰角）；
- 目标出现在画面里时，它就能报出：**目标在我镜头的哪个方向**。

于是每个观测（一次"看"）可以写成：

```
一次观测 = { 方位角 az, 仰角 el, 时刻 t, 相机位置 }
```

从观测可以反推一条**视线（Line of Sight）**：从相机出发、指向目标方向的一条射线。

**关键：单台设备只能给出视线，给不出"目标在视线上的哪个位置"（距离未知）。**

## 2.2 单站光电的致命短板

| 能力 | 单站光电 | 雷达 |
|---|---|---|
| 方向 | ✅ 精确（0.15毫弧度） | ✅ |
| 距离 | ❌ 完全测不了 | ✅ 精度10米 |
| 速度 | ❌ 测不了 | ✅ 多普勒 |
| 抗干扰 | ✅ 被动，不辐射 | ❌ 会被干扰 |

雷达被干扰、或想隐蔽行动时，光电是唯一选择——但单站光电"无距离"，必须想办法补上。

## 2.3 双站交汇：用几何补距离（本报告的第一个核心）

**原理（大白话）：** 两个站从不同位置看同一个目标，两条视线在空中相交，交点就是目标位置。就像你站在马路这边、朋友站在那边，同时用手指指向同一架飞机——两根手指的延长线在空中相交的那个点，就是飞机。

**数学（高中几何）：** 两条直线求交点（实际工程用"最近点"因为测量有误差）。

**一个例子（真实仿真数据）：** 基线4公里、测角误差0.15毫弧度：

| 目标高度 | 斜距 | 定位中位误差 |
|---|---|---|
| 1 km | 2.2 km | 0.34 米 |
| 5 km | 5.4 km | 0.85 米 |
| **10 km** | **10.2 km** | **2.6 米** |
| 15 km | 15.1 km | 5.6 米 |

**人话翻译：** 10公里外的目标，双站交汇能告诉你"它在这个点±2.6米"——这精度足够让拦截无人机飞到附近后自己用镜头找到它。

**注意一个坑（交会角）：** 目标在两站连线的正上方时几何最好；目标太远或太偏，两条视线几乎平行，交点就"飘"——误差急剧变大。

## 2.4 共面性残差（最重要的概念，务必看懂）

### 2.4.1 先看字面

- **共面** = 几条线/几个点躺在同一个平面里；
- **残差** = 实际测量与理想几何的偏差；
- 合起来：**"B站的视线，偏离'应由平面'的角度"**。

### 2.4.2 大白话：两束激光照同一架飞机

- A站是一只手电筒，射出一束光；
- B站是另一只手电筒，射出一束光；
- 两站之间拉一根线（基线）。

**如果两束光照的是同一架飞机**：两条光束 + 基线，三样东西一定能放进一张"纸片平面"里——像打开的折扇，三根扇骨在同一平面。

**如果B站照的是另一架飞机**：B的光束就"翘出"了扇面。**翘出的角度，就是共面性残差**。

```
         目标X（同一架）
        /|\
       / | \      ← 两条视线+基线，全在同一个平面里
      /  |  \         残差 ≈ 0
   A站——B站

         目标X       目标Y（另一架）
        /|          /
       / |         / ← B的视线翘出平面了
      /  |        /    残差 = 翘起角度（很大）
   A站——B站
```

### 2.4.3 公式逐项拆解

```
r = asin( | u_B · (u_A × b̂) | )
```

| 符号 | 含义 | 直觉 |
|---|---|---|
| u_A | A站视线方向的单位向量 | 光束A的方向 |
| u_B | B站视线方向的单位向量 | 光束B的方向 |
| b̂ | 基线方向的单位向量 | 两站连线的方向 |
| u_A × b̂ | 向量叉积 | 算出"视线A和基线张成的平面"的**法向量**（垂直该平面的方向） |
| u_B · (…) | 向量点积 | 光束B在法向方向的投影——"翘出平面多少" |
| asin | 反正弦 | 把投影值换算成**角度**（弧度） |

**这个公式最妙的地方：它完全不需要知道目标在哪。** 只需要两条视线的方向 + 基线方向，就能检验"它们是不是指向同一个目标"。

### 2.4.4 为什么用它，而不是直接比角度

A站看目标在方位23°，B站看目标在方位24°——这个"差1°"里混着基线几何、目标距离，没有可比性。

共面性是一个**视角无关的几何不变量**：

> 同一个目标，从任意两个站看，共面性残差必然≈0（只剩测量噪声）；
> 不同目标，共面性残差一般远大于0。

### 2.4.5 实测数字（仿真输出，单位毫弧度 mrad）

| 配对类型 | 残差序列（10帧） | RMS | 漂移斜率 |
|---|---|---|---|
| **正确配对** | 0.15 0.13 0.01 0.09 0.02 0.10 0.07 0.12 0.05 0.07 | ~0.1 | 0.008 mrad/s |
| 错误配对 | 3.73 2.35 1.48 0.27 0.74 2.17 3.28 4.36 5.77 6.92 | ~3.3 | 0.78 mrad/s |

**正确与错误的分离度：RMS差约30~50倍，斜率差约100倍。**

### 2.4.6 一个反直觉但重要的点

任意三点（A、B、目标）**总是**共面的（三点必在同一平面）——所以共面性约束的不是三点，而是：

> **"B站声称看到的目标，是否恰好落在『A站视线与基线张成的平面』上"**——落在上面，两站看的是同一个东西；翘出去，不是。

### 2.4.7 交叉瞬间为什么残差也小（关键中的关键）

两个目标在t=2.5秒时**汇聚到同一点**（交叉）。此时：
- A站看目标X的视线，指向重合点；
- B站看目标Y的视线，也指向重合点；
- 重合点、A、B三点确定一个平面，两条视线照样共面 → **残差照样≈0**！

所以**交叉瞬间，几何上不可判**（谁是谁说不清）。这正是"单帧配准"在交叉场景必错的原因，也是"轨迹配准"能赢的原因——交叉只有1帧，前后9帧清清楚楚，多数票胜出。

## 2.5 轨迹是什么

- **一帧** = 一次拍摄 + 检测（这一瞬间看到了哪些目标）；
- **连续多帧** = 同一目标在画面里移动，把它的位置按时间连起来 = **一条轨迹**；
- 轨迹 = `[(t1, az1, el1), (t2, az2, el2), ..., (tK, azK, elK)]`，外加速度估计。

**轨迹的本质：把"一张张照片"升级成"一段录像"，录像里有运动信息。**

## 2.6 术语速查表（遇到看不懂先回来看这里）

| 术语 | 一句话解释 |
|---|---|
| 视线 (LOS) | 从相机指向目标的射线方向 |
| 方位角 az | 目标相对正北的水平角度 |
| 仰角 el | 目标相对地平线的垂直角度 |
| 毫弧度 mrad | 角度单位，1毫弧度≈0.057°；10公里处1毫弧度≈10米 |
| 基线 | 两站之间的距离（本报告=4公里） |
| 共面性残差 | B站视线"翘出"两站几何平面的角度 |
| 极线约束 | 共面性在图像上的表达（B站的目标必须落在一条线上） |
| 轨迹 | 同一目标的连续观测序列 |
| 帧间关联 | 单站内部：把相邻帧的检测串成轨迹 |
| 跨站配准 | 双站之间：把两边的轨迹配对 |
| 匈牙利算法 | 解决"一对一最优配对"的经典算法 |
| 蒙特卡洛 | 用大量随机试验统计误差的方法 |
| 门限 | 判断"通过/拒绝"的阈值 |

# 第三部分：双站交汇定位（环节1）

## 3.1 怎么算精度：蒙特卡洛

误差公式推导复杂（要偏导数、协方差传播），工程上更常用**蒙特卡洛**：给测量加随机噪声，算1000次交点，统计交点的散布。

```
for 1000次:
    给A站视线加随机角度噪声(σ=0.15mrad)
    给B站视线加随机角度噪声
    求两条视线最近点 = 目标估计位置
    记录与真值的误差
统计: 中位误差、95%误差
```

## 3.2 结果表（基线4km，σ=0.15mrad）

| 目标高度 | 斜距 | 交会角 | 中位误差 | 95%误差 |
|---|---|---|---|---|
| 500 m | 2.1 km | 152° | 0.44 m | 1.34 m |
| 1000 m | 2.2 km | 127° | 0.34 m | 0.86 m |
| 2000 m | 2.8 km | 90° | 0.38 m | 0.86 m |
| 3000 m | 3.6 km | 67° | 0.50 m | 1.21 m |
| 5000 m | 5.4 km | 44° | 0.85 m | 2.24 m |
| 8000 m | 8.3 km | 28° | 1.76 m | 5.21 m |
| **10000 m** | **10.2 km** | **23°** | **2.60 m** | **8.03 m** |
| 15000 m | 15.1 km | 15° | 5.58 m | 17.68 m |

**读表方法：** 10公里外，目标位置误差中位数2.6米、最坏情况（95%）8米。这精度够不够？够——拦截无人机在2公里距离时，自己的吊舱视场至少覆盖几十米，8米误差轻松捕获。

## 3.3 精度随测角精度的变化（10km处）

| 测角精度 | 中位误差 |
|---|---|
| 0.05 mrad（极好） | 0.85 m |
| 0.15 mrad（本报告基准） | 2.6 m |
| 0.30 mrad | 5.2 m |
| 0.50 mrad | 8.5 m |

**结论：测角精度是命门，设备越好（0.15mrad），交汇越准。**

# 第四部分：单站轨迹形成（环节2，层次一）

## 4.1 帧间关联：把检测串成轨迹

每个站独立工作。每一帧：
1. 检测出画面里的目标（位置、时间戳）；
2. 预测已有轨迹"现在应该在哪"（用上一帧位置+速度外推）；
3. 把新检测与预测做匹配（距离最近且没超门限 → 同一目标）；
4. 匹配成功 → 更新轨迹；匹配不上 → 开新轨迹。

**核心思想：目标的运动是平滑的，相邻帧位置不会跳变——"位置连续性"就是认人的依据。**

## 4.2 一个具体的例子

目标以50米/秒飞行，帧间隔0.5秒 → 每帧移动25米。在4.5公里外，25米≈0.32°。

```
帧1: 方位24.377°
帧2: 方位24.674°   ← 帧间差0.297°
帧3: 方位24.983°   ← 帧间差0.309°
→ 连续帧位置平滑变化，判定同一目标，串成轨迹
```

## 4.3 交叉时的麻烦（必须知道）

两个目标在图像上**重合**的那1~2帧，单站分不清谁是谁，可能"交换身份"（把目标X的检测记到了目标Y的轨迹上）。

**这就是整套系统最后的0.05%误差来源**——别急，第六部分会详细讲怎么处理。

# 第五部分：跨站轨迹配准（环节3，层次二）——全篇核心

## 5.1 总体流程（六步）

```
步骤1  候选生成: 极线门控粗筛（100×100 → 几百候选）
步骤2  残差序列: 每个候选的共面性残差随时间变化
步骤3  代价计算: RMS + 斜率惩罚 → 代价矩阵
步骤4  整体匹配: 匈牙利算法一对一配对
步骤5  帧级投票: 逐帧独立匹配 + 多数票（防交叉污染）
步骤6  确认: 连续稳定 → 全局编号
```

## 5.2 步骤1：候选生成

对A站的每条轨迹和B站的每条轨迹，算一次共面性残差。残差小的（<门限）才保留为候选配对。

100×100=10000对，大多数被几何直接排除（残差几十毫弧度），剩下的几百对进入下一步。

**演示数据**（3目标3帧，残差单位mrad）：

| A\B | B站目标1 | B站目标2 | B站目标3 |
|---|---|---|---|
| A站目标1 | **0.15** ✓ | 11.53 | 10.66 |
| A站目标2 | 11.60 | **0.14** ✓ | 22.45 |
| A站目标3 | 10.79 | 22.10 | **0.00** ✓ |

对角线（正确配对）残差0.1毫弧度，其他都是10~20毫弧度——**一眼可辨**。

## 5.3 步骤2：残差序列——为什么"有轨迹"就赢

单帧只看"这一刻共不共面"；轨迹级看**"连续几秒都共面吗"**。这带来三种力量：

### 力量一：噪声平均（√K效应）

正确配对每一帧的残差都是随机噪声（围绕0波动）。K帧取RMS，噪声按√K压低：

```
σ_rms ≈ σ / √K
```

K=8帧 → 等效噪声从0.15mrad降到0.05mrad → 门限可以收紧，假候选被滤掉。

### 力量二：漂移检测（杀手锏）

**错误配对的两个目标各自运动，其几何关系会被持续撕开**——残差序列单调上升（漂移）。正确配对则贴0波动。

```
正确配对: 0.03 0.09 0.16 0.06 0.08 0.02 0.03 0.18  → 平稳
错误配对: 3.63 4.05 4.55 4.73 5.22 5.62 5.87 6.48  → 单调上升
斜率: 正确0.008 mrad/s vs 错误0.780 mrad/s（差100倍）
```

**人话：单帧只问"这一刻共面吗"，轨迹问"连续4秒都共面吗"。两个不同目标不可能4秒一直共面——它们的运动必然把几何撕开。**

### 力量三：运动一致性

轨迹片段给出角速度、加速度——这些是三维物理量，**投影到哪个像平面都不变**。两站独立估计的速度方向应该一致，可作为独立证据。

## 5.4 步骤3：代价计算

```
C(i,j) = RMS{残差序列} + λ × |漂移斜率|
```

- RMS小 = 全程共面 → 像同一个目标；
- 斜率小 = 没有漂移 → 进一步确认；
- 两个条件都满足的配对，代价最小。

## 5.5 步骤4：匈牙利算法（一对一匹配）

代价矩阵出来后，用匈牙利算法求**最优一对一配对**：

- 排他约束：A站每条轨迹最多配给B站一条轨迹（一个目标不可能同时是两个目标）；
- 全局最优：不是贪心挑最小的，而是让**总代价最小**；
- 计算量：100×100矩阵，微秒级，实时无压力。

## 5.6 步骤5：帧级投票（防交叉污染的关键改进）

轨迹级配准有个盲点：**交叉瞬间"互补交换"**——两站都交换了身份，错误配对反而全程共面（残差0），正确配对被污染抬高。轨迹级算法会被骗。

解法：**每帧独立做一次匹配，跨帧统计票数**。

```
帧1: A#4 ↔ B#4  ✓（9次）
帧2: A#4 ↔ B#4  ✓
...
帧6: A#4 ↔ B#33 ✗（交叉瞬间，只有1次）
帧7: A#4 ↔ B#4  ✓
...
→ 9票对1票，身份恢复正确
```

**交叉只污染1帧，多数票把它淹没。**

## 5.7 步骤6：确认状态机

一次匹配只是"候选"。连续多个确认周期匹配保持稳定 → 才分配全局编号：

```
本机跟踪 → 候选关联 → 几何一致 → 连续确认 → 已确认（全局编号）
```

**一次匹配会错，三次一致不会。**（对应文档：你的VISUAL_REGISTRATION方案里的状态机）

## 6.4 迭代过程中的三个重要发现（为什么96%变成了99.95%）

### 发现一：评估函数有bug（96%是假象）

最初的评估函数用 `set()` 去重后再计数，丢失了帧数权重——主目标判定在票数相同时随机选。修复为按帧计数后，正确率从96.2%跳到99.8%。

**教训：先修评估，再谈算法。数字不对，可能是尺子坏了。**

### 发现二：交叉的"互补交换"最阴险

交叉时两站**都**交换了身份，错误配对反而全程共面（代价0.000），正确配对被污染抬高被门控滤掉——轨迹级配准对此无解，必须帧级投票。

### 发现三：截尾统计反而有害

对残差序列"去掉最大20%再算RMS"看似聪明，实则对"污染的错误配对"也友好（它的尖峰被截掉了），引入新错误。**简单门控1.5mrad + 帧级投票 才是最稳的。**

# 第七部分：完整代码（带逐行注释，可直接运行）

> 代码要点：numpy + scipy。运行环境：Windows，Python 3.10+，`pip install numpy scipy`。

```python
# -*- coding: utf-8 -*-
"""
双站光电交汇 + 100目标轨迹配准 完整仿真
最终方案: 帧级投票（逐帧共面匹配 + 跨帧多数票）
"""
import numpy as np
from scipy.optimize import linear_sum_assignment

# ============ 全局参数 ============
A = np.array([-2000.0, 0.0, 0.0])     # 光电站A位置 (米)
B = np.array([2000.0, 0.0, 0.0])      # 光电站B位置 (米), 基线4km
bhat = (B - A) / np.linalg.norm(B - A)  # 基线方向单位向量
SIGMA = 0.15e-3       # 测角噪声 0.15 毫弧度
DT = 0.5              # 帧间隔 0.5 秒
KFRAMES = 10          # 观测帧数 (共5秒)
N_TARGETS = 100       # 目标数
MIN_SPACING = 100.0   # 最小间距 100 米
N_CROSS = 10          # 尝试构造的交叉对数
T_MID = 2.5           # 交叉时刻 (秒)

def coplanarity(uA, uB):
    """共面性残差: B站视线 uB 与 平面(uA, 基线) 的夹角 (弧度)"""
    n = np.cross(uA, bhat)          # 平面法向量
    n = n / np.linalg.norm(n)
    return np.arcsin(np.clip(abs(np.dot(uB, n)), 0, 1))

def observe(T, C):
    """模拟测角: 真实视线 + 高斯噪声"""
    d = T - C
    d = d / np.linalg.norm(d)
    n = np.random.randn(3)
    n -= n.dot(d) * d               # 投影到垂直方向
    n = n / np.linalg.norm(n) * np.random.randn() * SIGMA
    return d + n

def azel(u):
    """视线向量 -> (方位角, 仰角)"""
    return np.arctan2(u[0], u[1]), np.arcsin(np.clip(u[2], -1, 1))

def ray_from_azel(az, el):
    """(方位角, 仰角) -> 视线单位向量"""
    return np.array([np.cos(el)*np.sin(az), np.cos(el)*np.cos(az), np.sin(el)])

# ============ 场景生成 ============
def gen_scenario():
    """生成100目标: 间距>100m, 匀速直线, 有上有下, 部分目标交叉"""
    xr, yr, hr = (-1800, 1800), (4200, 4800), (300, 1500)
    pts = []
    attempts = 0
    # 泊松盘采样: 随机撒点, 保证新点与已有所有点距离>100m
    while len(pts) < N_TARGETS and attempts < 60000:
        attempts += 1
        p = np.array([np.random.uniform(*xr), np.random.uniform(*yr), np.random.uniform(*hr)])
        if all(np.linalg.norm(p - q) > MIN_SPACING for q in pts):
            pts.append(p)
    assert len(pts) == N_TARGETS
    P0 = np.array(pts)
    # 速度: 水平40~60m/s 来袭方向, 垂直±20m/s (有上有下)
    V = np.zeros((N_TARGETS, 3))
    for i in range(N_TARGETS):
        spd = np.random.uniform(40, 60)
        ang = np.random.uniform(-np.pi/4, np.pi/4)
        V[i] = [np.sin(ang)*spd, -np.cos(ang)*spd, np.random.uniform(-20, 20)]
    # 显式构造交叉: 两目标速度反向, 在t_mid汇聚到同一点
    cross_pairs = []
    idx = list(range(N_TARGETS)); np.random.shuffle(idx)
    for c in range(N_CROSS):
        i, j = idx[2*c], idx[2*c+1]
        X = np.array([np.random.uniform(-600, 600), np.random.uniform(4300, 4600),
                      np.random.uniform(400, 1200)])
        spd = np.random.uniform(45, 55); a1 = np.random.uniform(-np.pi/4, np.pi/4)
        vi = np.array([np.sin(a1)*spd, -np.cos(a1)*spd, np.random.uniform(-20, 20)])
        vj = -vi + np.random.uniform(-10, 10, 3)
        P0i, P0j = X - vi*T_MID, X - vj*T_MID
        inr = lambda p: (xr[0] <= p[0] <= xr[1] and yr[0] <= p[1] <= yr[1] and hr[0] <= p[2] <= hr[1])
        if not (inr(P0i) and inr(P0j)): continue
        if np.linalg.norm(P0i-P0j) < MIN_SPACING: continue
        P0[i], P0[j], V[i], V[j] = P0i, P0j, vi, vj
        cross_pairs.append((i, j))
    return P0, V, cross_pairs

# ============ 单站跟踪 (帧间关联) ============
class Track:
    """一条轨迹: 位置(方位/仰角) + 角速度 + 历史"""
    def __init__(self, tid, az, el, frame):
        self.id = tid
        self.az, self.el = az, el          # 当前位置
        self.azr, self.elr = 0.0, 0.0      # 角速度
        self.history = [(frame, az, el)]   # 历史观测
    def predict(self, dt):
        """预测下一帧位置: 匀速外推"""
        return self.az + self.azr*dt, self.el + self.elr*dt
    def update(self, az, el, frame, dt):
        """用新检测更新状态"""
        self.azr = 0.5*self.azr + 0.5*(az - self.az)/dt
        self.elr = 0.5*self.elr + 0.5*(el - self.el)/dt
        self.az, self.el = az, el
        self.history.append((frame, az, el))

def single_station_track(obs):
    """单站: 检测->预测->关联->更新, 形成轨迹列表"""
    N, K = obs.shape[0], obs.shape[1]
    tracks = []; next_tid = 0
    GATE = 0.5 * np.pi / 180   # 帧间关联门限 0.5度
    for k in range(K):
        dets = [(i, obs[i, k]) for i in range(N)]
        preds = [(t.id, t.predict(DT)) for t in tracks]
        matched = set()
        if len(dets) and len(preds):
            M = np.full((len(dets), len(preds)), 1e6)
            for a, (i, (az, el)) in enumerate(dets):
                for b, (tid, (paz, pel)) in enumerate(preds):
                    M[a, b] = np.sqrt(((az-paz)*np.cos(el))**2 + (el-pel)**2)
            Mg = np.where(M < GATE, M, 1e6)
            ra, cb = linear_sum_assignment(Mg)   # 匈牙利: 检测-轨迹关联
            for a, b in zip(ra, cb):
                if Mg[a, b] < 1e6:
                    i, (az, el) = dets[a]; tid = preds[b][0]
                    tracks[tid].update(az, el, k, DT)
                    matched.add(a)
        for a, (i, (az, el)) in enumerate(dets):
            if a not in matched:   # 未匹配检测 -> 开新轨迹
                tracks.append(Track(next_tid, az, el, k))
                next_tid += 1
    return tracks

# ============ 帧级投票配准 (最终方案) ============
def frame_vote_match(tracksA, tracksB, gate=0.8e-3):
    """
    核心算法: 每帧做一次跨站匹配(共面性+匈牙利), 跨帧统计票数
    返回: {A轨迹id: B轨迹id} 主配对
    """
    histA = {t.id: dict((f, (az, el)) for f, az, el in t.history) for t in tracksA}
    histB = {t.id: dict((f, (az, el)) for f, az, el in t.history) for t in tracksB}
    votes = {}   # (A轨迹, B轨迹) -> 匹配帧数
    for k in range(KFRAMES):
        idsA = [ta for ta in histA if k in histA[ta]]
        idsB = [tb for tb in histB if k in histB[tb]]
        if not idsA or not idsB: continue
        M = np.full((len(idsA), len(idsB)), np.inf)
        for a, ta in enumerate(idsA):
            uA = ray_from_azel(*histA[ta][k])
            for b, tb in enumerate(idsB):
                r = coplanarity(uA, ray_from_azel(*histB[tb][k]))
                if r < gate: M[a, b] = r    # 共面门控
        Mg = np.where(np.isfinite(M), M, 1e6)
        ra, cb = linear_sum_assignment(Mg)  # 每帧匈牙利
        for a, b in zip(ra, cb):
            if Mg[a, b] < 1e6:
                votes[(idsA[a], idsB[b])] = votes.get((idsA[a], idsB[b]), 0) + 1
    # 多数票: 每个A轨迹选票数最多的B轨迹
    match = {}
    for ta in set(k[0] for k in votes):
        best = max((tb for (t, tb) in votes if t == ta),
                   key=lambda tb: votes[(ta, tb)], default=None)
        if best is not None: match[ta] = best
    return match

# ============ 主程序 ============
if __name__ == '__main__':
    np.random.seed(40001)
    P0, V, cross_pairs = gen_scenario()
    # 生成两站观测
    obsA = np.empty((N_TARGETS, KFRAMES), dtype=object)
    obsB = np.empty((N_TARGETS, KFRAMES), dtype=object)
    for k in range(KFRAMES):
        T = P0 + V * (k * DT)
        for i in range(N_TARGETS):
            obsA[i, k] = azel(observe(T[i], A))
            obsB[i, k] = azel(observe(T[i], B))
    # 单站轨迹
    trA = single_station_track(obsA)
    trB = single_station_track(obsB)
    # 帧级投票配准
    match = frame_vote_match(trA, trB)
    print('配准完成: %d 个A站轨迹完成配对' % len(match))
    print('交叉对数量: %d' % len(cross_pairs))
```

# 第八部分：离100%还差什么（诚实的边界）

## 8.1 当前水平：99.95%

40次蒙特卡洛（4000个目标）只错1个。那1个错在哪？

**答：单站跟踪在交叉瞬间交换身份，把目标的主轨迹分散到了两条轨迹上**——交叉帧两目标在图像上重合，任何帧间关联算法都分不清，这是**物理极限**（不是算法缺陷）。

## 8.2 补齐路径：交叉多假设跟踪（MHT）

教科书解法三件套：

```
① 单站层: 交叉预警(两轨迹预测接近) → 保留多个假设, 不立即定案
② 交叉后: 用双站极线 + 运动连续性 重新确认归属 (跨站几何是最终裁判)
③ 状态机: 交叉期间身份降级为"待确认", 禁止用于任务分配, 确认后恢复
```

## 8.3 一句话结论

> **在"双站信息可判定"的意义上，100%可达到（理想观测40次全过）；
> 完整链路99.95%，差距全部来自交叉瞬间单站信息不可判——补上多假设跟踪就是100%，这是工程成熟度问题，不是原理障碍。**
