# 航迹级 SuperGlue 候选路线

## 定位

本目录是双站光电独立试验的一条候选关联路线。输入是两站匿名局部航迹、冻结的几何候选边及数值特征，输出是带空匹配能力的一对一航迹关系。该路线借鉴 SuperGlue 的注意力和最优传输结构，不加载或改造原始图像 SuperGlue 权重，也不使用图像关键点描述子。

2026年8月14日已完成20目标五初始化正式训练和V4保留集对照。该路线满足继续到下一规模的安全门槛，但相对图网络的总体按时召回率只提高1.25个百分点，未达到2个百分点的优选门槛，因此没有替换同输入图网络基线。40目标共享跟踪器标定失败，本路线未打开40目标保留集。

目标估计到局部航迹的图网络不属于本路线，也不进入当前主线。

## 算法

每条航迹最多取最近 6 次匿名观测。单层 64 维门控循环单元编码方向、相对时间、置信度和测量质量历史。现有 15 维航迹特征经过多层感知机编码，两部分合成为 64 维航迹描述子。

网络执行两轮注意力更新，每轮包含站内自注意力和双站交叉注意力，每个注意力模块使用 4 个头。现有 18 维几何和运动边特征转换为交叉注意力偏置。共享候选图之外的关系在交叉注意力、相似度矩阵和最优传输输出中始终被屏蔽，模型不能扩大几何候选集合。

相似度矩阵增加空匹配行和空匹配列，并执行 30 次对数域 Sinkhorn 迭代。在线结果依次通过以下确定性检查：

1. 两侧航迹必须互为最高分候选；
2. 分数达到冻结验证阈值；
3. 关系在最近 3 圈中至少出现 2 次；
4. 一条 A 站航迹和一条 B 站航迹最多各发布一次。

## 训练合同

- 优化器：AdamW；
- 学习率：`1e-3`；
- 权重衰减：`1e-4`；
- 丢弃率：`0.1`；
- 最大训练轮数：200；
- 早停耐心值：25；
- 初始化：固定 5 组；
- 验证阈值：`0.3` 至 `0.9`；
- 匹配项损失与空匹配项损失各占 50%。

训练程序在读取任何文件前拒绝含 `test` 条目的标定清单。在线适配器只读取匿名航迹、相机位置、时间、协方差和冻结候选边，不访问 AirSim Actor 名称、真实身份或离线标签。双方均未形成确认航迹的首圈快照没有可训练关系，保留在因果验证序列中检查无证据不输出，但不执行梯度更新。

20目标正式训练使用192个训练快照，其中160个参与梯度优化、32个空首圈快照被跳过。5组初始化分别训练63、77、90、67和63轮后提前停止；初始化3301入选，验证宏平均F1为0.3590，正确关系271个，发布关系313个，冻结阈值为0.3。

## 接口

共享编排调用：

```python
from dual_optical_track_superglue.online_benchmark import (
    freeze_route,
    load_frozen_route,
)

freeze_manifest = freeze_route(calibration_manifest, output_root)
route = load_frozen_route(freeze_manifest)
publication = route.publish(revolution_snapshot)
```

`freeze_manifest.json` 同时提供 `validation_selection` 和 `training_summary.selected_validation`。两处均包含 `macro_f1`、`correct_assignment_count`、`selected_assignment_count` 和 `validation_failed_closed`，供 main 读取。路线名固定为 `track_superglue`。

正式训练和在线发布通过`adapter.adapt_shared_feature_graph(snapshot)`直接复用现有图网络生成的15/18维匿名特征，保证候选关系未通过精细几何门时也使用相同的哨兵值。`adapter.adapt_frozen_graph(graph, snapshot)`用于接入已有冻结图，`adapter.adapt_snapshot(snapshot)`仅保留为独立兼容入口。三种适配都不扩大共享候选边白名单。

## 测试

从项目根目录运行：

```bash
pytest -q research_modules/independent_experiments/dual_optical_track_superglue/tests
```

测试默认使用中央处理器。检测到CUDA时，可选图形处理器用例才会运行。2026年8月14日V4运行后共21项测试通过，覆盖张量尺寸、掩码、空匹配行列、Sinkhorn数值和边缘和、一对一输出、时间确认、在线真值隔离、15/18维特征等价、空首圈训练处理、main冻结接收、权重保存加载及共享发布数据类型。

20目标保留集宏平均F1为0.4111，按时召回率为0.3392，条件正确率为0.8925，错误关系98个，P95端到端时延为440.98毫秒。相对图网络，中重干扰按时召回率提高5.25个百分点，配对差值95%置信区间下限为2.50个百分点；总体按时召回率仅提高1.25个百分点，因此只获得继续对照资格。

## 限制

- 当前只有20目标正式训练权重和保留集结果；
- 当前只证明在20目标中重干扰和错误关系数量上优于同输入图网络，尚未达到总体召回优选门槛；
- 共享单站跟踪器和候选图若删除了正确关系，本路线无法恢复；
- 40目标因共享单站跟踪器P95耗时至少514.78毫秒而停止，尚无大规模候选图吞吐量结论；
- AirSim 真实身份只允许在离线评分文件中使用，不能进入在线发布路径。
