# 航迹级 SuperGlue 实施计划

## 目标

在与现有边图网络完全相同的匿名快照、候选边和数据划分上，评估注意力与部分最优传输是否能改善密集竞争、两侧航迹数量不等和大量空匹配条件下的双站航迹关联。该路线保持候选边白名单、在线身份隔离和两次/三圈确认，不改变共享跟踪器。

## 已完成

- [x] 建立独立可导入包，未修改双站共享编排和现有图网络代码。
- [x] 建立最近 6 次观测的单层 64 维门控循环单元编码器。
- [x] 建立 15 维航迹特征编码和 64 维融合描述子。
- [x] 建立两轮、4 头的站内自注意力和双站交叉注意力。
- [x] 将 18 维边特征接入几何偏置，并在全部网络阶段固定非候选掩码。
- [x] 增加空匹配行列和 30 次对数域 Sinkhorn 求解。
- [x] 增加互为最佳、冻结阈值和最近 3 圈至少 2 次的发布检查。
- [x] 建立 AdamW、五初始化、200 轮、25 轮早停及 `0.3` 至 `0.9` 验证阈值默认合同。
- [x] 将匹配与空匹配损失贡献固定为 50%/50%。
- [x] 建立训练/验证离线标签适配；含测试条目的清单在打开工件前被拒绝。
- [x] 提供 `freeze_route`、`load_frozen_route` 和 `publish` 共享入口。
- [x] 冻结清单提供 main 所需验证摘要字段。
- [x] 正式训练与发布直接复用图网络15/18维特征构建结果，并用逐数组测试固定同输入合同。
- [x] 完成main验证接收、小型冻结工件加载和连续三圈发布冒烟测试；前两圈保持待确认，第三圈执行两次/三圈确认。
- [x] 完成 CPU 单元测试，并保留可选 CUDA 用例。

以上代码完成项已在20目标V4正式训练和保留集对照中使用；40目标尚未进入本路线。

## 明确不做

- 不加载原始图像 SuperGlue 权重；
- 不读取在线 AirSim Actor 名称或真实身份；
- 不用学习模型增加共享候选边；
- 不使用保留测试标签选择阈值、初始化或网络参数；
- 不把目标估计到局部航迹的图网络纳入当前主线；
- 不因增加候选路线删除现有边图网络基线。
