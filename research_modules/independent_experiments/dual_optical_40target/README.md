# 双光电40目标轨迹关联独立试验

本目录验证两个旋转光电节点在AirSim中对40个移动目标形成匿名本地轨迹并完成跨相机一对一关联。试验与D1-D7隔离，不使用中心全局航迹、目标分配合同或D5数据结构。增强链路在原有多时刻恒速拟合和匈牙利分配前增加对称共面性粗筛，在分配后增加Top-5全局假设、延迟确认和重复轨迹片段抑制。

40目标是本目录保留的历史默认场景，不是程序写死的规模。运行入口已经支持`--target-count N`，目标生成、记录和评分可按命令行参数扩展；不同规模必须使用独立的`--output-dir`，避免覆盖40目标正式记录。规模参数可运行不等于相应规模已经通过验收，结论仍以各自种子和结果文件为准。

本目录同时维护统一100目标在线对比中的“增强极线/多假设/匈牙利”路线适配。第二版路线标识为`enhanced-geometry-online-v2`，消费main生成的匿名因果快照和冻结参数；统一场景、共享跟踪器、数据划分、三路线调度及最终评分仍由`dual_optical_online_benchmark/`管理。该接口不改变本目录40目标历史结果，也不把统一对比结果回写为40目标能力。

## 运行

从项目根目录执行：

```bash
python3 research_modules/independent_experiments/dual_optical_40target/run_experiment.py
```

默认启动一次Blocks，完成3米目标网格预检，reset后运行种子20260811的12秒正式试验，最后关闭Blocks并生成中文报告。默认不保存AirSim相机PNG；需要调试图像时显式增加`--save-keyframes`。

运行100目标时显式设置目标数、随机种子和独立输出目录，例如：

```bash
python3 research_modules/independent_experiments/dual_optical_40target/run_experiment.py \
  --target-count 100 \
  --seed 20260813 \
  --output-dir research_modules/independent_experiments/dual_optical_40target/outputs/manual_dense100_seed20260813
```

上述目录名用于新试验，避免覆盖已冻结的正式100目标记录。其他目标数量沿用同一命令格式，只需同步修改`--target-count`、`--seed`和`--output-dir`。

外部已经启动匹配settings的Blocks时可使用：

```bash
python3 research_modules/independent_experiments/dual_optical_40target/run_experiment.py --no-launch
```

已有完整记录时，可在不启动AirSim的条件下重新生成图表和报告：

```bash
python3 research_modules/independent_experiments/dual_optical_40target/run_experiment.py \
  --report-only \
  --output-dir research_modules/independent_experiments/dual_optical_40target/outputs/airsim_seed_20260811_epipolar_mht_run01
```

算法更新后，可只用已保存的匿名轨迹重算增强关联，不重新启动AirSim：

```bash
python3 research_modules/independent_experiments/dual_optical_40target/run_experiment.py \
  --report-only --reprocess-enhanced \
  --output-dir research_modules/independent_experiments/dual_optical_40target/outputs/airsim_seed_20260811_epipolar_mht_run01
```

将正式中文报告转换为Word：

```bash
python3 research_modules/independent_experiments/dual_optical_40target/build_word_report.py \
  --source research_modules/independent_experiments/dual_optical_40target/outputs/airsim_seed_20260811_epipolar_mht_run01/DUAL_OPTICAL_40TARGET_AIRSIM_REPORT_CN.md
```

Word生成器采用A4版式。当前增强报告包含17幅正文图、7幅公式图和5张表，并检查待办清单与媒体文件是否完整。

## 输出

默认输出目录为：

`research_modules/independent_experiments/dual_optical_40target/outputs/airsim_seed_20260811_epipolar_mht_run01/`

该默认目录对应40目标增强历史试验。动态目标数运行必须使用新的输出目录；正式2千米密集100目标记录位于`outputs/airsim_seed_20260813_dense100_run01/`。

- `online/`：匿名检测、扫描状态、本地轨迹、旧版候选与匹配，以及第二版共面性证据、Top-5假设、状态时间线、片段抑制和几何敏感性；
- `truth/`：只供运行结束后评分的Actor身份和真实轨迹；
- `keyframes/`：默认只有空清单；显式启用调试开关时才保存相机关键帧；
- `figures/`：三维场景、扫描、本地轨迹、算法流程、双视线拟合原理、代价矩阵和40目标配准效果图；
- `metrics.json`：验收指标；
- `DUAL_OPTICAL_40TARGET_AIRSIM_REPORT_CN.md`：中文实验报告；
- `DUAL_OPTICAL_40TARGET_AIRSIM_REPORT_CN.docx`：嵌入图表和公式的Word实验报告。

## 实测结果

2026年8月10日完成种子20260810的单次正式AirSim试验，有效记录位于`outputs/airsim_seed_20260810_run11/`。两台相机均检测到全部40个目标，稳定轨迹真值覆盖率均为1.000。A侧形成50条稳定轨迹，B侧形成47条，说明扫描重访过程仍有轨迹碎片。

跨相机关联输出37组关系，其中36组正确、1组错误，准确率为0.973，全目标召回率为0.900。在线真值泄漏为0，平均三维位置拟合误差为0.080米。结果通过本轮95%准确率和80%召回率门限，但未达到40个目标全部正确配准；4个目标未形成正确关系。

实验报告给出针孔反投影、扫描片段聚合、单相机重访成轨、六参数恒速三维拟合、候选门控、综合代价和匈牙利分配的公式与实际门限。配准效果图使用离线真值解释36组正确关系、1组额外误配和4个未正确闭合目标，离线身份不参与在线关联。

2026年8月11日完成种子20260811的增强正式试验，记录位于`outputs/airsim_seed_20260811_epipolar_mht_run01/`。A、B两侧分别形成47条和45条稳定轨迹，均覆盖40个目标。共面性粗筛把2115个全组合缩减为156个六参数拟合，拟合量减少92.6%，40个目标均保留至少一组正确粗筛候选。

最低代价全局解形成38组局部轨迹关系。恒速外推检查发现其中两组关系属于同一条物理轨迹：共同时间的位置差为0.126米，速度差为0.034米每秒。增强输出抑制1组重复片段后保留37组关系，离线评分为37组正确、0组错误、0个重复身份，唯一目标召回率为0.925。28组满足连续确认条件，9组因交叉邻近或竞争假设保持待确认。待确认关系仍是当前最低代价解释，不等同于错误关系，也不能作为已经稳定交付的身份。

旧版全组合拟合耗时约4095毫秒，当前增强原型耗时约12269毫秒。增强方案减少了六参数拟合次数，但Python实现仍逐组合计算共面性序列并回放多个决策周期，因此总耗时尚未下降。下一步性能工作应放在向量化共面性计算和增量状态更新，不能把拟合量减少直接写成实时性提升。

当前跨相机关联在episode结束后批量执行。六参数候选使用完整匿名轨迹拟合一次，再按时间戳回放确认状态；该时间线验证延迟确认逻辑，不代表已经实现每0.5秒在线增量拟合。

0.15毫弧度角噪声、每组1000次采样的模型几何敏感性中，位置变化中位数的跨关系中位值为0.441米，95%分位位置变化的跨关系中位值为0.892米。该结果只反映当前基线和交会角的模型敏感性，不是AirSim测量精度或真实设备指标。

### 2千米密集100目标基线

动态目标数入口已用于正式种子20260813的单次AirSim试验，记录位于`outputs/airsim_seed_20260813_dense100_run01/`。场景沿用2千米双站几何并将目标数设为100，用于检查确定性关联链路在更密集条件下是否仍能完整运行。

基础链路输出97组匹配，其中89组正确、8组错误，准确率为0.9175，全目标召回率为0.89。增强链路输出94组匹配，其中87组正确、7组错误，准确率为0.9255，全目标召回率为0.87。在线真值泄漏计数为0，Actor身份仍只用于运行结束后的离线评分。

本次严格验收未通过。基础链路准确率低于0.95门限，增强链路全目标召回率低于0.90门限。该试验没有注入随机漏检和虚警，只能作为理想检测条件下的单种子密集目标基线，不能写成100目标工程能力已经定型。多种子、漏检与虚警腐化以及图神经网络对照由独立实验目录承担，不并入本目录的确定性默认链路。

### 100目标连续周扫V2专项

2026年8月13日完成统一第二版协议下的9回合预检、30-seed标定和20-seed保留测试。新产物位于`dual_optical_online_benchmark/outputs/formal_v2_24_6_20/`；旧`formal_24_6_20/`继续保留为第一版零匹配失败证据，两组结果不得合并统计。

第二版路线已适配带角速度、测量协方差、状态协方差、轨迹状态和共享跟踪器指纹的快照。入口校验协议、输入、跟踪器和冻结参数指纹，拒绝外来或被改写的数据。关联仍采用确定性几何路线：归一化共面性筛选、多时刻轨迹拟合、协方差门控、匈牙利一对一分配、最多3个全局假设和三圈两次确认。在线过程不读取AirSim真实身份；训练数据只用于输入审计，不训练学习参数。

预检使用种子`20270001-20270003`，分别运行理想、姿态误差和完整干扰场景，共9个回合。3米运动初始化残差门和单个全局假设只用于预检早停。三类场景的平均共同确认成轨率分别为0.7767、0.7433和0.6833，中位轨迹纯度分别为1.0000、0.9167和0.8889。正式30-seed标定冻结的共享跟踪器采用10米运动初始化残差门、3个全局假设、0.99卡方置信度和0.1过程噪声；预检与正式配置不得混写。预检只检验两台相机是否形成足量本地轨迹，不检验跨相机关联是否正确。

标定集包含24个训练seed和6个验证seed，共540份逐圈快照。增强路线比较64组候选配置后通过冻结：验证F1为0.004654，33组选中关系中15组正确、18组错误，精确率0.4545，召回率0.002339。冻结通过只表示F1、正确关系数和选中关系数均大于0，是“非零能力门控”，不是准确率、召回率或实时性验收。

保留测试使用`20270201-20270220`，每个seed包含三档干扰和6个扫描圈，共360次在线发布。增强路线宏平均精确率、召回率和F1均为0，正确匹配数为0；95分位端到端时延为10268.93毫秒，1000毫秒时限满足率为0.1667。60次第一圈发布按时返回但没有匹配，其余300次发布超时并按失败处理。零错配和零重复身份由“没有有效发布匹配”造成，不能解释为关联精度良好。

当前V2只证明快照、冻结、隔离和失败关闭流程能够完整执行。它没有形成可用的100目标在线配准能力，性能和关联结果均未达到使用条件。详细证据见[`docs/EPIPOLAR_MHT_FORMAL_V2_24_6_20_RESULT_ANALYSIS_CN.md`](docs/EPIPOLAR_MHT_FORMAL_V2_24_6_20_RESULT_ANALYSIS_CN.md)。第一版失败原因仍以[`docs/EPIPOLAR_MHT_FORMAL_24_6_20_FAILURE_ANALYSIS_CN.md`](docs/EPIPOLAR_MHT_FORMAL_24_6_20_FAILURE_ANALYSIS_CN.md)为准。

### 共享候选与20目标筛选结果

2026年8月13日完成增强路线的共享候选适配。正式入口优先读取快照中的`geometry_candidate_pairs`和候选图指纹，只对main提供的匿名局部航迹对执行共面性、多时刻拟合和多假设匈牙利分配；旧快照缺少该字段时保持全组合兼容回退。共享候选为空时不执行任何航迹对拟合。候选边引用未知航迹、方向颠倒、重复或指纹不一致时失败关闭。

增强路线同时读取在线载荷中的`target_count`，支持20、40、60和100四档规模。冻结清单与快照都声明规模时，两者必须一致；不一致的输入在关联计算前拒绝。旧快照或旧冻结清单缺少该字段时，规模保持未知并写入诊断，不按100目标补默认值。该兼容路径只用于读取旧记录，不能据此声明旧记录属于某一目标规模。

第二圈可以形成`tentative`候选，第三圈最早按最近三圈两次一致并满足支持度门限转为`confirmed`。发布记录区分候选筛选、六参数拟合、全局分配和跨圈状态更新时间，并记录完整组合数、白名单边数、成熟边数和拟合数。端到端超过1000毫秒时返回`availability="timeout"`且匹配为空，同时清除该场景临时确认状态，后续回合不能补发超时结果。

同输入消融入口为`load_candidate_path_ablation_runner(freeze_manifest)`。返回的运行器对同一快照分别维护共享白名单和旧全组合两套独立状态，奇偶圈交替执行顺序，并输出相同的完整输入指纹、各自匹配、候选计数和分阶段时延。旧分支的候选图指纹保持为空，避免误称其消费了白名单；两分支的同输入性由`input_fingerprint`证明。

20目标标定与冻结已完成。增强路线在验证集上的F1为0.671164，通过正向能力冻结门控并进入一次性保留测试。保留集宏平均精确率为0.4430，宏平均召回率为0.3542，宏平均F1为0.3905；条件精确率为0.7502206531，在线身份合同违规为0。重干扰条件下F1降至0.1720，说明漏检、虚警和姿态误差同时存在时，现有几何证据不足以维持稳定关联。

保留集共发布120圈，其中29圈超过1000毫秒时限。端到端95分位时延为1495.0947毫秒，超过固定验收上限；候选筛选阶段95分位时延为1173.15毫秒，是当前主要在线耗时。增强路线因此在20目标阶段淘汰，不进入40、60和100目标试验，并且不得在后续规模重新加入。该判定与本目录历史40目标单种子结果分开：历史结果继续保留，但不能作为统一连续周扫协议下的晋级证据。

向量化候选筛选、增量轨迹缓存和有界候选预算仍可作为后续性能研究。若形成新实现，应使用新的路线版本和未使用过的数据重新验证；本轮已淘汰路线及其冻结参数不因后续优化计划而恢复晋级资格。
