# 双站光电100目标轻量关联试验

## 结论

轻量路线已经接入双站连续周扫在线协议V2，完成9回合预检、30个校准随机种子和20个保留测试随机种子。路线可以在不使用真实目标编号、AirSim对象名称和真实三维位置的条件下形成非零匹配，冻结隔离和三路线同源输入校验均通过。

保留测试没有收敛。逐圈宏平均F1为0.011777，宏平均精确率为0.023362，宏平均召回率为0.007944，错误关系765个。1000毫秒时限满足率为0.5944，端到端时延95%分位数为2183.95毫秒。该路线目前适合作为在线问题诊断基线，不能作为有效配准方案进入系统主线。

联合冻结中的 `accepted=true` 只表示验证集存在非零正确匹配。验证集发布2044个关系，其中正确780个、错误1264个，宏平均F1为0.156884。冻结通过不代表算法达到精度、召回率或实时性要求。

## 场景

| 项目 | 配置 |
| --- | --- |
| 光电站 | 2个，横向基线2千米 |
| 目标 | 100个3米Actor，速度50米/秒 |
| 航向 | 50个0度，50个负30度，空间混排 |
| 扫描 | 同方向连续360度周扫，2秒一圈 |
| 时长 | 12秒，6圈 |
| 逻辑采样 | 100赫兹，AirSim时钟倍率0.1 |
| 云台误差 | 固定偏差均方根0.4毫弧度，逐帧抖动均方根0.3毫弧度 |
| 干扰 | 轻、中、重三档漏检和虚警 |
| 校准划分 | 24个训练随机种子、6个验证随机种子 |
| 保留测试 | 20个未见随机种子 |
| 在线时限 | 每圈端到端不超过1000毫秒 |

AirSim `simGetDetections` 提供目标框，协议再注入漏检和虚警。离线真实身份只用于预检诊断、训练标签、验证选择和当圈发布后的测试评分。它不进入在线快照和候选特征。

## 算法

### V2输入

main在每圈结束时冻结两站匿名航迹。每条观测保留时间、单位视线、测量协方差、状态向量、状态协方差和新息马氏距离；每条航迹保留确认或滑行状态、近期命中和漏扫次数。快照同时记录协议指纹、共享跟踪器指纹和输入指纹。轻量路线在计算前核对这些字段，防止使用外来跟踪器、被修改的快照或保留测试之外的随机种子。

### 候选门控

两站每条稳定航迹构成一个潜在组合。算法先用共面残差、时间重叠、重投影误差、交会角和条件数排除明显不可能的组合。这一步只保留几何上可能对应同一目标的候选边，仍允许目标保持未匹配。

V2候选边包含18维特征。前14项描述多时刻共面误差、时间重叠、重投影误差、拟合速度、交会条件和角速度差；后4项利用协方差和近期命中，对运动残差、共面残差、合成视线不确定度及航迹连续性进行归一化。真实身份和真实位置不参与这些特征。

### 轻量评分

校准阶段比较四类模型：非负几何权重、Platt概率标定、单调概率标定和带二范数约束的逻辑回归。所有参数只在24个训练随机种子上拟合。6个验证随机种子同时选择模型、概率门限和未匹配代价。

V2最终选择 `logistic_edge_features_C0.1`。概率门限为0.4，未匹配代价为0.9。低于门限或保留代价不优于未匹配的候选不会进入最终分配。

### 全局分配与确认

匈牙利算法在当前候选图上寻找总代价最低的一对一组合，避免一条A站航迹同时匹配多条B站航迹。输出关系还需经过时间确认：同一航迹对在连续3圈内至少出现2次，才标为确认关系。超过1000毫秒的结果按失败关闭，不在评分阶段事后补回。

## 预检

预检使用3个随机种子，对理想、仅姿态误差和完整干扰各运行一次，共9回合。默认10米运动残差门和3个全局假设时，完整干扰场景中位航迹纯度为0.8452，低于0.85门槛。离线候选比较随后选中3米运动残差门和单一全局假设，没有降低既定门槛。

| 场景 | 回合数 | 平均共同确认率 | 中位航迹纯度 | 判定 |
| --- | ---: | ---: | ---: | --- |
| 理想 | 3 | 0.7767 | 1.0000 | 通过 |
| 姿态误差 | 3 | 0.7433 | 0.9167 | 通过 |
| 完整干扰 | 3 | 0.6833 | 0.8889 | 通过 |

预检只检查共享局部跟踪器能否形成足够纯净、足够共同可见的匿名航迹，不评价轻量跨站关联模型。

预检按设计只承担小样本早期止损和结构可行性检查，不冻结正式跟踪器配置。9回合预检选中3米运动初始化残差门和单一全局假设，指纹为 `0b3838...bc9`。正式标定扩大到30个随机种子，并在13个候选配置中独立选择最终配置；只有10米运动初始化残差门和3个全局假设的旧默认候选通过全部正式门槛，最终指纹为 `867bdf...95d`。两阶段指纹不同符合既定流程，不是合同断链。正式校准、保留测试和三条路线快照均使用 `867bdf...95d`，内部一致。小样本预检可以提前拦住明显不可行方案，不能代替正式多随机种子标定。

训练使用随机种子 `20270101` 至 `20270124`，验证使用 `20270125` 至 `20270130`。每个随机种子包含3档干扰和6圈，共432份训练快照和108份验证快照。冻结文件写出前没有打开保留测试数据。

## 保留测试

保留测试使用随机种子 `20270201` 至 `20270220`，每个随机种子包含3档干扰和6圈，共360次在线发布。三条路线逐圈输入指纹一致，在线真实身份使用标记为否。

| 宏平均召回率 | 0.007944 |
| 宏平均F1 | 0.011777 |
| 发布关系总数 | 1051 |

宏平均精确率按全部逐圈样本计算。空候选图和超时圈按零分计入，因此它不同于将286个正确关系除以1051个发布关系得到的总体关系比例。宏平均指标反映连续周扫过程中每一圈都要形成及时、正确结果的要求。

前3圈受至少4圈稳定航迹门限影响，180份样本全部为空。后3圈候选图规模迅速增大，146份样本超过1000毫秒。剩余34份可用计算发布了1051个关系，但其中765个为错配。测试损失同时来自成轨等待、候选规模、计算超时和轻量评分判别不足，不能只调整概率门限处理。

## 历史结果

旧 `formal_24_6_20` 使用V1快照和旧共享跟踪器协议。该轮轻量路线在20个保留测试随机种子上零匹配，原因是验证正候选不足、冻结的0.7概率门限拒绝全部候选。旧结果记录在 `DUAL_OPTICAL_100TARGET_LIGHTWEIGHT_FORMAL_24_6_20_FAILURE_ANALYSIS_CN.md`。

当前 `formal_v2_24_6_20` 增加协方差特征、共享跟踪器冻结、非退化冻结保护和三圈两次确认，已经消除零输出，但没有解决低精度、低召回和超时问题。

更早的 `formal_expanded_20260820_20260920_run01` 是保存后候选图的离线模型对照。该轮高分没有覆盖连续周扫成轨、逐圈因果发布和1000毫秒端到端时限，不能与本轮在线结果直接比较。原8张结果图属于该历史试验，本报告不引用其性能数据。

## 后续工作

后续重复实验应继续区分预检和正式标定。预检只负责早期止损，正式阶段仍需使用多随机种子在候选配置中独立选参。正式配置选定后，校准、测试和三条路线必须绑定同一最终指纹；不要求预检指纹与正式指纹相同。

第二步应按圈记录稳定航迹、共同可关联目标、硬门控候选、轻量评分保留边和匈牙利发布关系，分离成轨损失、候选门控损失和评分损失。计算侧需要拆分候选图构建、评分和匈牙利求解时延，先把95%分位时延降到1000毫秒以内。

第三步在新的训练集加入密集平行航迹、交叉航迹和持续虚警构成的困难负样本。验证冻结条件应同时限制宏平均精确率、召回率、错误关系和时限满足率，不能继续只以非零F1放行。新的保留测试随机种子必须在模型和门限冻结后才可打开。
