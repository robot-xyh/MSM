# 目标假设与局部航迹图网络

本包用于独立双光电目标假设—局部航迹交接试验。在线输入是两站按圈冻结的匿名局部航迹，输出是每个相机内“匿名目标假设—匿名局部航迹”的一一对应结果。包内同时保留 V5 图网络试验和 V4.1 无模型确定性交接复用，两者均不接入 D1-D7 主流程，也不生成或改写全局航迹编号。

## 在线流程

1. 每圈先在共享候选边内评估 A/B 航迹对。带权视线拟合直接使用两站原始时间戳，联合估计北东地坐标系下的位置、速度和 6×6 协方差。短基线、小交会角、病态矩阵和大残差均失败关闭。
2. A/B 匈牙利分配结果写成匿名在线发布。发布包含输入快照指纹、协议指纹、配对、代价和延迟，不包含离线真值。一个配对在最近三圈至少出现两次后，才能生成 `ConfirmedTrackPair`。
3. 确认对必须携带来源发布哈希。形成目标假设时，还要提供原在线发布注册表；缺失发布、哈希变化、seed 不同、协议不同、快照不同或确认状态不符都会被拒绝。离线标签文件不能构造确认对。
4. 目标假设只在后续圈次生效。形成假设时已使用的样本不能再次进入目标—航迹图。节点特征和边证据均只读取 `timestamp > last_observation_timestamp + epsilon` 的新样本；没有新证据时不保留候选边。
5. 每个相机分别构建二部图。硬几何门控先形成不可变白名单。`rule_baseline` 映射到包内 `deterministic` 路线；`gnn_assisted` 在同一目标假设、同一局部航迹和同一白名单上输出有界代价修正。
6. 图网络采用独立的目标编码器和航迹编码器，隐层为 64 维，执行两轮信息交换。两条路线最后都使用带未匹配项的匈牙利算法。相同目标—航迹关系在最近三圈至少出现两次后才标记为确认。

## V4.1 确定性交接复用

`deterministic.py` 单独提供规则代价、带未匹配项的匈牙利一一分配和最近三圈两次一致确认。该文件不依赖图网络模型。包入口采用按需加载，V4.1 只导入确定性路径时不会加载 PyTorch，也不会读取 V5 冻结权重。

V4.1 使用 V4 已封存的零相位连续周扫匿名快照和航迹级 SuperGlue 发布做事后回放。它复验源发布、输入、模型和协议哈希，只向下一圈进行因果外推，在线发布封存后才读取离线身份评分。2026-08-15 的二十目标回放中，确定性交接覆盖为 0.0600，低于原 V4 基线的 0.6150，因此判定为诊断性未通过。四十目标因共享单站跟踪器没有通过上游冻结门槛而未运行。

## V5 适配器

`v5_adapter.py` 提供 V5 runner 约定的三个入口：

- `train_and_freeze`：只打开 calibration manifest 中的训练集和验证集标签。40、60、100 目标按相同 seed 数准备样本，训练阶段再次按三尺度最小可用样本数等量抽样。模型至少执行五次独立初始化。
- `publish_test`：只接受 `dual-optical-v5-online-test-manifest-v1` 在线测试清单，并校验 `online_only=true`、清单指纹及模型冻结哈希。发布清单原样绑定 `online_manifest_fingerprint`，同时记录在线清单和 V5 模型 wrapper 的文件哈希。输入和输出均不得包含 `label_path`、`label_sha256`、真值计数或 Actor/全局身份字段。
- `score_publications`：两条路线发布文件落盘并校验哈希后，才读取完整测试清单和离线标签。输出每条路线的有效目标假设身份、当前局部航迹身份、覆盖率、错误匹配、未匹配、一一对应、确认状态和延迟。

当前 `dual_optical_online_benchmark.v5_runner` 的适配器函数签名已经匹配本包。调用方必须先注册 V5 模型 wrapper，再通过 runner 生成带 `online_manifest_fingerprint` 的在线专用测试清单。直接传入含标签路径的完整 dataset manifest、缺少或篡改指纹的清单、绑定其他模型的清单都会在读取快照前拒绝。完整清单只交给 `score_publications`。

## 冻结与验收边界

原生冻结 JSON 明确记录：

- `training_splits=["train"]`；
- `selection_splits=["validation"]`；
- `scale_sampling_policy="uniform_over_40_60_100"`；
- `initialization_count>=5`；
- `test_data_accessed=false`；
- `test_labels_accessed=false`；
- `model_fingerprint`。

模型冻结仅证明训练过程和标签隔离完成。当前没有为目标—航迹图网络设置正式性能门槛，因此原生冻结保持 `acceptance_passed=false` 和 `formal_use_allowed=false`。评分文件同样写明 `formal_acceptance_claimed=false`，诊断指标不能替代正式批量验收。

## 验证状态

2026-08-15 完成包内单元和适配器测试，共 17 项。测试覆盖异步拟合、协方差、坏几何、在线发布来源、因果样本隔离、空图、一一对应、两圈/三圈确认、三尺度平衡、五次初始化、完整清单拒绝、双路线在线发布和离线评分。

V5已完成40、60、100目标全量批次。三个规模的9回合预检均通过，但每个规模的25组共享跟踪器候选全部未通过正式门槛。质量选择候选的单圈处理P95分别为531.75、817.76和1799.78毫秒，平均航迹碎片数也均高于对应基线；40和100目标另有错误恢复率超限。因此模型和测试结果均标记为诊断，不具备正式使用资格。

保留测试中，图网络相对规则基线在40目标减少3条即时错配，在60目标减少2条，100目标没有变化。两条路线在40、60、100目标的覆盖分别同为3.36%、2.97%和1.92%，三种规模均未形成跨圈确认。当前证据不支持把该图网络接入在线主线。V5没有相同seed的零相位对照，结果也不能单独证明180度相位差的效果。

完整证据位于`dual_optical_online_benchmark/outputs/scale_funnel_v5_phase180_targettrack/`。执行清单、机器可读汇总和中文报告分别为`v5_run_manifest.json`、`v5_summary.json`和`V5_PHASE180_TARGET_TRACK_REPORT_CN.md`。
