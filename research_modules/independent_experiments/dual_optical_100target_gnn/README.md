# 双站光电100目标图网络关联独立试验

本目录验证100目标、随机漏检和随机虚警条件下的双站匿名轨迹关联。实现使用普通PyTorch，不依赖`torch_geometric`或DGL，也不启动AirSim。main负责生成共享快照和离线标签，本目录只消费冻结清单声明的校准数据。

本试验与D1至D7隔离。A、B两侧本地轨迹组成二部图；图网络输出候选边属于同一目标的概率，但不直接发布匹配。几何硬门控之后，确定性几何、学习代价和混合代价三种方案均通过带未匹配项的匈牙利算法形成一对一结果。高于未匹配门限的边在求解前阻断，避免无效边改变合法匹配的全局最优解。

## 环境

- Python 3.12
- NumPy、SciPy、Matplotlib、python-docx
- PyTorch 2.x；图形处理器评测需要可用的CUDA
- 不需要`torch_geometric`、DGL或AirSim Python客户端

### 确认策略诊断

在线默认策略仍为`legacy_strict`：从第3圈开始，最近3圈同一关系至少出现2次才正式发布，默认路线版本保持`dual-optical-edge-gnn-online-v2`。以下策略只用于隔离诊断，不改变正式默认值：

- `early_repeat`：前两圈关系一致即可在第2圈确认，之后采用最近3圈2次；
- `graded`：双方航迹处于确认或短时保持状态，且互为第一候选、网络概率、第二候选优势和原始归一化共面残差同时满足要求时允许单圈快速确认，其余关系采用`early_repeat`；
- `direct_1of1_diagnostic`：当前匈牙利结果立即输出，只用于测量覆盖上限和误配代价，必须同时传入`--diagnostic-mode`，发布路线版本明确带有`diagnostic`标记。

分级策略的概率门限只能取`0.7/0.8/0.9`，第二候选优势只能取`0.10/0.20`。参数由外部验证集选择后显式传入，在线代码不读取真实身份。匿名测试重放示例：

```bash
PYTHONPATH=research_modules/independent_experiments \
python3 -m dual_optical_100target_gnn confirmation-ablation \
  --test-manifest /path/to/anonymous_test_manifest.json \
  --freeze-manifest /path/to/freeze_manifest.json \
  --output-dir /path/to/confirmation_ablation_output \
  --split test \
  --strategy graded \
  --probability-threshold 0.8 \
  --margin 0.2 \
  --device cuda
```

`--split`默认值为`test`，兼容原测试重放。验证集选择分级确认参数时，传入`--split validation`和`phase=calibration`清单；入口只重放其中的validation条目，train条目不进入在线关联，calibration清单混入test条目时失败。该入口不支持train重放。

输出包含逐圈发布、`input_split`、原始/待确认/快速确认/已确认数量、各阶段时延和实际设备。测试或校准清单即使保留离线标签文件引用，重放入口也不会打开标签；在线快照若携带真实身份、Actor或标签字段则失败关闭。

`confirmation-ablation`和`freeze-online`均支持显式`--device cuda`。显式请求CUDA时，设备不可用会直接失败，不会静默退回中央处理器；重放清单同时记录请求设备、实际设备和推理后端。本轮匿名重放记录的请求设备与实际设备均为`cuda`。验证重放只读取校准清单中的validation条目，测试重放只读取test条目，二者都不打开离线标签。真实身份只在重放结束后的独立评分步骤使用。

## 算法

节点特征包括轨迹样本数、持续时间、扫描次数、方位和俯仰跨度、角速度、缺失比例、检测稳定度、方位/俯仰角速度、方位不确定度、角速度不确定度、最近三圈命中、轨迹状态和V2可用标记。边特征在原有共面、时间、重投影、交会角和运动量基础上，增加双站角速度差、按协方差归一化的运动/共面残差、联合方位不确定度和近期命中重叠率。这些量来自匿名视线和已知相机外参，不使用AirSim真实目标位置、Actor名称或真实身份。

几何硬门控默认要求共面残差中位数不超过0.50毫弧度、至少3个对齐样本、时间重叠比例不低于0.15、重投影均方根不超过30像素、交会角不低于1度且条件数不超过1e8。网络无法恢复被硬门控拒绝的边。

图网络包含两层消息传递，隐藏维度64，随机失活率0.1。边分类器输出同目标概率。训练使用加权二元交叉熵和AdamW，学习率0.001、权重衰减0.0001。当前V2正式协议执行五次独立初始化，每次最多200轮，验证损失连续25轮不改善时停止；历史episode协议保留80轮和耐心值10，仅用于读取旧产物。

混合路线先把几何证据和学习概率合成为同尺度有效概率，再取负对数：

`p_effective = p_geometry^0.4 × p_learned^0.6`

`C_hybrid = -log(p_effective)`

匈牙利算法输出一对一结果。在线发布采用最近3圈至少2圈一致确认；第一圈和第三圈命中、第二圈漏失仍可确认。

## 腐化设置

- 轻度：3%随机漏检，每半程1个瞬时虚警，每相机无持续假轨迹；
- 中度：7%随机漏检，每半程2个瞬时虚警，每相机1条持续假轨迹；
- 重度：12%随机漏检，每半程4个瞬时虚警，每相机2条持续假轨迹。

持续假轨迹跨越至少4个扫描半程。瞬时虚警保留在腐化记录中，但因扫描次数不足不会进入稳定轨迹二部图。每个seed和腐化等级映射到固定随机种子，可重复生成相同数据。

三档漏检和虚警是在AirSim回合保存完成后，对本地轨迹样本离线注入。它们用于保证三种算法获得完全相同的受扰输入，不代表AirSim检测器或真实光电设备的误识别分布。本地轨迹多数纯度较高，但仍存在低纯度轨迹；以多数身份作为监督标签会给这部分样本引入标签噪声。

图网络宏平均F1高于本轮轻量路线0.011777和增强极线路线0，但绝对精确率、召回率和时限满足率均未达到工程使用要求。360次发布中33次形成可用GPU匹配，180次候选图为空，147次超时。该结果表明V2已修复旧版“验证全零仍冻结、测试零匹配”的合同问题，但稳定轨迹形成、候选边保留和端到端计算仍限制在线效果。详细口径见[图网络V2正式结果](docs/DUAL_OPTICAL_100TARGET_GNN_REPORT_CN.md)。

## 逐规模漏斗结果

## 历史扩展输出与判定

评估输出逐seed和逐腐化指标、按轻中重三档汇总的几何/学习/混合对照、失败原因、CPU/GPU推理耗时、候选图指纹、按seed成组的95%置信区间和中文报告。结果同时记录数据指纹、冻结模型指纹、权重哈希以及测试图和离线标签哈希。图网络与外部最佳轻量方案比较后，进入下一轮隔离工程验证必须同时满足：

- 验证集选出的图网络正式路线宏平均F1比外部最佳轻量方案提高至少0.02；
- 配对seed的F1差值95%置信区间下限大于0；
- 错误关联数量不高于外部最佳轻量方案；
- 重复真实身份数量不高于外部最佳轻量方案；
- 图形处理器推理耗时95%分位不超过100毫秒。

未提供外部轻量比较清单时，扩展报告固定写为“等待外部比较”，不根据本模块内部几何基线作最终promotion。本轮外部比较已经完成，图网络未通过升级条件，因此不进入替换轻量路线的工程验证。后续优先补充真实检测器误差回放，并分析轻量模型在不同目标密度和扫描条件下的稳定性。
