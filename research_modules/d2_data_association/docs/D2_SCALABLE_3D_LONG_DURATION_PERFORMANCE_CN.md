# D2 长时关联性能验证

**验证日期**：2026-07-22  
**适用范围**：200 目标六维质点关联、受治理回放和长 episode 性能诊断

## 1. 结论

200v200 关联随 episode 时长超线性增长的主因已定位并修复。热点位于 D1 航迹元数据中
重复携带的大型诊断树，D2 原实现对每条航迹重复递归检查这些内容。三维门控、稀疏候选
图和 GNN/Hungarian 不是本轮主要瓶颈。

最终加固代码的可复现 200 航迹、48 周期基准为 `16.858297 -> 6.472896 s`，加速
`2.604444x`，48/48 周期语义一致。既有五 seed 和 10 秒实际隔离回放是在自定义 Mapping
等价审查加固前运行，其语义哈希和在线真值隔离证据仍有效，计时不作为最终加固版本性能，
需由 main 复跑。上述结果均不是实时服务等级或 AirSim 验收结论。

## 2. 根因

D1 会把 `sensor_health`、`association_audit` 和 `latency_audit` 复制到同一批次的每条
`GlobalTrack`。这些诊断树在批内内容相同，但会随已见传感器数量增长。短时输入约有
64 个传感器，10 秒输入增至 181 个传感器。D2 之前在适配、`Detection3D` 构造和 tracker
入口对每条航迹递归访问这些树，导致工作量同时随航迹数、传感器数和周期数增长。

同配置 `cProfile` 结果如下。递归函数累计时间包含嵌套调用，不能与阶段墙钟直接相加，
但调用次数和热点排序能明确说明增长来源。

| 项目 | 2.2 秒 | 10 秒 |
| --- | ---: | ---: |
| D2 发布周期 | 9 | 48 |
| 递归元数据访问 | 2,879,628 | 62,249,840 |
| 元数据审计累计时间 | 5.223 s | 111.810 s |
| GNN/Hungarian 累计时间 | 0.161 s | 0.990 s |
| claim summary 累计时间 | 0.011 s | 0.307 s |
| duplicate coalescence 累计时间 | 0.046 s | 0.207 s |

## 3. 修复方法

输入批次先执行完整禁用身份键审计。对于三个批内共享诊断字段，第一个不同值执行递归
审计；后续只有完全由可信内置容器和标量组成、无循环且内容相等的值才复用已通过结果。
未知或自定义 Mapping 始终完整审计。任一轨道上的内容发生变化时也执行完整审计，因此
单轨注入 `truth_id`、actor 身份或上游规范 ID 仍会立即拒绝。

审计通过后，D1 到 D2 的适配边界只保留 D2 实际消费的字段，包括双时间戳、观测标识、
来源谱系、模态和坐标帧。大型 D1 健康与诊断树不再复制到每个 `Detection3D`。对象构造
和 tracker step 仍分别执行递归身份审计，构造后篡改继续 fail closed。

本轮没有修改以下行为：

- 六维状态、三维马氏门控和稀疏候选边；
- GNN/Hungarian 代价和求解频率；
- D2 中心 `global_track_id` 所有权；
- observation claim ledger、replay/stale 和生命周期；
- 显式 `id_switch_count` 及其 availability 语义。

## 4. 性能结果

### 4.1 自包含长时基准

基准使用 200 条航迹、48 个周期，传感器诊断规模从 20 增至 181。

| 路径 | 总时间 |
| --- | ---: |
| 未投影 D1 诊断参考路径 | 16.858297 s |
| 批审计和 D2 合同投影路径 | 6.472896 s |
| 加速 | 2.604444x |

48/48 周期语义一致，最终航迹哈希和最终 claim 哈希一致，最终 claim 数为 9600。机器可读
结果为 `d2_long_duration_metadata_benchmark_20260722.json`，文件 SHA-256 为
`8a8f9781955e22e91f87aecdeb1cb9f049fda43e1bbd0340ae62da6d5583afa5`。

## 5. 测试

- 审查加固后的元数据、性能和恶意 Mapping 专项：`25 passed`。
- 加固前元数据批审计、合同投影和长时语义专项：`38 passed`。
- claim、replay、duplicate 核心专项：`54 passed`。
- 审查加固前 D2 全量回归：`214 passed, 1 warning in 48.48s`；最终全量由 main 复跑。
- 新增和修改入口的 Python 语法检查通过。

唯一警告来自既有 Matplotlib `Axes3D` 环境，不影响 D2 关联、身份治理或性能结论。

## 6. 边界

当前证据关闭 D2-owned 的长 episode 重复元数据审计缺口。仍需由后续系统验证覆盖真实
AirSim observation ID 和时钟分布、遮挡/杂波/OOSM、极端全重叠候选图以及固定硬件上的
循环时延分位数。本轮没有 AirSim 接口变化，也没有调整关联阈值或降低关联频率。
