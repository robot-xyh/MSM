# D1 协方差成对限制向量化准入评估

## 结论

D1 优化准入结论为 **通过**。评估只读取三轮已写盘证据，不参与控制，也不使用离线真值改变业务结果。
系统实时性缺口 **未关闭**。本批是 200 对 200 三维质点、seed 1100 的三次交错 clean 回放，每次世界时间 2.2 秒；它不是多 seed、AirSim 或实机容量试验。

## 证据边界

- 本批只有 seed 1100 的三次重复，不能估计跨 seed 稳定性。
- 世界时间只有 2.2 秒，候选实时因子仍低于 1，不能关闭系统实时容量缺口。
- 本批没有 AirSim、均方根误差、归一化估计误差平方或归一化创新平方证据。
- 准入仅说明当前冻结输入下的 D1 性能优化满足门限，不代表跟踪精度或拦截效果提升。
