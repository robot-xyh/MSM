## 3. 解读说明

- 探测、跟踪、分配、降级、末端配准和安全指标分开报告，避免单一命中率掩盖问题。
- 计数类指标应与比例类指标一起检查，少量但严重的安全事件可能被总体成功率掩盖。
- 偏态或长尾指标在形成正式结论前，应使用 bootstrap 或非参数方法复核。
