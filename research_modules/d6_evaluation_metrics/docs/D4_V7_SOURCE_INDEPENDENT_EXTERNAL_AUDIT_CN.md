# D4 v7 来源独立评价 D6 盲审

## 结论

D6 从冻结标签数据、v7 模型参数、同快照确定性 R0 规则和投影约束重新计算 128 帧动作。D4 高层评价器调用数为 0，D4 汇总字段没有作为指标来源。D6 重算记录与 D4 逐帧记录完全一致。

规则正类共 42 帧，精确正动作命中为 0/42。validation 和 test 均未形成转移变化。train 出现 3 次可执行转移变化，全部位于负类且均为错误边，对应 3 次虚假转移。候选没有形成来源独立的正确转移能力。

投影拒绝、干预不变量失败和原始 R0 完整动作元组偏差均为 0。该安全结果不能抵消正动作泛化失败。评价结论为失败关闭；置信校准、正式留出、运行预检、D3、D7、联盟、控制和物理权限全部关闭，系统继续使用 R0。
